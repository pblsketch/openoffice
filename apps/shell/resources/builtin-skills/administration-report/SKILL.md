# 행정문서 (행안부 가이드라인)

행정안전부가 2026년 8월 24일부터 적용하는 「행정문서 작성 가이드라인 2.0」과 「AI 친화적 행정문서 작성방법」에 맞게 문서를 다듬는다. 사람이 읽기 쉽고, AI가 읽어도 구조를 잃지 않게 하는 것이 목적이다.

이 스킬은 **행안부 기준**이다. 다른 기관의 지침이 있으면 그 지침을 먼저 따른다. 법적 강제가 아니라 부처의 작성 기준이다.

## 세 가지 원칙

1. **문장은 서술식으로.** 주어·목적어·서술어를 갖춘 문장으로 쓴다. "~함", "~추진" 같은 개조식은 표 안의 짧은 항목에만 쓴다.
2. **글꼴은 어디서나 열리는 것으로.** 함초롬바탕·함초롬돋움·맑은고딕을 쓴다. 휴먼명조·HY\*·한컴 \* 처럼 그 프로그램에만 있는 글꼴은 다른 PC에서 대체 글꼴로 바뀐다.
3. **표와 그림은 단순하게.** 제목은 표·그림 **위**에 쓴다. 표를 제목 상자처럼 쓰지 않고, 칸 병합은 꼭 필요한 만큼만 한다.

## 번호 사다리

```
Ⅰ.  →  1.  →  가.  →  1)  →  가)  →  (1)  →  (가)  →  ①  →  ㉮
```

- 한 깊이에서 두 가지 표기를 섞지 않는다.
- 단계를 건너뛰지 않는다. `1.` 다음에 `(1)`이 오면 `가.`가 빠진 것이다.
- 원문자(①, ㉮)는 어느 단계에서나 쓰는 글머리다. 사다리의 깊이로 세지 않는다.
- 번호는 글자로 적혀 있는 것만 고친다. 한글의 자동 문단 번호는 이 도구로 바꾸지 않는다.

## 고치는 차례

문서를 통째로 다시 쓰지 않는다. 걸린 것만, 아래 차례로 고친다.

1. **글꼴** — `replace_font`로 바꾼다. 예: `from: "휴먼명조", to: "함초롬바탕"`. 본문과 표 칸이 한 번에 바뀌고 실행 취소도 한 단계다.
2. **표 제목** — 표 바로 위에 제목 문단이 없으면 `insert_paragraphs`로 넣는다. 예: `표 1 인구감소지역 지정 개요`. 표를 가리키는 글자가 없으면 `list_tables`로 표 번호를 확인하고, 표가 놓인 문단의 앞뒤 글자를 기준으로 넣는다.
3. **1×1 제목 상자** — 절 제목을 1×1 표 안에 넣은 경우다. **글자를 먼저 꺼내 일반 문단으로 넣고, 그다음에 표를 지운다.** 순서를 바꾸면 제목이 사라진다. `read_table`로 칸의 글을 읽고, `insert_paragraphs`로 같은 자리에 넣은 뒤 `delete_table`을 부른다.
4. **번호** — `replace_text`로 바꾼다. 예: `(1) 세부 내용` → `가. 세부 내용`. 같은 번호가 여러 곳에 있으면 `occurrence`로 하나씩 확인한다.
5. **문장** — 개조식 문단을 서술식으로 고친다. `replace_selection`이 있으면 선택한 부분만, 없으면 `replace_text`로 문단을 통째로 바꾼다. 뜻을 바꾸지 말고 문장 꼴만 고친다.

고친 뒤에는 **무엇을 몇 곳 바꿨는지 한 줄씩** 알린다.

## 하지 않는 것

- **표 안의 표와 병합을 함부로 건드리지 않는다.** 지우면 내용이 사라지고, 합치면 칸의 글이 뭉개진다. 짚어만 주고 사람이 정하게 한다.
- **꾸미기를 새로 넣지 않는다.** 음영·테두리·글자색으로 강조를 더하지 않는다. 이미 있는 강조(밑줄·진하게)는 지침이 허용하므로 지우지 않는다.
- **분량을 채우려고 빈 줄을 늘리지 않는다.**
- **문서 전체를 다시 쓰지 않는다.** 걸린 곳만 고친다.
