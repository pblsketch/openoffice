# 행정문서 작성 (행안부 형식)

빈 문서나 짧은 메모에서 **보고서를 처음부터** 쓴다. 이미 있는 문서를 고치는 일은 `administration-report`(점검) 스킬이 맡는다.

## 1. 먼저 묻는다

한 번에 하나씩, 필요한 것만 묻는다.

- 무엇을 보고하는가(주제), 누구에게(장관·실국장·과장), 왜(목적)
- 근거가 되는 자료(법령, 통계, 회의·점검 결과). 없으면 **지어내지 않고** `○○`로 둔다
- 분량(1~2쪽 / 3~5쪽), 기한, 꼭 들어가야 할 항목

답을 기다리기 어려우면 합리적인 기본값으로 쓰고, **무엇을 가정했는지 첫 줄에 밝힌다.**

## 2. 뼈대

1~2쪽은 이 넷이면 충분하다.

```
제목 (한 줄)
Ⅰ. 추진 배경      — 목적 / 근거 / 그동안의 경과
Ⅱ. 주요 내용      — 추진 체계 / 세부 내용(필요하면 표)
Ⅲ. 향후 일정      — 월별 또는 단계별
Ⅳ. 행정 사항      — 협조 요청·예산·홍보 (필요할 때만)
```

3~5쪽이면 Ⅱ 아래를 `1.` → `가.`로 한두 단계 더 나눈다. 절은 넷을 넘기지 않는다.

## 3. 쓰는 법

- **문단은 서술식**으로 쓴다. "~한다 / ~하였다". 개조식("~함", "~추진")은 표 안의 짧은 항목에만.
- 한 문단에 한 가지를 쓴다. 항목이 셋을 넘으면 문단을 나누거나 표로 만든다.
- 기호는 `□`(큰 제목) → `○`(항목) → `-`(세부) → `·`(더 세부) 순으로 쓴다.
- 번호는 `Ⅰ.` → `1.` → `가.` → `1)` → `가)` → `(1)` → `(가)`. 한 깊이에서 두 가지를 섞지 않는다.
- **표는 두 줄 이상일 때만** 만든다. 제목은 표 **위에** 한 줄로: `표 1 인구감소지역 지정 개요`. 그림도 제목을 위에 쓴다.
- 표는 첫 줄을 열 이름으로 만들고, 칸 병합은 꼭 필요할 때만 한다.
- 글꼴은 **함초롬바탕**(본문)과 **함초롬돋움**(제목). 음영·테두리·글자색으로 꾸미지 않는다.
- 강조는 진하게와 밑줄까지만 쓴다.
- 숫자에는 근거를 붙인다("2025년 12월 기준"). 모르는 값은 `○○`로 두고, 그 사실을 마지막에 알린다.
- 날짜는 `2026. 10. 29.` 꼴로 쓴다.

## 4. 문서에 쓰는 순서 (도구)

1. **문단부터 넣는다.** `insert_paragraphs`에 `where: "end"`를 주고 제목과 Ⅰ~Ⅲ 문단을 한 번에 넣는다(한 호출에 100문단까지). 빈 문서에는 이것부터.
2. **표는 문단을 넣은 뒤에.** `insert_table`의 `anchor`는 표 바로 위에 놓을 제목 문단의 글, `where: "after"`. 첫 줄이 열 이름이면 `header: true`.
   - 칸의 글은 한 호출에 다 넣지 말고, 만든 뒤 `fill_cells`로 채운다(표 번호는 `list_tables`).
3. **서식은 마지막에, 필요한 곳만.** `format_paragraph`로 절 제목을 진하게 하거나 크기를 키운다. 본문은 건드리지 않는다.
4. **다시 읽어 확인한다.** `read_document`로 앞부분을 읽어 번호가 건너뛰지 않았는지, 같은 깊이에 다른 표기가 섞이지 않았는지 본다.

## 5. 하지 않는 것

- **없는 사실·통계·법령 조문을 만들지 않는다.** 모르면 `○○`로 두고 사용자에게 알린다.
- **표를 제목 상자로 쓰지 않는다.** 1×1 표에 절 제목을 넣지 않고, 제목은 그냥 문단으로 쓴다.
- 한 문단에 여러 항목을 몰아넣지 않는다.
- 분량을 채우려고 빈 줄을 늘리지 않는다.
- 사용자가 주지 않은 수치를 그럴듯하게 채우지 않는다.

## 6. 마지막에 알린다

- 만든 절과 쪽수(대략)
- 사용자가 채워야 할 `○○` 자리와, 그 자리에 무엇이 필요한지
- 넣지 못한 자료가 있으면 그 이유
