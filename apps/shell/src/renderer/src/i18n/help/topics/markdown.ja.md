# Markdown エディター

Markdown エディターは .md / .markdown を開きます — .txt / .json は直接ソースビューで — ソースとレンダリングプレビューの体験です。

- **開く**：ホーム、または ファイル ▸ 開く。コマンドラインからも開けます。
- **編集**：プレーンテキストとして編集します。GFM の拡張（表、タスクリスト、取り消し線、自動リンク）はプレビューで描画されます。
- **プレビュー**：リアルタイム。画像のような相対パスの資産は、文書の隣から読み込まれます。
- **保存**：バイト単位で忠実に保存します。BOM、CRLF、末尾の改行の有無はそのまま保持され、変更がなければファイルは書き直されません。
- **検索と置換**：ctrl+F でソースを検索し、すべて置換で書き戻します。
- **AI**：プリセットのボタンから、アシスタントに文書の書き換え、書き足し、翻訳をさせられます。 選択範囲を AI に隠せます（「AI アシスタントパネル」の章を参照）。

## ツールバー

エディターの上の 1 行にボタンが並びます（ホバーすると説明が表示されます）。

- **ファイルと履歴**：保存、名前を付けて保存、元に戻す、やり直し、検索。右側の**自動保存**トグルが、変更を定期的にディスクへ書き込みます。
- **AI ボタン**：AI パネルを開きます。その隣には、書き換え／書き足し／翻訳のプリセットがあります。
- **段落スタイル**（ドロップダウン）：本文と各見出しレベルの間を切り替えます。
- **行内書式**：**太字**、_斜体_、~~取り消し線~~、`インラインコード`、リンク。
- **リスト**：箇条書き、番号付きリスト、タスクリスト。
- **挿入**：表、画像、区切り線。
- **プロパティ**：ファイル冒頭の YAML front matter のブロックを挿入、またはそこへ移動します。
- **アウトライン**：見出しの階層で移動します。
- **スペルチェック**：この文書のスペルチェックを切り替えます。
- **画像ホスト設定**：貼り付け・ドロップした画像をまず自分のストレージへ — S3 互換（R2/OSS/COS/MinIO）、SM.MS、GitHub — ローカルの assets コピーはフォールバックとして残ります。

すぐ試せる例:

- **見出し**：その行にカーソルを置く ▸ 段落スタイルのドロップダウン ▸「見出し 1」。
- **表**：**表を挿入**をクリック ▸ 行数と列数をドラッグして選ぶ ▸ セルに入力。プレビューにはすぐ描画されます。
- **タスクリスト**：数行を選ぶ ▸ **タスクリスト**をクリック ▸ 各行が `- [ ]` になり、プレビューではチェックボックス付きのリストとして描画されます。

## ノート間のリンク

ノート内のリンクは **Ctrl+クリック**（Mac では **⌘+クリック**）でたどります。普通のクリックはこれまでどおり文字の編集です。

- **見出し**：`[テキスト](#見出し)` と `[[#見出し]]` は同じノートのその見出しへ移動します。
- **ほかのファイル**：`[テキスト](other.md)` や `[テキスト](../folder/report.pdf)` は、ノートのあるフォルダーを基準にそのファイルを専用のタブで開きます。別の Markdown ノートの見出しを指すリンクなら、そのノートがその見出しの位置で開きます。
- **ウィキリンク**：`[[ノート]]`、`[[ノート#見出し]]`、`[[ノート|表示テキスト]]` はノートの保管庫のどこからでも探します。保管庫とは、ノートから上にたどって最初に `.obsidian` を含むフォルダーで、なければノート自身のフォルダーです。同じ名前のファイルが複数あるときは、ノートに近いほうを開きます。
- **補完**：`[[` と入力すると保管庫のノート一覧が出ます。選ぶと `[[名前]]` として書き込まれます。
- **画像**：`![[画像.png]]` は文字の下に画像を表示し、`![[画像.png|300]]` で幅を指定します。表示されるのは保管庫内の 20 MB 以下の画像だけです。
- **変わらないもの**：ウィキリンクはファイル上ではただの文字のままなので、保存で書き換わることはありません。Web のリンクはブラウザーで開きます。ネットワークパス（`\\server\share`）、ソース表示のリンク、AI は何も開きません。

## 書き出し

ファイルメニューで、いずれもローカルで、いずれも保存先を確認します。

- **Word として書き出す…** と **PDF として書き出す…** は、実際の .docx や .pdf を書き出します。
- **ODT として書き出す…** は、Word への書き出しと同じ変換で .odt（OpenDocument テキスト）を書き出します。変換で変わる点や失われる点があれば、一覧を示して確認してから書き出します。
- **画像としてエクスポート…** は、選んだフォルダーの中に 1 ページにつき 1 枚の PNG を書き出します。
- **Docs 文書に変換して開く** は .docx に変換し、このアプリ内の組み込み Docs タブで開きます。クラウド上の何かへ引き渡すものではなく、変換されたコピーは約 1 週間後に消去されるキャッシュフォルダーに置かれます。

## ソースビュー

ツールバーには **ソース** の切り替えがあります（アプリと同じ言語で表示）。これをオンにすると、エディターがそのままの Markdown に置き換わります。保存が書き込むのとまったく同じテキストで、見栄えを整えることもなく、裏で正規化されることもありません。

- **編集はバイト単位で忠実です。** ソースビューから保存しても、エディターから保存しても同じバイト列が書き出されます。BOM、CRLF、末尾の改行の有無はそのまま残ります。
- **同じ文書です。** 自由に往復させてください。ソースはエディター自身のテキストであり、統合しなければならないコピーではありません。
- **ソースビューを開いている間は、書式ツールバーを使えません。** そのボタンの多くは、レンダリングされた側でのみ意味を持つエディター用の構造を挿入するからです。ビューを閉じると戻ります。
- **.txt と .json** はソースビューで直接ここに開きます：表示するものがないため、ソースこそがドキュメント本体です。
