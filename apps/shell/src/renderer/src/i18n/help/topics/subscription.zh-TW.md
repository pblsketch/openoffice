# 訂閱連線

GenOffice 的 AI 是靠你手上已有的訂閱來運作的：Claude 訂閱（Anthropic）或 ChatGPT 方案（OpenAI）皆可。ChatGPT 直接在 GenOffice 中連線；如果你已經在這台電腦上使用 OpenAI 的 Codex 程式，也可以改為透過 Codex 連線。你不需要 API 金鑰，GenOffice 本身也沒有需要另外註冊的帳戶。

## 運作方式

- AI 並不是內建在 GenOffice 裡。Claude 會經過這台電腦上安裝的 **Claude Code** 程式：GenOffice 向這個程式要答案，而這個程式是用你自己的帳戶登入的，所以每一次要求都會算在你自己方案的用量裡。
- ChatGPT 由 GenOffice 自己連線，不需要任何程式。在瀏覽器中開啟的 OpenAI ChatGPT 登入頁面上登入，並允許此應用程式使用你的 ChatGPT 方案。要求會從這台電腦直接送到 OpenAI，用量則從該 ChatGPT 方案中扣除。
- **Codex** 是 OpenAI 的程式。透過 Codex 連線 ChatGPT 時，GenOffice 會向 Codex 程式要答案，方式和 Claude Code 相同。
- GenOffice 在應用程式內沒有自己的登入畫面。登入是在該公司自己的程式裡完成，或是在瀏覽器中開啟的該公司網頁上完成。GenOffice 不會讀取或儲存 Claude Code 和 Codex 的登入資訊。GenOffice 唯一保存的登入，是你直接連線 ChatGPT 時 OpenAI 發給此應用程式的那一個，它只會留在這台電腦上（在 Windows 上會加密保存）。GenOffice 不會看到你的 ChatGPT 密碼。

## 開始之前

以下兩項只要有一項就行，兩項都有也沒問題。

- Claude 訂閱（需要 Pro 或 Max 方案，免費的 Claude 帳戶無法連線），以及在這台電腦上已安裝並登入的 Claude Code 程式。
- ChatGPT 方案。直接連線時不需要安裝任何程式。免費方案只能少量使用。如果你已經在這台電腦上使用 Codex 程式，也可以改為透過 Codex 連線。

如果 Claude Code 或 Codex 還沒安裝，或是還沒登入，下一節的按鈕可以幫你處理。

## 連結

1. 按一下首頁左下角的那一列開啟**設定**，然後選擇 **AI**。**訂閱連線**底下依序有 Claude、ChatGPT 和 Codex 三張卡片。使用 ChatGPT 方案的話，請在 ChatGPT 卡片上連結。Codex 卡片是給在這台電腦上使用 Codex 程式的人準備的。
2. 看看卡片上寫的狀態，再按卡片上的按鈕。各種狀態的意思請見下表。
3. 回到 GenOffice 視窗。卡片會自動重新檢查；按**重新檢查**則會立刻檢查。

第一次啟動時歡迎畫面的第二步，以及尚未連結任何 AI 時的 AI 面板，會先問「你現在在用哪種 AI？」。選擇 Claude 付費訂閱、ChatGPT 或兩者都還沒有之後，只會顯示這條路徑的步驟和對應的一張卡片。Claude 的步驟是安裝程式 → 登入 → 連線完成；ChatGPT 的步驟是登入 → 連線完成。在 ChatGPT 路徑底下，按**這台電腦上已在使用 Codex 程式？透過 Codex 連線**會切換到 Codex 路徑（安裝程式 → 登入 → 連線完成），在該路徑上按**不用 Codex，直接在應用程式中連線**則會回到直接連線。如果 Codex 已經連線，一開始就會顯示 Codex 路徑。按**選擇其他方式**可以重新選擇，你也可以全部略過，之後再連結。如果還是連不上，按**複製求助資訊**，把複製的內容傳給協助你的人。其中不包含帳戶和檔案路徑。

ChatGPT 卡片不經過任何程式，所以永遠不會顯示**尚未安裝**或**已登入，但不是訂閱方式**。顯示**尚未登入**時，按**使用 ChatGPT 繼續**：瀏覽器會開啟 OpenAI 的 ChatGPT 登入頁面。登入並允許此應用程式使用你的 ChatGPT 方案後，卡片會自動變成**已連線**。如果你沒有允許，或是 10 分鐘內沒有完成，卡片會提示登入沒有完成；再按一次按鈕會重新開始。沒有登入視窗，也不需要貼上代碼。登入過程中，按**取消登入**可以停止。

應用程式啟動時、開啟設定時，以及開始安裝或登入後回到視窗時，都會檢查連線狀態。

如果 Claude 或 Codex 卡片提示登入沒有完成，請選擇 **開啟登入視窗**。瀏覽器顯示的代碼必須貼到該視窗中；先前顯示的代碼已失效。

如果瀏覽器頁面或登入視窗顯示 `3p_delegated_access_policy_denied`，可能是 Claude 帳號上的某項政策阻擋了這次登入。如果再試一次仍然如此，請詢問管理該帳號的人，或試試用其他帳號能否登入。

## 沒有訂閱：免費 AI

沒有 Claude 或 ChatGPT 訂閱嗎？可以在設定 ▸ AI 的**免費使用**改為連結一個免費 AI。在第一次啟動時歡迎畫面的第二步選擇**兩者都還沒有**，會顯示同樣的卡片；尚未連結任何 AI 時在 AI 面板選擇它，會提供**連結免費 AI**。

- **OpenRouter**：按**在瀏覽器中連接**。瀏覽器會開啟 OpenRouter；註冊或登入後，允許存取。瀏覽器顯示已連結後，關閉那個分頁再回來即可。不必複製金鑰，卡片上會顯示今天還剩幾次免費要求。
- **Google Gemini**：按**取得金鑰**，在 Google AI Studio 建立一個金鑰，貼到卡片中，再按**連接**。僅限 18 歲以上的人使用。在已啟用帳單的 Google 專案中建立的金鑰可能會被收費。
- 連結後，這個 AI 就會成為**使用的 AI**。兩個都連結時，可以用卡片上的**使用此 AI**在兩者之間切換。**中斷連線**會把金鑰從 GenOffice 移除。
- 免費模型比訂閱模型弱，每天的要求次數也有限。修改一次文件可能會用掉好幾次要求。今天的額度用完時，AI 面板會告訴你，並說明什麼時候可以再用。
- 免費使用期間，你傳送的內容可能會被用來改進該公司的 AI。含有個人資料的文件請特別留意。

## 依用量付費的登入

顯示**已登入，但不是訂閱方式**的卡片會附上一則警告：「這不是訂閱，而是依實際用量收費。」

- 在你按下**仍要使用**之前，GenOffice 不會使用這個登入。按下之後，每一次要求都會向該帳戶計費。
- 即使如此，它也不會被自動選用。你得自己在**使用的 AI**裡選它，它在那裡會標示為**付費**。
- 你的許可只針對這個程式記住。程式登出或登入方式改變後，許可就會清除。
- 想改用訂閱，請用訂閱帳戶重新登入該程式，再按**重新檢查**。

## 更換帳戶或登出

已登入的卡片會顯示目前登入的帳戶。Claude 和 Codex 卡片在程式有回報方案名稱時，也會顯示方案名稱。另外還會多出兩個按鈕。

- **使用其他帳戶登入**會重新啟動程式自己的登入流程。請在開啟的視窗中用另一個帳戶完成登入。
- **登出**會執行程式自己的登出指令。之後卡片會顯示**尚未登入**。
- 在 Claude 和 Codex 卡片上，這兩個動作都會套用到這台電腦上的整個程式，而不只是 GenOffice。如果你也在終端機中使用 Claude Code 或 Codex，那裡也會一併登出或換成另一個帳戶。因此 GenOffice 會先請你確認。
- Claude 和 Codex 卡片上還有**不在本應用程式中使用**。它會保留該程式及其登入，只讓 GenOffice 不再使用它：不檢查狀態，不傳送要求，**自動**也會略過它。在終端機中使用該程式不受影響。之後卡片會顯示**已在本應用程式中關閉**，按**重新使用**即可恢復。由於 GenOffice 之外沒有任何變化，兩者都不需要確認。
- ChatGPT 卡片則不同。按**登出**時會請你確認「將中斷本應用程式的 ChatGPT 連線」；確認後，GenOffice 會請 OpenAI 結束此應用程式的連線，並刪除它保存在這台電腦上的登入資訊。按**使用其他帳戶登入**會直接在瀏覽器中開啟登入頁面，不會先詢問。兩者都不會影響這台電腦上的其他程式，包括 Codex。
- 已連線的 ChatGPT 卡片會顯示「此應用程式中的 AI 在你的 ChatGPT 方案內執行」，並附有**管理用量**連結。它會開啟 ChatGPT 設定中的用量頁面，你可以在那裡查看此應用程式用了多少，並單獨為此應用程式設定上限。
- 帳戶和這兩個按鈕只會出現在設定 ▸ AI 的卡片上。GenOffice 只是顯示帳戶，不會把它儲存在任何地方。

## 用的是哪個 AI

設定 ▸ AI 底下的**使用的 AI**一開始是**自動**。自動會依下列順序決定：

1. Claude 卡片顯示「已連線」時，使用 Claude。
2. 否則，ChatGPT 卡片顯示「已連線」時，使用 ChatGPT。
3. 否則，Codex 卡片顯示「已連線」時，使用 Codex。
4. 都不是，就表示尚未連結任何 AI，這時 AI 面板顯示的是連結指引，而不是錯誤訊息。

自動絕不會選用任何要額外花錢的方式：不選 API 金鑰，也不選依用量付費的登入。這些只有在你自己選用的期間才會使用。

你也可以自己指定一個 AI：在同一個位置選，或是在 AI 面板底部的模型清單裡選。如果你選的那個無法使用了，GenOffice 不會悄悄換成另一個，而是告訴你發生了什麼事，並顯示重新連結的方法。

模型清單顯示的是程式自己回報的模型（ChatGPT 則是 OpenAI 告知你的方案可以使用的模型；在你自己選擇之前，會使用其中第一個）：每個模型都有名稱，旁邊是確切的模型 ID，**預設模型**則會寫明它目前對應的模型。AI 面板底部的選擇標籤和**使用的 AI**也會顯示這個模型。讀取清單不會向 AI 提出任何要求，所以不會計入方案用量。如果程式版本太舊、無法回報模型，就會改為顯示應用程式內建的簡短清單。

凡是可以選擇 Codex 的地方，都會附上一行說明：「在應用程式中使用 Codex 訂閱並非 OpenAI 官方建議的方式。」請在了解這一點之後再決定。

## 要求中途停止時

方案額度用完、登入失效，或是程式已經不在了，要求就會停止。GenOffice 不會自行切換到另一個 AI。

- 回覆停下的地方會顯示原因。如果是額度用完，而程式有回報重設時間，也會一併顯示。
- 直接連線的 ChatGPT 會在方案額度用完，或是你在 ChatGPT 設定中為此應用程式設定的上限用完時停止。不會顯示重設時間。如果你在 ChatGPT 設定中中斷了此應用程式的連線，卡片會變成**尚未登入**；請重新登入。
- 如果你的另一個訂閱已經連線，就會出現**改用 … 繼續**按鈕，例如**改用 ChatGPT 繼續**或**改用 Codex 繼續**。按下後，那個訂閱會成為使用的 AI（模型清單也會顯示這項變更），並重新執行這次要求。
- 如果另外只剩下一個你已允許的依用量付費登入，同一個按鈕會附上費用提醒。
- 絕不會出現把你切換到 API 金鑰的按鈕。

## 用量提示

某項額度用到 80% 以上之後，AI 面板會顯示一行類似「已用 85% · 下午3:00 重設」的提示。Claude 會回報 5 小時額度和 7 天額度；Codex 有回報這些資訊時，也會以同樣的方式顯示。低於 80%，或是程式沒有回報任何資訊時，就不會顯示這一行。直接連線的 ChatGPT 不會顯示這一行；它用了多少，請透過 ChatGPT 卡片上的**管理用量**查看。

## 傳送了什麼、傳到哪裡

第一次可以使用訂閱時，GenOffice 會顯示一次說明。想再看一次，請到 設定 ▸ AI ▸ **首次連線說明**，按**再次檢視**。說明裡講了三件事：

- 文件內容和對話會以你本人的帳戶傳送給 Anthropic 或 OpenAI。
- 這些內容是否用於 AI 訓練，取決於你在該公司帳戶中的設定，而不是由 GenOffice 決定。
- GenOffice 會關閉 Codex 的對話記錄儲存，但 Codex 仍可能在這台電腦上保留自己的診斷記錄檔。

透過直接連線的 ChatGPT 送出的要求不會經過 Codex 程式，而是從這台電腦直接送到 OpenAI。

用**把選取的內容對 AI 隱藏**藏起來的內容，不論使用哪個 AI 都不會傳送。

## 值得知道的事

- **速度。** 透過 Claude Code 或 Codex 得到的回覆，會比透過 API 金鑰的晚幾秒才開始，因為得先等程式啟動。直接連線的 ChatGPT 不需要啟動任何程式。
- **ChatGPT 免費方案。** 會顯示為「已連線」，但額度很小，所以要求會更早停止。它也不會顯示用量提示。
- **產生圖片。** 在這個版本裡，不論哪一種方案，訂閱都無法產生圖片。這需要生圖服務商的金鑰，請見 [AI 模型與設定](help://ai-models)。
- **代理伺服器。** Claude Code 和 Codex 不會從 GenOffice 取得代理伺服器設定。它們使用這台電腦上設定的代理伺服器，例如 `HTTPS_PROXY` 環境變數，就和你在終端機裡執行它們時一樣。如果在終端機裡連不上，在這裡也一樣連不上。
- **命令與其他程式。** 從 `ieumoffice` 命令或已連接的程式開發代理送來的要求，除非你允許，否則不會使用你的訂閱。即使允許，用的也是 Claude Code 或 Codex，絕不會用直接連線的 ChatGPT。請見[連接程式設計助手](help://mcp)。
- **代理程式模式。** [代理程式模式](help://agent-mode)執行的是這台電腦上的 Claude Code 或 Codex。直接連線的 ChatGPT 無法執行代理程式。
