# การติดตั้ง GenOffice

ทุกเวอร์ชันถูกเผยแพร่ไว้ที่ [หน้าเผยแพร่ (Releases)](https://github.com/pblsketch/openoffice/releases/latest) ของโปรเจกต์บน GitHub รุ่นสำหรับ Windows เผยแพร่พร้อมกับรุ่นสำหรับ Mac และ Linux ที่ออกเป็นเบต้า ผู้พัฒนาไม่สามารถทดสอบรุ่น Mac และ Linux ได้โดยตรง แต่ยืนยันผ่านรายงานจากผู้ใช้

## เลือกไฟล์ให้ตรงกับเครื่องของคุณ

| แพลตฟอร์ม                               | ข้อกำหนด                             | ไฟล์                              |
| --------------------------------------- | ------------------------------------ | --------------------------------- |
| **Windows**                             | Windows 10 ขึ้นไป, Intel/AMD 64 บิต  | `GenOffice-Setup-<version>.exe`   |
| **Mac (เบต้า)**, Apple Silicon          | macOS 12 ขึ้นไป, ชิป M1 หรือใหม่กว่า | `GenOffice-<version>-arm64.dmg`   |
| **Mac (เบต้า)**, Intel                  | macOS 12 ขึ้นไป, โปรเซสเซอร์ Intel   | `GenOffice-<version>-x64.dmg`     |
| **Linux (เบต้า)**, ทุกดิสทริบิวชัน      | 64 บิต (x86_64)                      | `GenOffice-<version>.AppImage`    |
| **Linux (เบต้า)**, ตระกูล Ubuntu/Debian | 64 บิต (x86_64)                      | `ieumoffice_<version>_amd64.deb`  |
| **Linux (เบต้า)**, Fedora/RHEL/openSUSE | 64 บิต (x86_64)                      | `ieumoffice-<version>.x86_64.rpm` |

หากต้องการดูว่าคุณใช้ Mac รุ่นไหน ให้เปิดเมนู Apple ▸ **เกี่ยวกับ Mac เครื่องนี้** หาก "ชิป" ระบุว่า Apple M… ให้เลือกไฟล์ที่ลงท้ายด้วย `-arm64.dmg` หาก "โปรเซสเซอร์" ระบุว่า Intel … ให้เลือกไฟล์ที่ลงท้ายด้วย `-x64.dmg` ไฟล์อื่น ๆ ในหน้าเผยแพร่ (`.zip`, `.yml`, `.blockmap`) เป็นไฟล์ที่แอปใช้อัปเดตตัวเอง คุณไม่ต้องดาวน์โหลดไฟล์เหล่านั้น เวอร์ชันเก่ากว่ายังอยู่ในหน้าเผยแพร่

## บน Windows

1. ดาวน์โหลด `GenOffice-Setup-<version>.exe` จากหน้าเผยแพร่
2. เปิดไฟล์นั้น ตัวติดตั้งไม่ได้ลงลายเซ็นโค้ด Windows จึงอาจแสดงหน้าต่างสีน้ำเงิน "Windows ปกป้องพีซีของคุณ" ขึ้นมาก่อน ให้เลือก **ข้อมูลเพิ่มเติม** แล้วเลือก **เรียกใช้ต่อไป** ข้อความที่เห็นจริงอาจต่างกันไปตามเวอร์ชันของ Windows
3. ทำตามขั้นตอนของตัวติดตั้งไปจนเสร็จ

ตัวติดตั้งจะวาง GenOffice ไว้ในเมนู Start และลงทะเบียน `.docx`, `.xlsx`, `.pptx`, `.pdf` และไฟล์อื่น ๆ ดังนั้นดับเบิลคลิกที่ไฟล์ก็จะเปิดขึ้นมา

เนื่องจากตัวติดตั้งไม่ได้ลงลายเซ็น ให้เรียกใช้เฉพาะไฟล์ที่ดาวน์โหลดจากหน้าเผยแพร่ข้างต้นเท่านั้น

## เมื่อ Windows บล็อกการดาวน์โหลดหรือการติดตั้ง

### Edge แจ้งว่าไฟล์ "ไม่ค่อยมีคนดาวน์โหลด"

Microsoft Defender SmartScreen จะเตือนแบบนี้กับไฟล์ที่ยังไม่ค่อยเห็นคนดาวน์โหลด คำแนะนำของ Microsoft ในการเก็บไฟล์ไว้คือ

1. เปิดรายการดาวน์โหลดของ Edge (**Ctrl+J**) กด **…** ข้างไฟล์ แล้วเลือก **Keep**
2. ในหน้าต่างที่เปิดขึ้น ให้กด **Show more** แล้วกด **Keep anyway** ไฟล์จะถูกเก็บไว้ในโฟลเดอร์ดาวน์โหลดของคุณ

หน้าต่างนั้นยังมีปุ่มสำหรับรายงานว่าไฟล์ปลอดภัยด้วย ปุ่มนั้นเพียงเปิดหน้ารายงานของ Microsoft (`feedback.smartscreen.microsoft.com`) และไม่ได้เก็บไฟล์ไว้ ให้ปิดหน้านั้นแล้วกด **Show more** ในหน้าต่างแทน

หากหน้าต่างไม่มี **Show more** หรือไม่มี **Keep anyway**:

- บนพีซีที่โรงเรียนหรือบริษัทดูแล ผู้ดูแลระบบสามารถปิดไม่ให้ข้ามคำเตือนเหล่านี้ได้ (นโยบายของ Edge) เมื่อเป็นเช่นนั้น จะไม่มีใครบนพีซีเครื่องนั้นเก็บไฟล์ไว้ได้ ให้ขอผู้ดูแลระบบติดตั้งให้หรืออนุญาตไฟล์นั้น
- การดาวน์โหลดจากหน้าเผยแพร่ด้วยเบราว์เซอร์อื่นจะได้ไฟล์เดียวกัน
- ถ้าทั้งสองวิธีไม่ได้ผลและเป็นพีซีของคุณเอง คู่มือแก้ปัญหาการดาวน์โหลดของ Microsoft อนุญาตให้ปิด Microsoft Defender SmartScreen ชั่วคราวเป็นทางเลือกสุดท้าย ใน Edge ให้เปิด **การตั้งค่าและอื่นๆ (…) ▸ การตั้งค่า ▸ ความเป็นส่วนตัว การค้นหา และบริการ ▸ ความปลอดภัย** ปิด **Microsoft Defender SmartScreen** ดาวน์โหลดไฟล์อีกครั้ง แล้วเปิดกลับทันที ระหว่างที่ปิดอยู่ Edge จะไม่เตือนทั้งเรื่องการดาวน์โหลดและเว็บไซต์อันตราย เช่น หน้าฟิชชิง

### หน้าต่าง "Windows ปกป้องพีซีของคุณ" ปรากฏขึ้น

Microsoft Defender SmartScreen จะแสดงหน้าต่างนี้ครั้งแรกที่พบตัวติดตั้งที่ไม่ได้ลงลายเซ็น กด **ข้อมูลเพิ่มเติม** แล้วปุ่ม **เรียกใช้ต่อไป** จะปรากฏขึ้น บนพีซีที่โรงเรียนหรือบริษัทดูแล การตั้งค่าของผู้ดูแลระบบอาจซ่อนปุ่มนั้นไว้ ให้สอบถามผู้ดูแลระบบ

### Smart App Control บล็อกไว้

เมื่อเปิด Smart App Control ของ Windows 11 อยู่ ระบบจะหยุดตัวติดตั้งที่ไม่ได้ลงลายเซ็น และไม่มีเส้นทาง **ข้อมูลเพิ่มเติม** ให้เลือก Microsoft ระบุว่าไม่มีวิธีอนุญาตเฉพาะแอปเดียว ตัวเลือกเดียวคือปิด Smart App Control ที่ **Windows Security ▸ App & browser control ▸ Smart App Control settings** การปิดจะเอาการป้องกันนี้ออกจากแอปอื่นทั้งหมดด้วย ใน Windows ที่อัปเดตล่าสุดสามารถเปิดกลับได้โดยไม่ต้องติดตั้ง Windows ใหม่

## บน Mac (เบต้า)

ต้องใช้ macOS 12 (Monterey) ขึ้นไป รุ่น Mac ไม่มีลายเซ็นนักพัฒนาของ Apple ดังนั้นเมื่อเปิดครั้งแรก macOS จะแจ้งว่าไม่สามารถตรวจสอบได้ว่าแอปปลอดจากมัลแวร์ และจะไม่เปิดแอป คุณต้องอนุญาตหนึ่งครั้งตามด้านล่าง

1. เปิดไฟล์ dmg แล้วลาก `GenOffice.app` ไปไว้ในโฟลเดอร์ **แอปพลิเคชัน**
2. เปิด GenOffice จากโฟลเดอร์แอปพลิเคชัน เมื่อคำเตือนปรากฏ ให้กด **เสร็จสิ้น**
3. เปิด **การตั้งค่าระบบ ▸ ความเป็นส่วนตัวและความปลอดภัย** ใกล้ด้านล่าง ข้างบรรทัดที่บอกว่า GenOffice ถูกบล็อก ให้กด **Open Anyway** แล้วป้อนรหัสผ่าน Mac ของคุณ ปุ่มนี้จะแสดงอยู่ประมาณหนึ่งชั่วโมงหลังจากที่คุณพยายามเปิดแอป
4. ในหน้าต่างที่ปรากฏอีกครั้ง ให้กด **เปิด** จากนั้นจะเปิดได้โดยไม่มีคำเตือน

บน macOS 12 ตำแหน่งนี้คือ **การตั้งค่าระบบ ▸ ความปลอดภัยและความเป็นส่วนตัว ▸ ทั่วไป** และปุ่มที่นั่นคือ **Open Anyway**

หาก macOS แจ้งว่าแอป "is damaged and can't be opened" อย่าย้ายไปที่ถังขยะ ให้รันบรรทัดด้านล่างใน Terminal แล้วเปิดแอปอีกครั้งและอนุญาตตามด้านบน คำสั่งนี้จะลบเครื่องหมายที่ macOS ติดไว้กับไฟล์ที่ดาวน์โหลดจากอินเทอร์เน็ต

```sh
xattr -dr com.apple.quarantine /Applications/GenOffice.app
```

หาก macOS แจ้งว่าแอปไม่รองรับบน Mac เครื่องนี้ ให้ตรวจสองอย่าง:

- Mac ที่ใช้ Intel รันไฟล์สำหรับ Apple Silicon (`-arm64.dmg`) ไม่ได้ ให้ดู "โปรเซสเซอร์" ใน **เกี่ยวกับ Mac เครื่องนี้** ลบแอปที่ติดตั้งไว้ แล้วติดตั้งไฟล์ `-x64.dmg` แทน
- macOS 11 หรือเก่ากว่ารัน GenOffice ไม่ได้ **เกี่ยวกับ Mac เครื่องนี้** ก็แสดงเวอร์ชัน macOS ด้วย

นอกจากนี้บน Mac:

- การ์ดการเชื่อมต่อ AI ไม่มีปุ่มติดตั้ง ให้ทำตามลิงก์คู่มือติดตั้งอย่างเป็นทางการบนการ์ดเพื่อติดตั้ง Claude Code หรือ Codex แอป Claude บนเดสก์ท็อปไม่ใช่ Claude Code จึงต้องติดตั้ง Claude Code แยกต่างหากแม้จะมีแอปบนเดสก์ท็อปอยู่แล้ว
- การลงชื่อเข้าใช้จะเสร็จสิ้นในเบราว์เซอร์ หากเบราว์เซอร์ขอให้วางรหัส ให้รัน `claude auth login` หรือ `codex login` ใน Terminal ด้วยตัวเอง ดู [การเชื่อมต่อการสมัครสมาชิก](help://subscription)

## บน Linux (เบต้า)

- **AppImage**: ทำให้ไฟล์รันได้ (`chmod +x GenOffice-<version>.AppImage`) แล้วรันไฟล์นั้น ไม่มีขั้นตอนติดตั้ง
- **deb**: ติดตั้งด้วย `sudo apt install ./ieumoffice_<version>_amd64.deb`
- **rpm**: ติดตั้งด้วย `sudo dnf install ./ieumoffice-<version>.x86_64.rpm` บน openSUSE ให้ใช้ `sudo zypper install ./ieumoffice-<version>.x86_64.rpm`

แพ็กเกจ deb และ rpm ติดตั้งไว้ที่ `/opt/GenOffice` และลิงก์คำสั่งเทอร์มินัล `/usr/bin/ieumoffice` เช่นเดียวกับบน Mac การ์ดการเชื่อมต่อ AI ไม่มีปุ่มติดตั้ง และเมื่อการลงชื่อเข้าใช้ขอรหัส ให้รัน `claude auth login` หรือ `codex login` ในเทอร์มินัลด้วยตัวเอง

## การอัปเดต

- GenOffice ตรวจหาเวอร์ชันใหม่จากหน้าเผยแพร่บน GitHub หน้าเดียวกัน เมื่อมีเวอร์ชันใหม่เผยแพร่ **การตั้งค่า ▸ เกี่ยวกับ** จะเสนอให้อัปเดต: กด **อัปเดตเป็น …** รอให้ดาวน์โหลดเสร็จ แล้วกด **รีสตาร์ตและติดตั้ง** บน Windows จะมีหน้าต่างแสดงความคืบหน้าการติดตั้ง เมื่อเสร็จแล้ว GenOffice จะเปิดขึ้นอีกครั้งพร้อมเอกสารที่เปิดไว้ บน Mac แอปจะปิด เปลี่ยนเป็นเวอร์ชันใหม่ แล้วเปิดขึ้นอีกครั้งพร้อมเอกสารที่เปิดไว้ ใช้ได้กับแอปที่อยู่ในโฟลเดอร์แอปพลิเคชัน ส่วนแอปที่เปิดจากดิสก์อิมเมจโดยตรงจะแสดงหน้าดาวน์โหลดแทน การอัปเดตจะติดตั้งเฉพาะเมื่อคุณกดปุ่มนั้นเท่านั้น ไม่ใช่เมื่อปิดแอปตามปกติ
- บน Linux มีเฉพาะ AppImage ที่อัปเดตตัวเอง หากติดตั้งด้วย deb หรือ rpm แอปจะแจ้งเวอร์ชันใหม่และเปิดหน้าดาวน์โหลด ให้ติดตั้งไฟล์ใหม่ด้วยวิธีเดียวกัน
- **เมนู (☰) ▸ ตรวจหาการอัปเดต** จะตรวจสอบทุกครั้งที่คุณสั่ง บน Mac ให้ใช้ **วิธีใช้ ▸ ตรวจหาการอัปเดต**
- เมื่อการตรวจสอบล้มเหลว — ไม่มีเครือข่าย หรือยังไม่มีอะไรเผยแพร่ — จะไม่มีอะไรเกิดขึ้น และแอปยังใช้งานได้เหมือนเดิม
- **ช่องทางอัปเดต** ซึ่งอยู่ใต้ การตั้งค่า ▸ เกี่ยวกับ เช่นกัน มีให้เลือกระหว่างเสถียรกับเบต้า การเปลี่ยนมีผลทันทีและจะตรวจหาอัปเดต แต่จะไม่ถอยกลับการติดตั้งแบบเบต้าไปเป็นเสถียร
- ไฟล์อัปเดตก็ไม่ได้ลงลายเซ็นโค้ดเช่นกัน ก่อนติดตั้ง แอปจะตรวจไฟล์ที่ดาวน์โหลดมาเทียบกับ checksum ที่เผยแพร่พร้อมกับรุ่นนั้น
- หากกด **รีสตาร์ตและติดตั้ง** แล้วแอปปิดไป แต่เวอร์ชันใหม่ไม่ได้ติดตั้ง เมื่อเปิดแอปครั้งถัดไปจะแจ้งให้ทราบและเสนอการอัปเดตอีกครั้ง ครั้งนี้ตัวติดตั้งจะเปิดในหน้าต่างของตัวเอง คุณจึงดูความคืบหน้าและตอบคำขอสิทธิ์ผู้ดูแลระบบได้ หากยังไม่สำเร็จ หน้าต่างอัปเดตจะพาไปยังหน้าดาวน์โหลด การติดตั้งด้วยไฟล์จากที่นั่นยังคงเก็บการตั้งค่าและเอกสารของคุณไว้ ขั้นตอนการอัปเดตถูกบันทึกไว้ใน `update-log.txt` ในโฟลเดอร์ข้อมูลของแอป (พิมพ์ `%APPDATA%\GenOffice` ในแถบที่อยู่ของ File Explorer เพื่อเปิด) โปรดแนบไฟล์นี้เมื่อแจ้งปัญหา

## เวอร์ชันที่คุณกำลังใช้

**การตั้งค่า ▸ เกี่ยวกับ** คือที่ที่แอปรายงานว่าคุณมีเวอร์ชันไหน ติดตามช่องทางอัปเดตไหน และโปรเจกต์นี้อยู่ที่ไหน รวมถึงระบุชื่อโปรเจกต์โอเพนซอร์สที่แอปนี้พัฒนาต่อยอดมา

## บรรทัดคำสั่งมาให้ด้วย

ทุกการติดตั้งมีคำสั่ง `ieumoffice` ที่คุยกับเอนจินตัวเดียวกับที่หน้าต่างใช้ ทั้งสองฝ่ายจึงไม่มีวันขัดแย้งกันเรื่องไฟล์ `ieumoffice install-cli` จะนำคำสั่งนี้ไปไว้ใน `PATH` ของคุณ ดู [บรรทัดคำสั่งและเอเจนต์](help://cli) ว่ามันทำอะไรได้บ้าง
