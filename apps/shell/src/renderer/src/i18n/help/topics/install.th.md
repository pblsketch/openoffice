# การติดตั้ง GenOffice

ทุกเวอร์ชันถูกเผยแพร่ไว้ที่ [หน้าเผยแพร่ (Releases)](https://github.com/pblsketch/openoffice/releases/latest) ของโปรเจกต์บน GitHub เวอร์ชันนี้ออกสำหรับ Windows

## เลือกไฟล์ให้ตรงกับเครื่องของคุณ

| แพลตฟอร์ม   | ข้อกำหนด                            | ไฟล์                            |
| ----------- | ----------------------------------- | ------------------------------- |
| **Windows** | Windows 10 ขึ้นไป, Intel/AMD 64 บิต | `GenOffice-Setup-<version>.exe` |

เวอร์ชันเก่ากว่ายังอยู่ในหน้าเผยแพร่

## บน Windows

1. ดาวน์โหลด `GenOffice-Setup-<version>.exe` จากหน้าเผยแพร่
2. เปิดไฟล์นั้น ตัวติดตั้งไม่ได้ลงลายเซ็นโค้ด Windows จึงอาจแสดงหน้าต่างสีน้ำเงิน "Windows ปกป้องพีซีของคุณ" ขึ้นมาก่อน ให้เลือก **ข้อมูลเพิ่มเติม** แล้วเลือก **เรียกใช้ต่อไป** ข้อความที่เห็นจริงอาจต่างกันไปตามเวอร์ชันของ Windows
3. ทำตามขั้นตอนของตัวติดตั้งไปจนเสร็จ

ตัวติดตั้งจะวาง GenOffice ไว้ในเมนู Start และลงทะเบียน `.docx`, `.xlsx`, `.pptx`, `.pdf` และไฟล์อื่น ๆ ดังนั้นดับเบิลคลิกที่ไฟล์ก็จะเปิดขึ้นมา

เนื่องจากตัวติดตั้งไม่ได้ลงลายเซ็น ให้เรียกใช้เฉพาะไฟล์ที่ดาวน์โหลดจากหน้าเผยแพร่ข้างต้นเท่านั้น

## การอัปเดต

- GenOffice ตรวจหาเวอร์ชันใหม่จากหน้าเผยแพร่บน GitHub หน้าเดียวกัน เมื่อมีเวอร์ชันใหม่เผยแพร่ **การตั้งค่า ▸ เกี่ยวกับ** จะเสนอให้อัปเดต: กด **อัปเดตเป็น …** รอให้ดาวน์โหลดเสร็จ แล้วกด **รีสตาร์ตและติดตั้ง**
- **เมนู (☰) ▸ ตรวจหาการอัปเดต** จะตรวจสอบทุกครั้งที่คุณสั่ง บน Mac ให้ใช้ **วิธีใช้ ▸ ตรวจหาการอัปเดต**
- เมื่อการตรวจสอบล้มเหลว — ไม่มีเครือข่าย หรือยังไม่มีอะไรเผยแพร่ — จะไม่มีอะไรเกิดขึ้น และแอปยังใช้งานได้เหมือนเดิม
- **ช่องทางอัปเดต** ซึ่งอยู่ใต้ การตั้งค่า ▸ เกี่ยวกับ เช่นกัน มีให้เลือกระหว่างเสถียรกับเบต้า การเปลี่ยนมีผลทันทีและจะตรวจหาอัปเดต แต่จะไม่ถอยกลับการติดตั้งแบบเบต้าไปเป็นเสถียร
- ไฟล์อัปเดตก็ไม่ได้ลงลายเซ็นโค้ดเช่นกัน ก่อนติดตั้ง แอปจะตรวจไฟล์ที่ดาวน์โหลดมาเทียบกับ checksum ที่เผยแพร่พร้อมกับรุ่นนั้น

## เวอร์ชันที่คุณกำลังใช้

**การตั้งค่า ▸ เกี่ยวกับ** คือที่ที่แอปรายงานว่าคุณมีเวอร์ชันไหน ติดตามช่องทางอัปเดตไหน และโปรเจกต์นี้อยู่ที่ไหน รวมถึงระบุชื่อโปรเจกต์โอเพนซอร์สที่แอปนี้พัฒนาต่อยอดมา

## บรรทัดคำสั่งมาให้ด้วย

ทุกการติดตั้งมีคำสั่ง `ieumoffice` ที่คุยกับเอนจินตัวเดียวกับที่หน้าต่างใช้ ทั้งสองฝ่ายจึงไม่มีวันขัดแย้งกันเรื่องไฟล์ `ieumoffice install-cli` จะนำคำสั่งนี้ไปไว้ใน `PATH` ของคุณ ดู [บรรทัดคำสั่งและเอเจนต์](help://cli) ว่ามันทำอะไรได้บ้าง
