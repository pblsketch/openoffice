# การเชื่อมต่อเอเจนต์เขียนโค้ด

GenOffice สื่อสารด้วย Model Context Protocol เอเจนต์เขียนโค้ดจึงอ่าน เขียน และเรนเดอร์เอกสารของคุณด้วยเอนจินชุดเดียวกับที่แอปใช้ เอเจนต์ไม่ได้เดารูปแบบไฟล์มันได้สคีมาของแต่ละ op จากนิยามชุดเดียวกับที่ตัว executor ใช้ตรวจ

## ลงทะเบียนจากในแอป

ไปที่ **การตั้งค่า ▸ การเชื่อมต่อ** แผงนี้แบ่งเป็นสองข้าง คุณจะใช้ข้างเดียวหรือทั้งสองข้างก็ได้

**สกิล** จะมีหนึ่งแถวต่อเอเจนต์เขียนโค้ดหนึ่งตัวที่พบในเครื่องนี้ ได้แก่ Claude Code, Codex, Cursor, Gemini CLI, Copilot CLI, OpenCode และ Windsurf แต่ละแถวมี **ติดตั้ง**, **อัปเดต** และ **ถอนการติดตั้ง** พร้อมด้วย **ติดตั้งในโฟลเดอร์อื่น…**, **ดาวน์โหลดสกิล (zip)** และ **คัดลอกพาธ** หากผู้ช่วยของคุณไม่ได้อยู่ในรายการ ให้ชี้โฟลเดอร์ที่มันอ่าน `SKILL.md` ให้ GenOffice หรือบันทึกไฟล์ zip ไว้แล้วให้ผู้ช่วยติดตั้งเอง สกิลกับ MCP วางเคียงกันได้ ผู้ช่วยจะเลือกอย่างใดอย่างหนึ่ง และทั้งคู่ทำสิ่งเดียวกันพอดี

**MCP** มีสองเส้นทางให้เลือก ได้แก่ **ให้ผู้ช่วยเป็นผู้เริ่ม (แนะนำ)** ซึ่งคุณนำค่าตั้งที่แสดงอยู่ไปเพิ่มในไคลเอ็นต์ของคุณ แล้วผู้ช่วยจะสตาร์ตเซิร์ฟเวอร์เอง กับ **เซิร์ฟเวอร์ HTTP ในเครื่อง** ที่แอปเป็นคนรันให้ ไม่ว่าจะเลือกทางไหน ผู้ช่วยก็สุดท้ายไปคุยกับ GenOffice และคุณไม่ต้องพิมพ์คำสั่งเลย

## ลงทะเบียนจากบรรทัดคำสั่ง

ทำสิ่งเดียวกันนี้จากเทอร์มินัลได้ นี่คือเส้นทางขั้นสูง ที่ควรใช้เมื่อเอเจนต์ตั้งอยู่ในที่ที่แผงค้นหาไม่พบ

```sh
ieumoffice mcp install all
```

คำสั่งนี้จะหาเอเจนต์เขียนโค้ดที่อยู่บนเครื่องนี้ ได้แก่ Claude Code, Codex, Cursor, Gemini CLI, Copilot CLI, OpenCode และ Windsurf แล้วเขียนรายการเซิร์ฟเวอร์แบบ stdio ลงในค่าตั้งของแต่ละตัว ส่วนที่เหลือของไฟล์นั้นจะยังคงเดิม รายการนี้ชื่อ `ieumoffice` ถ้าลงทะเบียนเองสำหรับ Claude Code การลงทะเบียนแบบเดียวกันคือ `claude mcp add --transport stdio ieumoffice -- ieumoffice mcp`

```sh
ieumoffice mcp list             # where each agent stands
ieumoffice mcp install cursor    # just one
ieumoffice mcp uninstall cursor  # take it back out
```

ถ้าติดตั้งเอเจนต์ไว้ในตำแหน่งที่ไม่ปกติ ให้ใช้ `--dir <path>` ส่วน `--force` จะเขียนรายการที่มีอยู่แล้วทับ

`ieumoffice mcp --help` แสดงทุกอย่างที่เซิร์ฟเวอร์รับไว้ในหน้าจอเดียว ทั้งรูปแบบติดตั้ง ถอดออก และแสดงรายการ การให้บริการผ่าน HTTP และสวิตช์สคีมาสองตัว

## รันเองโดยไม่ต้องมีผู้ช่วย

สำหรับไคลเอ็นต์ที่อยู่คนละเครื่อง ให้เปิดเป็น HTTP แทน

```sh
ieumoffice mcp --http 8765 --token <secret>
```

`--host <addr>` กำหนดที่ที่เซิร์ฟเวอร์จะรับ และต้องส่งโทเคนเดียวกันนั้นให้ไคลเอ็นต์

ผ่าน HTTP ไฟล์ก็เดินทางมาได้ `PUT /files/<name>` ใช้อัปโหลดหนึ่งไฟล์ เครื่องมือทุกตัวรับ URL แบบ `http(s)` แทนพาธได้ ผลลัพธ์จะกลับมาเป็น URL สำหรับดาวน์โหลด และถ้าเล็กพอก็กลับมาเป็น resource ที่ฝังอยู่ในตัว ส่วน op, spec และ Markdown ส่งเป็นข้อความตรง ๆ ทั้งสองแบบ

## สิ่งที่เอเจนต์ได้

ทุกคำสั่งเป็นเครื่องมือหนึ่งชิ้น ตัวที่น่าสนใจคือ

- **`docs`, `sheet`, `slides`** — อ่านและแก้ไขไฟล์ผ่านช่องทางเขียนของตัวแอปเอง ทีละหนึ่ง **op** งานนำเสนอใหม่จะไล่ไปตาม `deck_start`, `deck_page`, `deck_build`
- **`render`** — ได้ PNG หนึ่งไฟล์ต่อหนึ่งหน้า จัดวางโดยตัวเรนเดอร์ของแอป เอเจนต์จึงมองเห็นสไลด์จริงแทนที่จะเดา
- **`pdf`** — ชั้นข้อความของ PDF ทีละหน้า โดยไม่ต้องเปิดโปรแกรม
- **`info`** — ข้อมูลเมตาดาต้าและสรุปโครงสร้าง มักเป็นคำสั่งแรกที่ถูกที่สุดเวลาเจอไฟล์ที่ยังไม่คุ้นเคย
- **`search`, `image`, `media`** — การค้นหาเว็บและค้นหาภาพ การสร้างภาพ และการวิเคราะห์สื่อ ผ่านสิ่งที่ตั้งค่าไว้ในแอป เอเจนต์จึงไม่ต้องมีคีย์ของตัวเอง หัวข้อถัดไปบอกว่าคำสั่งเหล่านี้ใช้อะไรได้บ้าง
- **`merge`** — เติมค่าในเทมเพลต `{{key}}`

## การค้นหา ภาพ และสื่อ: สิ่งที่เอเจนต์ใช้ได้

คำขอที่มาจากคำสั่ง `ieumoffice` หรือจากไคลเอ็นต์ MCP ไม่ใช่สิ่งที่คุณพิมพ์เองในแอป GenOffice จึงระมัดระวังกับคำขอเหล่านี้

- **การค้นหา** ใช้ได้เสมอและฟรีเป็นค่าเริ่มต้น คีย์ของผู้ให้บริการค้นหาจะถูกใช้เฉพาะเมื่อคุณเลือกไว้
- **การสร้างภาพ** ต้องใช้คีย์ของผู้ให้บริการสร้างภาพ ในเวอร์ชันนี้การสมัครสมาชิกสร้างภาพไม่ได้
- **การบรรยายภาพ** จะใช้ผู้ให้บริการแบบใช้คีย์เมื่อมีการตั้งค่าไว้ ส่วนการสมัครสมาชิก Claude หรือ Codex ของคุณ **จะไม่ถูกใช้ เว้นแต่คุณจะอนุญาต**
- **วิดีโอและเสียง** ต้องใช้ผู้ให้บริการแบบใช้คีย์ที่รองรับวิดีโอ

หากต้องการอนุญาตให้ใช้การสมัครสมาชิก ให้เปิด การตั้งค่า ▸ AI ▸ **ขั้นสูง** แล้วเปิด **อนุญาตให้คำขออัตโนมัติใช้การสมัครสมาชิก** จะมีคำเตือนขึ้นมาก่อน — "ไม่มีขีดจำกัดรายชั่วโมง โปรแกรมจึงส่งคำขอได้มากเท่าที่ต้องการ และคำขอเหล่านั้นอาจมีข้อความทั้งหมดของเอกสารและภาพของแต่ละหน้า ทั้งสองบริษัทไม่แนะนำให้โปรแกรมใช้การสมัครสมาชิกของคุณโดยอัตโนมัติ และบัญชีของคุณอาจถูกจำกัดการใช้งาน" — และสวิตช์จะเปิดก็ต่อเมื่อกด **เปิดต่อไป** แล้วเท่านั้น

แม้จะเปิดสวิตช์แล้ว:

- คำขอจะถูกจัดการทีละรายการ รายการอื่นต้องรอคิว
- ไม่มีขีดจำกัดรายชั่วโมง คิวนับทีละคำขอ ไม่ใช่ทีละงาน งานแปล PDF ที่ยาวจึงสลับกับคำขออื่นแทนที่จะขวางไว้ สวิตช์ที่เปิดไว้ภายใต้คำเตือนเดิมถูกปิดแล้ว ให้อ่านคำเตือนใหม่แล้วเปิดอีกครั้ง
- การเข้าสู่ระบบแบบจ่ายตามการใช้งานที่คุณอนุญาตด้วย **ใช้ต่อไป** ไม่นับเป็นการสมัครสมาชิกในที่นี้ แต่ถือเหมือนคีย์: ถ้าคุณเลือกไว้เป็น AI ที่ใช้ การบรรยายภาพจะผ่านการเข้าสู่ระบบนั้นไม่ว่าสวิตช์จะเปิดหรือปิด และแต่ละครั้งจะถูกคิดค่าบริการ

เมื่อสวิตช์ปิดอยู่และไม่ได้ตั้งค่าคีย์ไว้ เครื่องมือจะตอบว่าฟีเจอร์นั้นใช้ไม่ได้ และระบุชื่อการตั้งค่านี้ เอเจนต์ตรวจสอบก่อนได้ด้วยเครื่องมือ `capabilities` ดู [บรรทัดคำสั่งและเอเจนต์](help://cli)

## สคีมาและงบที่เล็กลง

`apply` และ `create` ประกาศพารามิเตอร์ `ops`, `cells` และ `data` พร้อมสคีมาที่มีชนิดของแต่ละ op ซึ่งสร้างจาก `ieumoffice guide <domain> --json` แบบนี้แม่นยำแต่ไม่เล็ก ไคลเอ็นต์ที่หน้าต่างบริบทแคบสามารถขอเป็นอาร์เรย์ธรรมดาแทนได้

```sh
ieumoffice mcp --compact-schemas
GENOFFICE_MCP_COMPACT_SCHEMAS=1 ieumoffice mcp
```

## ทำไมต้องมีสกิล

เอเจนต์ที่ไม่รู้จักศัพท์ของ op ก็จะเดา สกิลมีคู่มืออ้างอิงและแนวทางการออกแบบติดไปด้วย ซึ่งเป็นเนื้อหาเดียวกับที่ `ieumoffice guide` พิมพ์ออกมา ผู้ช่วยจึงเขียน op ที่อ่านสเปกของมันจริง ๆ แล้ว ติดตั้งจากแผงด้านบน หรือใช้ `ieumoffice skill` จากเทอร์มินัลก็ได้

## ในแอปมันเข้าถึงอะไรได้บ้าง

เซิร์ฟเวอร์ไม่ได้จำกัดอยู่แค่ไฟล์บนดิสก์ ตราบใดที่ GenOffice ยังทำงานอยู่ เอเจนต์ก็ทำงานผ่านหน้าต่างได้ด้วย

- **`open_in_genoffice`** เปิดไฟล์ในแท็บใหม่และโฟกัสไปที่แท็บนั้น
- **`open_documents`** แสดงรายการเอกสารทุกฉบับที่คุณเปิดอยู่ ทั้ง id ชนิด พาธ และมีการแก้ไขที่ยังไม่บันทึกหรือไม่ จากนั้นจึงอ่านเนื้อหาปัจจุบันของเอกสารหนึ่ง บันทึกไว้ในที่เดิม หรือปิดมัน โดยจะบันทึกก่อนเว้นแต่คุณสั่งให้ทิ้ง
- **เครื่องมือเนื้อหา** รับ id (หรือพาธ) นั้นเป็นอาร์กิวเมนต์ `document` การแก้ไขจึงตกลงในแท็บที่คุณเปิดค้างไว้แล้ว และหน้าต่างจะสลับไปแสดงแท็บนั้น

สองอย่างที่ยังไปไม่ถึง นั่นคือไม่มีแผง AI และกล่องอัปเดตในแอปก็ใช้ไม่ได้

## แผงเซิร์ฟเวอร์ HTTP ในเครื่อง

ใต้ **เซิร์ฟเวอร์ HTTP ในเครื่อง** แอปจะรันเซิร์ฟเวอร์เองแทนที่จะปล่อยให้ผู้ช่วยเป็นผู้ทำ มีสวิตช์เปิดใช้งาน ช่อง **พอร์ต** ตัวบอกสถานะ **กำลังทำงาน / หยุดทำงานอยู่** และ **การสร้างแบบเบื้องหลัง** (เขียนเอกสารลงพาธได้เลยโดยไม่ต้องเปิดหน้าต่างใช้งาน) รวมทั้ง **ตัวอย่างการตั้งค่าไคลเอ็นต์** ที่คัดลอกไปใช้ได้ เมื่อเปิด **ขั้นสูง** จะเพิ่ม URL ของการเชื่อมต่อสองรายการ — Streamable HTTP และรายการ SSE แบบเก่า —, URL สำหรับ **ตรวจสอบสถานะ** และสวิตช์ **การบันทึกปูม** ที่จดบันทึกกิจกรรมของเซิร์ฟเวอร์และเครื่องมือลงไฟล์ในเครื่อง พร้อมปุ่ม **เปิด** **รีเฟรช** และ**ล้าง** ให้ใช้งานได้จากที่นั่น เซิร์ฟเวอร์รับการเชื่อมต่อเฉพาะที่ localhost เท่านั้น
