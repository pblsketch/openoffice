# Установка GenOffice

Каждая версия публикуется на [странице релизов](https://github.com/pblsketch/openoffice/releases/latest) проекта на GitHub. Эта версия выпускается для Windows.

## Выберите файл для своего компьютера

| Платформа   | Требования                                   | Файл                            |
| ----------- | -------------------------------------------- | ------------------------------- |
| **Windows** | Windows 10 или новее, 64-разрядный Intel/AMD | `GenOffice-Setup-<version>.exe` |

Более старые версии остаются на странице релизов.

## В Windows

1. Скачайте `GenOffice-Setup-<version>.exe` со страницы релизов.
2. Запустите его. У установщика нет цифровой подписи, поэтому Windows может сначала показать синее окно «Система Windows защитила ваш компьютер». Выберите **Подробнее**, затем **Выполнить в любом случае**. Точные формулировки зависят от версии Windows.
3. Пройдите установщик до конца.

Он помещает GenOffice в меню «Пуск» и регистрирует `.docx`, `.xlsx`, `.pptx`, `.pdf` и подобные форматы, так что двойной щелчок по файлу открывает его в GenOffice.

Поскольку установщик не подписан, запускайте только тот, который скачали со страницы релизов, указанной выше.

## Обновления

- GenOffice ищет более новую версию на той же странице релизов на GitHub. Когда она опубликована, её предлагает раздел **Настройки ▸ О программе**: нажмите **Обновить до …**, дождитесь загрузки, затем нажмите **Перезапустить и установить**.
- **Меню (☰) ▸ Проверить обновления…** выполняет проверку по вашему запросу. На Mac это **Справка ▸ Проверить обновления…**.
- Если проверка не удалась — нет сети или ещё ничего не опубликовано, — ничего не происходит, и приложение продолжает работать как прежде.
- **Канал обновлений**, тоже в разделе Настройки ▸ О программе, — Стабильный или Бета. Смена действует сразу и запускает проверку обновления; установку из канала Бета он не вернёт в Стабильный.
- У обновлений тоже нет цифровой подписи. Перед установкой приложение сверяет скачанный файл с контрольной суммой, опубликованной вместе с этим релизом.

## Сборка, которую вы запускаете

**Настройки ▸ О программе** — место, где приложение сообщает, какая у вас версия, за каким каналом оно следит и где находится проект. Там же назван проект с открытым исходным кодом, на котором основано это приложение.

## Командная строка идёт в комплекте

Каждая установка включает команду `ieumoffice`, которая работает через те же движки, что и окно, поэтому они никогда не расходятся во мнении о файле. `ieumoffice install-cli` помещает её в ваш `PATH`. Что она умеет — см. [Командная строка и агенты](help://cli).
