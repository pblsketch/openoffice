# 設定、語言、主題與 MCP 整合

## 開啟設定

首頁左下角的那一列會開啟設定面板（尚未連結 AI 時顯示為「連結 AI」）。面板共五個分區：帳戶、AI、一般、整合、關於。

**帳戶**會顯示你的 Claude 與 Codex 訂閱目前的狀態，**管理連線**則會帶你到 AI 分區。AI 另有兩篇專文說明：[訂閱連線](help://subscription)與 [AI 模型與設定](help://ai-models)。

## 語言

- 設定中提供 **21 種介面語言**：English、简体中文、日本語、한국어、Français、Deutsch、Español、ไทย、Bahasa Indonesia、Русский、العربية、Português、Italiano、Polski、Čeština、Nederlands、Bahasa Melayu、עברית、हिन्दी、繁體中文、Tiếng Việt。
- 切換後立即生效並會保留；原生選單列也會隨語言重建。

## 主題

淺色／深色／跟隨系統三種。跟隨系統時會依作業系統的外觀切換，編輯器區域同步換膚且不會閃白。

## 一般

- **AI 側邊欄位置**（左或右）、**AI 面板文字大小**與**AI 對話拼字檢查**。
- **在新文件中開啟 AI 面板** —— 關閉，新文件開始時面板是收合的，點一下就能取用。
- **所有文件自動儲存** 會讓每個編輯器預設開啟自動儲存；單一視窗仍然可以關閉。
- **預設儲存位置**搭配**變更**按鈕，以及**設為 Office 文件預設程式**，讓 .docx / .xlsx / .pptx 由 GenOffice 開啟。

GenOffice 不會收集也不會傳送使用統計，所以這裡沒有對應的開關。

## AI ▸ 進階

預設是收合的，要你自己展開；大多數人用不到它。**AI 模型**分頁放的是對話用的 API 金鑰，以及你自己架設的伺服器。在**生圖、媒體與搜尋**分頁，每一項能力都會自行挑選提供服務的供應商，供應商的金鑰與基礎網址只需填寫一次，各欄位共用：

- **網路搜尋**、**生圖**、**圖片解析**與**影片解析**，每一項都有供應商、模型、金鑰與基礎網址。
- **本機檔案搜尋**在這台機器上執行。它下方的 **Jev 搜尋重排** 預設關閉。開啟後，本機搜尋前 20 筆命中的摘錄——每份文件最多 1,200 個字元，外加檔名和資料夾名——會送给你選擇的決策端點（OpenRouter 或 TypeSafe 的 Jev、Perplexity、Liquid AI d1、Cloudflare、本機引擎或自訂 URL），按相關性重新排序。關閉時不會有任何東西離開本機。
- **允許自動呼叫使用訂閱**這一項**預設關閉**。它決定來自命令列或已連接的程式開發代理的要求，能不能使用你的 Claude 或 Codex 訂閱；請見[連接程式設計助手](help://mcp)。

## 關於

- **版本**、專案的 GitHub 網址，以及一行說明，寫明本應用程式所根據的開放原始碼專案。
- **更新通道**：穩定版或 Beta 版。變更後立即生效並檢查更新；它不會把 Beta 版的安裝降回穩定版。

## 預設應用程式關聯

設定中可以把 .docx / .xlsx / .pptx / .pdf 等格式註冊為由 GenOffice 開啟（作業系統層級的預設應用程式註冊；出現提示時請確認）。

## 第三方聲明與更新

- 說明 ▸ 第三方軟體聲明：隨附於應用程式的完整 OSS 授權清單。
- 選單（☰） ▸ 檢查更新（Mac 上為 說明 ▸ 檢查更新）：手動觸發一次更新檢查；有新版本時會提示安裝。

## MCP 整合（供進階使用者／AI 用戶端使用）

**整合**是把 GenOffice 接上程式開發代理的面板，它也有專門一章：連接程式開發代理。簡單說就是——選一條路（命令列或 MCP），照那一節做，然後開一個新對話直接問。

在**本機 HTTP 服務**之下，應用程式也可以自己跑這個服務——一個啟用開關、一個連接埠——而**進階**會再加上健康檢查的網址和日誌檔案——而不是丟給助理處理。它只監聽 localhost。
