# 區域網路協作編輯

同一個網路（區域網路，LAN）中的人可以一起開啟同一份文件、同時編輯，並看到彼此的游標和名字。不需要伺服器或帳戶：共用文件的電腦負責這次共同作業，檔案也只在那台電腦上儲存。

## 共用文件

1. 開啟文件，在編輯器的工具列中按一下 **共同作業**。
2. 輸入 **我的名字** 並選擇 **我的顏色**。其他人會在你的游標旁看到它們。
3. 按一下 **開始共用**。畫面上會出現 6 位數字的 **PIN** 和 **這台電腦的位址**。
4. 把 PIN 告訴要加入的人；如果對方找不到文件，也一併告知位址。

如果文件有尚未儲存的變更，請先儲存。設有密碼的文件無法共用。按 **新 PIN** 會為文件換上新的 PIN，已加入的人不受影響。

要停止共用，請再次開啟 **共同作業** 並按一下 **停止共用**。所有加入過的人，電腦上都會留下一份未儲存的副本。

## 加入

1. 在任一編輯器中按一下 **共同作業**，然後切換到 **加入**。
2. 在 **找到的文件** 中選擇文件，或在 **位址** 中輸入共用電腦的位址。
3. 輸入 PIN 並按一下 **加入**。共用的文件會在新分頁中開啟。

參與期間由共用者儲存檔案。你按下儲存並不會真的儲存，而會告訴你原因；關閉分頁時也不會詢問是否儲存。按 **離開** 即可退出共同作業。共同作業結束後，分頁仍會保持開啟，成為一份未儲存的副本，你可以把它儲存到任何位置。

## 一起編輯

- 每個人的游標或選取範圍都會以其顏色顯示，並附上名字。
- 復原只會還原你自己的編輯。
- 共同作業期間部分功能無法使用，例如會變更文件內容以外部分的功能。編輯器拒絕執行時會告訴你。
- 在韓文編輯器中只有共用者可以編輯，加入的人會即時看到變更。
- 純文字和 JSON 檔案會在 Markdown 編輯器的原始碼檢視中開啟，目前還無法共用。

## 安全性

- PIN 絕不會透過網路傳送。它以金鑰交換來驗證，之後傳輸的所有內容都會加密。網路上的其他人無法讀取文件、編輯內容或 PIN。
- 同一台電腦輸錯 PIN 5 次後，該電腦必須等待 10 分鐘。錯誤次數累計達 20 次後，所有共用中的文件都會換上新的 PIN，並通知共用者。
- 一份文件最多可有 16 人加入。
- 共用期間，你的名字和文件標題會在網路上廣播，方便其他人找到它。
- 第一次共用時，Windows 防火牆可能會要求權限。請在私人網路上允許。如果封鎖，其他電腦將無法連線。
