# 같은 네트워크에서 공동 작업

같은 네트워크(LAN)에 있는 사람들이 한 문서를 함께 열어 동시에 고치고, 서로의 커서와 이름을 볼 수 있습니다. 서버나 계정은 필요 없습니다. 문서를 공유한 PC가 세션을 맡고, 파일은 그 PC에서만 저장합니다.

## 문서 공유하기

1. 문서를 열고 편집기 도구 모음에서 **공동 작업**을 누릅니다.
2. **내 이름**을 적고 **내 색**을 고릅니다. 다른 사람의 화면에서 내 커서 옆에 보입니다.
3. **공유 시작**을 누르면 6자리 **PIN**과 **이 PC의 주소**가 나타납니다.
4. 참여할 사람에게 PIN을 알려 줍니다. 문서를 찾지 못하면 주소도 알려 줍니다.

저장하지 않은 변경이 있으면 먼저 저장해야 합니다. 암호가 걸린 문서는 공유할 수 없습니다. **새 PIN**을 누르면 PIN이 바뀌며, 이미 들어온 사람은 그대로 남습니다.

공유를 끝내려면 **공동 작업**을 다시 열고 **공유 끝내기**를 누릅니다. 참여했던 사람들의 PC에는 저장하지 않은 사본이 남습니다.

## 참여하기

1. 아무 편집기에서나 **공동 작업**을 누르고 **참여하기**로 바꿉니다.
2. **찾은 문서**에서 문서를 고르거나, **주소**에 공유한 PC의 주소를 입력합니다.
3. PIN을 입력하고 **참여**를 누르면 공유된 문서가 새 탭으로 열립니다.

참여하는 동안에는 공유한 사람이 파일을 저장합니다. 내가 저장을 누르면 저장하지 않고 그 이유를 알려 주며, 탭을 닫을 때 저장할지 묻지 않습니다. **나가기**를 누르면 세션에서 나옵니다. 세션이 끝나도 탭은 그대로 열려 있고, 저장하지 않은 사본이 되어 원하는 곳에 저장할 수 있습니다.

## 함께 고치기

- 사람마다 커서나 선택한 곳이 그 사람의 색과 이름으로 표시됩니다.
- 실행 취소는 내가 고친 것만 되돌립니다.
- 세션 동안에는 문서 본문이 아닌 부분을 바꾸는 기능처럼 일부 기능을 쓸 수 없습니다. 쓸 수 없는 기능을 누르면 편집기가 알려 줍니다.
- 한글 편집기에서는 공유한 사람만 고칠 수 있고, 참여한 사람은 바뀌는 내용을 실시간으로 봅니다.
- 마크다운 편집기의 원문 편집기로 열리는 일반 텍스트 파일과 JSON 파일은 아직 공유할 수 없습니다.

## 보안

- PIN은 네트워크로 보내지 않습니다. 키 교환으로 PIN을 확인하고, 그 뒤에 주고받는 내용은 모두 암호화합니다. 같은 네트워크의 다른 사람은 문서와 편집 내용, PIN을 읽을 수 없습니다.
- 한 PC에서 PIN을 5번 틀리면 그 PC는 10분 동안 다시 시도할 수 없습니다. 틀린 횟수가 모두 20번이 되면 공유 중인 모든 문서의 PIN이 바뀌고 공유한 사람에게 알립니다.
- 문서 하나에 16명까지 참여할 수 있습니다.
- 공유하는 동안에는 다른 사람이 문서를 찾을 수 있도록 내 이름과 문서 제목을 같은 네트워크에 알립니다.
- 처음 공유할 때 Windows 방화벽이 허용 여부를 물을 수 있습니다. 개인 네트워크에서 허용하세요. 차단하면 다른 PC에서 접속할 수 없습니다.
