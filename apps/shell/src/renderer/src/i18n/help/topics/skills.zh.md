# 技能

技能是交给 AI 的工作说明。把反复要做的事写下来一次——整理会议记录的步骤、报告的语气、每次都要检查的要点——之后就可以在 AI 面板中调用它，AI 也会在合适的时候自己拿来用。技能是一个放着 `SKILL.md` 文件的文件夹，采用开放格式，所以在 GenOffice 中做的技能，拿到 Claude Code 或 Codex 里也能原样使用。

## 开启和关闭技能

**设置 ▸ 技能**按来源分组列出这台电脑上的技能。技能和在编程智能体中一样以名称显示。用顶部的搜索框，可以按名称或说明查找。

| 来源                  | 包含的内容                                   | 初始状态 |
| --------------------- | -------------------------------------------- | -------- |
| **内置**              | GenOffice 自带的 5 个技能                    | 开启     |
| **我的技能**          | 你添加或制作的技能（`~/.ieumoffice/skills`） | 开启     |
| **Claude 技能文件夹** | `~/.claude/skills` 中的技能                  | 关闭     |
| **Claude 插件**       | 已安装的 Claude 插件中的技能                 | 关闭     |
| **Codex 技能文件夹**  | `~/.agents/skills` 中的技能                  | 关闭     |

- 用开关开启或关闭技能。同一个设置同时适用于各编辑器的 AI 面板、主屏的 AI 问答和智能体窗口。
- 已开启的技能可以选择**自动使用**或**仅调用时**，初始为自动使用。选仅调用时，只有你亲自调用时才会用到这个技能。
- 不同来源的技能可能同名。靠每一行上的来源标签区分。
- 更多菜单里有**查看内容**、**直接修改**（仅限我的技能）、**导出（zip）**（仅限我的技能）和**打开文件夹**。
- **移到回收站**会把我的技能中的一个移到系统回收站，之后可以从那里恢复。
- 内置技能不能删除，只能隐藏：选择**隐藏**。在列表底部点**重新显示**，它会以初始状态回来。
- 想修改内置技能或其他程序的技能，选择**复制到我的技能**。副本会出现在我的技能中，原技能随之关闭。
- 导出带模板的技能时，模板文档也会一起打进 zip。导出前请确认文档里没有个人信息。

## 添加技能

1. 在**设置 ▸ 技能**中点**添加**。
2. 选择**从文件夹**、**从 zip 文件**或**从 GitHub 链接**。选 GitHub 时，填入公开仓库的地址或 `owner/repo`，再点**查找**。
3. 在预览中检查找到的技能。预览会显示文件数量和大小、是否含脚本、正文中的网址，以及许可证文件。
4. 只勾选要安装的技能，然后点**安装**。装好的技能一开始就是开启状态。

预览下方始终写着：“只安装来自可信来源的技能。技能会向 AI 下达指令，在智能体窗口中还可以运行脚本”。来源不明的技能，请先读一遍再安装。

- 如果我的技能中已有同名技能，在那一行选择**替换**或**跳过**。
- 从 GitHub 下载时，GenOffice 只连接 `github.com`、`api.github.com` 和 `codeload.github.com`，不发送任何登录信息。压缩包过大或未通过安全检查时，什么都不会安装。
- **新建**会打开一个空白编辑器，由你自己写名称、说明和正文。

## 检查更新

- 对从 GitHub 安装的技能，更多菜单中的**检查更新**会查找新内容。只有在你点击时才会连接 GitHub。
- 没有变化时，会显示“已是最新”。有变化时，先查看有变化的文件和预览，再点**更新**。
- 如果安装后你自己改过这个技能，还会显示“你所做的修改将会丢失”。
- 更新后，技能的开启/关闭状态以及自动使用 / 仅调用时的选择都保持不变。

## 在 AI 面板中调用技能

1. 在 AI 输入框的开头或空格之后输入 `/` 或 `$`，就会出现已开启技能的列表。
2. 继续输入可以缩小范围。例如输入 `/meet` 会找到 `meeting-minutes`。说明里的词也能用来查找，输入 `/会议` 也可以。
3. 用方向键选中一个，按 Enter 或 Tab。这个技能会变成输入框上方的一个标签。
4. 写下你的要求并发送。GenOffice 会把技能内容附在请求里。

- 在 Excel 的 AI 面板中，`$` 只在输入框的最开头才会打开列表，这样不会妨碍输入 `$A$1` 这样的单元格地址。
- 可以添加多个标签，点 × 可以移除其中一个。Esc 只关闭列表，不会停止正在运行的 AI。
- 列表底部的**管理技能…** 会打开**设置 ▸ 技能**。
- 标签会留在已发送的消息和保存的对话中。重新打开对话再次发送时，会重新读取技能的当前内容。如果期间技能被移除或关闭，标签上会显示“不可用”。
- 要一起发送的技能文本太长时，会显示“技能太大，无法一起发送”，并且不会发送任何内容。

## AI 自己使用的技能

- 已开启且设为自动使用的技能，其名称和说明会以列表形式交给 AI。某个技能与请求相符时，AI 会取出它的内容来用。
- AI 使用技能时，对话中会显示“已使用技能 〈名称〉”。
- AI 根据说明判断要不要用某个技能。在说明里写清楚这个技能适合在什么时候用，能帮 AI 选得更准。

## 用对话制作技能

1. 在 AI 面板中说一句，比如“把刚才做的事存成技能”或“做一个按我们公司格式写报告的技能”。
2. AI 会挑出值得重复的步骤和规则，显示一张**创建技能**卡片。只用这一次的值，例如姓名和日期，不会写进说明里。
3. 在卡片上检查并修改名称、说明和正文。名称会显示在技能列表中，也是在 `/` 后面输入的内容，只能使用英文小写字母、数字和连字符(-)。
4. 点**保存**。新技能会加入我的技能，处于开启状态，并且马上出现在 `/` 列表中。

- 在你点**保存**之前，不会写入任何文件。点**取消**的话，对话中只会留下“未保存的技能建议”。
- 也可以请它修改现有技能，比如“把整理会议纪要的技能改成我们的做法”。这时卡片标题是**修改技能**。我的技能中的技能会通过**替换**直接覆盖；内置技能或其他程序的技能会以副本形式存进我的技能，原技能随之关闭。

## 把文档加为模板

在编辑器的 AI 面板中制作技能时，可以把当前文档作为模板一起带上。勾选卡片上的**将此文档作为模板一起保存**，按钮就会变成两个。

- **制作空白模板**：文档的副本会在新标签页“模板预览 - 〈title〉”中打开，该标签页里的 AI 会清除已填入的值，例如姓名、日期和个人信息。检查一遍这个标签页，再手动改改，然后点**将此标签页保存为模板**；标签页在那一刻的样子就成为模板。
- **按原文档保存**：把当前文档原封不动地保存为模板。如果文档中有你对 AI 隐藏的部分，这个按钮会被禁用，以免隐藏的内容原样进入模板。
- 模板以文档副本的形式保存在技能文件夹里。原文档不会改变。

## 使用带模板的技能

- 带模板的技能在列表中显示**含模板**。
- 以标签形式调用并发送后，模板的副本会作为新的未命名文档打开，该标签页里的 AI 接着处理你的请求。原来的面板会留下“将在新标签页中使用模板工作”和**转到标签页**。
- AI 自己选用带模板的技能时，不会马上打开标签页，而是在对话中显示**用此模板新建文档**按钮。
- 新文档存放在哪里，通常由你在第一次保存时决定。不过 Markdown 和 HTML 编辑器会照旧存入默认文件夹。模板文件本身保持不变。

## 带脚本的技能

- 在普通 AI 面板和主屏的 AI 问答中，技能的脚本绝不会运行。只有技能的文字会交给 AI。
- 带脚本的技能显示**含脚本 · 在智能体窗口中完整运行**，把它加为标签时会显示“此技能的脚本不会在普通 AI 窗口中运行”。但不会阻止发送。
- 想连脚本一起用，请在智能体窗口中调用这个技能。参见[智能体模式](help://agent-mode)。

## 内置技能

| 技能              | 作用                                             |
| ----------------- | ------------------------------------------------ |
| `meeting-minutes` | 把会议记录整理成列明决定事项和待办事项的会议纪要 |
| `internal-comms`  | 撰写公告、简报、进展汇报、常见问题解答等内部文字 |
| `humanizer`       | 找出文本中像是 AI 写的表达，把它改得自然         |
| `copy-editing`    | 检查你写好的英文文本，改得更清楚、更简洁         |
| `find-skills`     | 在智能体窗口中查找你需要的技能，并建议安装       |

`copy-editing` 是为英文营销文本设计的。`find-skills` 只能在智能体窗口中使用。

## 在智能体窗口中

- 智能体窗口沿用**设置 ▸ 技能**中的开启/关闭设置，也同样在输入框中用 `/` 或 `$` 调用技能。
- 项目文件夹中 `.claude/skills` 和 `.agents/skills` 里的技能，无需开启就会在该会话中使用。
- 技能列表在会话开始时就固定下来。如果在会话中途开启或关闭技能，会显示“更改的技能将从下一个会话起生效”。
- 智能体制作技能时，窗口中也会出现同样的卡片。模板可以从标签页中打开的文档和项目文件夹里的文件中选择。
- 智能体找到值得安装的技能时，会出现安装建议。用**打开预览**打开它，由你亲自点**安装**；否则什么都不会安装。安装的技能从下一个会话起可用。
