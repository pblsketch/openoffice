# 스킬

스킬은 AI에게 주는 작업 설명서입니다. 회의록을 정리하는 순서, 보고서의 말투, 매번 확인할 항목처럼 되풀이하는 일을 한 번 적어 두면, AI 창에서 불러 쓰거나 AI가 필요할 때 스스로 꺼내 씁니다. 스킬은 폴더 하나에 `SKILL.md` 파일이 든 공개 형식이라, GenOffice에서 만든 스킬은 Claude Code나 Codex로 옮겨도 그대로 쓸 수 있습니다.

## 설정에서 켜고 끄기

**설정 ▸ 스킬**에 이 PC의 스킬이 출처별로 모여 있습니다. 스킬은 코딩 에이전트에서처럼 이름으로 보입니다. 위의 검색칸에서 이름이나 설명으로 찾습니다.

| 출처                 | 들어 있는 것                                 | 처음 상태 |
| -------------------- | -------------------------------------------- | --------- |
| **기본**             | GenOffice에 함께 든 스킬 5개                 | 켜짐      |
| **내 스킬**          | 가져오거나 만든 스킬(`~/.ieumoffice/skills`) | 켜짐      |
| **Claude 스킬 폴더** | `~/.claude/skills`의 스킬                    | 꺼짐      |
| **Claude 플러그인**  | 설치된 Claude 플러그인의 스킬                | 꺼짐      |
| **Codex 스킬 폴더**  | `~/.agents/skills`의 스킬                    | 꺼짐      |

- 스위치로 켜고 끕니다. 켜고 끄기는 편집기의 AI 창, 홈의 AI 질문, 에이전트 창에 모두 똑같이 적용됩니다.
- 켜진 스킬은 **스스로 쓰기**와 **부를 때만** 가운데 하나를 고릅니다. 처음에는 스스로 쓰기입니다. 부를 때만으로 두면 사람이 직접 불렀을 때만 쓰입니다.
- 출처가 다르면 이름이 같은 스킬이 함께 있을 수 있습니다. 줄마다 붙은 출처 표시로 구분합니다.
- 더보기 메뉴에서 **내용 보기**, **직접 고치기**(내 스킬만), **내보내기(zip)**(내 스킬만), **폴더 열기**를 고릅니다.
- **휴지통으로**는 내 스킬을 운영체제의 휴지통으로 옮깁니다. 휴지통에서 되살릴 수 있습니다.
- 기본 스킬은 지우는 대신 **숨기기**를 합니다. 목록 맨 아래의 **다시 보이기**로 되살리면 처음 상태로 돌아옵니다.
- 기본 스킬이나 다른 프로그램의 스킬을 고치고 싶으면 **내 스킬로 사본 만들기**를 고릅니다. 사본이 내 스킬에 생기고 원래 스킬은 꺼집니다.
- 양식이 든 스킬을 내보내면 양식 문서도 zip에 함께 들어갑니다. 내보내기 전에 문서에 개인정보가 없는지 확인하세요.

## 스킬 추가하기

1. **설정 ▸ 스킬**에서 **추가**를 누릅니다.
2. **폴더에서**, **zip 파일에서**, **깃허브 링크로** 가운데 하나를 고릅니다. 깃허브는 공개 저장소의 주소나 `소유자/저장소`를 넣고 **찾기**를 누릅니다.
3. 미리보기에서 찾은 스킬을 확인합니다. 파일 수와 크기, 스크립트가 들었는지, 글 안의 웹 주소, 라이선스 파일이 보입니다.
4. 설치할 스킬만 체크하고 **설치**를 누릅니다. 설치한 스킬은 켜진 채로 시작합니다.

미리보기 아래에는 늘 "믿을 수 있는 곳에서 받은 스킬만 설치하세요. 스킬은 AI에게 지시를 주고, 에이전트 창에서는 스크립트를 실행할 수 있습니다"가 보입니다. 모르는 곳의 스킬은 내용을 읽어 보고 설치하세요.

- 내 스킬에 같은 이름이 이미 있으면 그 줄에서 **바꾸기**나 **건너뛰기**를 고릅니다.
- 깃허브에서 받을 때 GenOffice는 `github.com`, `api.github.com`, `codeload.github.com`에만 연결하고, 로그인 정보는 보내지 않습니다. 압축 파일이 너무 크거나 안전 검사에 걸리면 아무것도 설치하지 않습니다.
- **새로 만들기**를 누르면 빈 편집 화면에서 이름, 설명, 본문을 직접 적어 만들 수 있습니다.

## 업데이트 확인

- 깃허브에서 설치한 스킬은 더보기 메뉴의 **업데이트 확인**으로 새 내용이 있는지 봅니다. 이 단추를 누를 때만 깃허브에 연결합니다.
- 바뀐 것이 없으면 "최신입니다"가 보입니다. 바뀌었으면 바뀐 파일 목록과 미리보기를 보고 **업데이트**를 누릅니다.
- 설치한 뒤 그 스킬을 직접 고쳤다면 "고친 내용이 사라집니다"가 함께 보입니다.
- 업데이트해도 켜짐과 스스로 쓰기·부를 때만 설정은 그대로입니다.

## AI 창에서 부르기

1. AI 입력칸의 맨 앞이나 띄어쓰기 바로 뒤에서 `/` 또는 `$`를 칩니다. 켜진 스킬 목록이 뜹니다.
2. 이어서 글자를 치면 목록이 좁혀집니다. 예를 들어 `/meet`로 `meeting-minutes`를 찾습니다. 설명에 든 말로도 찾을 수 있어 `/회의록`도 됩니다.
3. 위아래 화살표로 고르고 Enter나 Tab을 누릅니다. 고른 스킬은 입력칸 위에 칩으로 붙습니다.
4. 할 일을 적고 보냅니다. GenOffice가 스킬 내용을 요청에 함께 넣습니다.

- 엑셀 AI 창에서는 셀 주소(`$A$1`)와 겹치지 않도록 `$`가 입력칸 맨 앞에서만 목록을 엽니다.
- 칩은 여러 개 넣을 수 있고, ×로 뺍니다. Esc는 목록만 닫고 실행 중인 AI를 멈추지 않습니다.
- 목록 맨 아래의 **스킬 관리…**를 누르면 **설정 ▸ 스킬**이 열립니다.
- 보낸 말풍선과 저장된 대화에 칩이 남습니다. 대화를 다시 열어 이어 보내면 스킬의 지금 내용을 다시 읽어 넣습니다. 그사이 지워졌거나 꺼진 스킬은 칩에 "없음"으로 표시됩니다.
- 함께 넣는 스킬 글이 너무 길면 "스킬이 너무 커서 함께 보낼 수 없습니다"가 보이고 보내지 않습니다.

## AI가 스스로 쓰기

- 켜져 있고 스스로 쓰기로 둔 스킬은 이름과 설명이 AI에게 목록으로 전해집니다. AI는 요청에 맞는 스킬이 있으면 그 내용을 꺼내 씁니다.
- AI가 스킬을 쓰면 대화에 "〈이름〉 스킬을 썼습니다"가 보입니다.
- AI는 설명을 보고 스킬을 쓸지 정합니다. 스킬을 만들 때 설명을 언제 쓰는 스킬인지 알 수 있게 적으면 잘 골라집니다.

## 말로 스킬 만들기

1. AI 창에서 "지금 한 작업을 스킬로 저장해 줘"나 "보고서를 우리 말투로 쓰는 스킬 만들어 줘"처럼 말합니다.
2. AI가 대화에서 되풀이할 순서와 규칙을 뽑아 **스킬 만들기** 카드를 띄웁니다. 이름, 날짜처럼 이번에만 쓰인 값은 본문에 넣지 않습니다.
3. 카드에서 이름, 설명, 본문을 확인하고 고칩니다. 이름은 스킬 목록에 보이고 `/` 뒤에 쳐서 부르는 말로, 영어 소문자·숫자·하이픈(-)으로 씁니다.
4. **저장**을 누릅니다. 새 스킬은 내 스킬에 켜진 채로 생기고 곧바로 `/` 목록에 나옵니다.

- **저장**을 누르기 전에는 아무 파일도 생기지 않습니다. **취소**하면 대화에 "저장하지 않은 스킬 제안"으로만 남습니다.
- "회의록 스킬을 우리 방식으로 고쳐 줘"처럼 있는 스킬을 고치게 할 수도 있습니다. 카드 제목이 **스킬 고치기**가 됩니다. 내 스킬이면 **바꾸기**로 덮어쓰고, 기본 스킬이나 다른 프로그램의 스킬이면 내 스킬에 사본으로 저장하고 원래 스킬은 끕니다.

## 문서를 양식으로 넣기

편집기의 AI 창에서 만들 때는 지금 문서를 양식으로 함께 넣을 수 있습니다. 카드에서 **이 문서를 양식으로 함께 저장**을 체크하면 단추가 둘로 바뀝니다.

- **비운 양식 만들기**: 문서의 사본이 새 탭 "양식 미리보기 - 〈제목〉"에 열리고, 그 탭의 AI가 이름, 날짜, 개인정보처럼 채워진 값을 비웁니다. 탭을 직접 보고 더 고친 뒤 **이 탭을 양식으로 저장**을 누르면 그때의 탭 내용이 양식이 됩니다.
- **원래 문서 그대로 저장**: 지금 문서를 그대로 양식으로 저장합니다. 문서에 AI에게서 가린 내용이 있으면 이 단추는 막힙니다. 가린 내용이 양식에 그대로 남지 않게 하려는 것입니다.
- 양식은 스킬 폴더 안에 문서의 사본으로 저장됩니다. 원래 문서는 바뀌지 않습니다.

## 양식이 든 스킬 쓰기

- 양식이 든 스킬은 목록에 **양식 포함**이 붙습니다.
- 칩으로 불러 보내면 양식의 사본이 제목 없는 새 문서로 열리고, 그 탭의 AI가 요청을 이어서 채웁니다. 원래 창에는 "새 탭에서 양식으로 작업합니다"와 **탭으로 가기**가 남습니다.
- AI가 스스로 양식 스킬을 쓴 경우에는 새 탭을 바로 열지 않고, 대화에 **이 양식으로 새 문서 열기** 단추가 보입니다.
- 새 문서는 보통 처음 저장할 때 위치를 고릅니다. 다만 마크다운·HTML 편집기는 원래처럼 기본 폴더에 저장합니다. 원래 양식 파일은 그대로 남습니다.

## 스크립트가 든 스킬

- 일반 AI 창과 홈의 AI 질문에서는 스킬에 든 스크립트가 실행되지 않습니다. 스킬의 글만 AI에게 전해집니다.
- 스크립트가 든 스킬에는 **스크립트 포함 · 에이전트 창에서 완전히 동작**이 붙고, 칩으로 넣으면 "이 스킬의 스크립트는 일반 AI 창에서 실행되지 않습니다"가 보입니다. 보내기는 막지 않습니다.
- 스크립트까지 쓰려면 에이전트 창에서 부릅니다. 자세한 내용은 [에이전트 모드](help://agent-mode)에 있습니다.

## 기본 스킬

| 스킬              | 하는 일                                                            |
| ----------------- | ------------------------------------------------------------------ |
| `meeting-minutes` | 회의 메모를 결정 사항과 할 일이 보이는 회의록으로 정리합니다       |
| `internal-comms`  | 공지, 소식지, 진행 보고, 자주 묻는 질문 같은 조직 안의 글을 씁니다 |
| `humanizer`       | 글에서 AI가 쓴 티가 나는 표현을 자연스럽게 고칩니다                |
| `copy-editing`    | 이미 쓴 영어 글을 더 분명하고 간결하게 다듬습니다                  |
| `find-skills`     | 에이전트 창에서 필요한 스킬을 찾아 설치를 제안합니다               |

`copy-editing`은 영어 마케팅 글을 기준으로 만든 스킬입니다. `find-skills`는 에이전트 창에서만 쓸 수 있습니다.

## 에이전트 창에서

- 에이전트 창도 **설정 ▸ 스킬**의 켜고 끄기를 그대로 따릅니다. 입력칸에서 `/`나 `$`로 부르는 방법도 같습니다.
- 프로젝트 폴더의 `.claude/skills`와 `.agents/skills`에 든 스킬은 따로 켜지 않아도 그 세션에서 쓰입니다.
- 스킬 목록은 세션을 시작할 때 정해집니다. 세션 도중에 켜고 끄면 "바뀐 스킬은 다음 세션부터 적용됩니다"가 보입니다.
- 에이전트가 스킬을 만들면 창에 같은 카드가 뜹니다. 양식은 탭에 열린 문서나 프로젝트 폴더의 파일 가운데 고릅니다.
- 에이전트가 쓸 만한 스킬을 찾으면 설치 제안이 뜹니다. **미리보기 열기**로 내용을 보고 직접 **설치**를 눌러야 설치되며, 설치한 스킬은 다음 세션부터 쓰입니다.
