# การตั้งค่า ภาษา ธีม และการเชื่อมต่อ MCP

## การเปิดการตั้งค่า

แถวที่มุมล่างซ้ายของหน้าแรกจะเปิดแผงการตั้งค่า (แถวนี้จะแสดงเป็น "เชื่อมต่อ AI" จนกว่าจะมี AI เชื่อมต่ออยู่) แผงนี้มีห้าส่วน ได้แก่ บัญชี, AI, ทั่วไป, การเชื่อมต่อ และเกี่ยวกับ

**บัญชี** แสดงสถานะการสมัครสมาชิก Claude และ Codex ของคุณ และ **จัดการการเชื่อมต่อ** จะพาไปยังส่วน AI ซึ่งมีบทความของตัวเอง ได้แก่ [การเชื่อมต่อการสมัครสมาชิก](help://subscription) และ [โมเดล AI และการตั้งค่า](help://ai-models)

## ภาษา

- การตั้งค่ามี **ภาษาสำหรับส่วนติดต่อผู้ใช้ 21 ภาษา**: อังกฤษ, จีนตัวย่อ, ญี่ปุ่น, เกาหลี, ฝรั่งเศส, เยอรมัน, สเปน, ไทย, อินโดนีเซีย, รัสเซีย, อาหรับ, โปรตุเกส, อิตาลี, โปแลนด์, เช็ก, ดัตช์, มลายู, ฮีบรู, ฮินดี, จีนตัวเต็ม, เวียดนาม
- การเปลี่ยนภาษามีผลทันทีและคงอยู่ถาวร แถบเมนูของระบบจะสร้างใหม่ตามภาษานั้น

## ธีม

สว่าง / มืด / ตามระบบ โหมดตามระบบจะเปลี่ยนตามรูปลักษณ์ของระบบปฏิบัติการ และพื้นที่แก้ไขจะเปลี่ยนสีตามโดยไม่กะพริบ

## ทั่วไป

- **ตำแหน่งแถบด้านข้าง AI** (ซ้ายหรือขวา), **ขนาดตัวอักษรในแผง AI** และ **ตรวจการสะกดในแชท AI**
- **เปิดแผง AI ในเอกสารใหม่** — ปิดอยู่ เอกสารใหม่จะเริ่มโดยแผง AI ยุบพับไว้ แค่คลิกเดียวก็เปิดได้
- **บันทึกอัตโนมัติทุกเอกสาร** เปิดการบันทึกอัตโนมัติเป็นค่าเริ่มต้นในทุกตัวแก้ไข แต่ยังปิดเฉพาะหน้าต่างได้
- **ตำแหน่งบันทึก** พร้อมปุ่ม **เปลี่ยน** และ **แอปเริ่มต้นสำหรับเอกสาร Office** เพื่อให้ GenOffice เป็นผู้จัดการ .docx / .xlsx / .pptx

GenOffice ไม่เก็บและไม่ส่งสถิติการใช้งาน จึงไม่มีสวิตช์สำหรับเรื่องนี้

## AI ▸ ขั้นสูง

ส่วนนี้ปิดอยู่จนกว่าคุณจะเปิดเอง และคนส่วนใหญ่ไม่จำเป็นต้องใช้ แท็บ **โมเดล AI** เก็บคีย์ API และเซิร์ฟเวอร์ที่คุณดูแลเองสำหรับการสนทนา ส่วนในแท็บ **สื่อ AI และการค้นหา** ความสามารถแต่ละอย่างเลือกผู้ให้บริการที่ดูแลความสามารถนั้น และคีย์กับ URL ฐานของผู้ให้บริการกรอกครั้งเดียวแล้วใช้ร่วมกัน:

- **ค้นหาเว็บ**, **สร้างภาพ**, **วิเคราะห์ภาพ** และ **วิเคราะห์วิดีโอ** แต่ละรายการมีผู้ให้บริการ โมเดล คีย์ และ URL ฐาน
- **ค้นหาไฟล์ในเครื่อง** ทำงานบนเครื่องนี้ ใต้มันคือ **จัดลำดับผลค้นหา Jev** **ปิดโดยค่าเริ่มต้น** เมื่อเปิด คัดลอก 20 ผลแรกของการค้นหาในเครื่อง — สูงสุด 1,200 อักขระต่อเอกสาร พร้อมชื่อไฟล์และโฟลเดอร์ — ส่งไปยัง endpoint ตัดสินใจที่คุณเลือก (Jev ผ่าน OpenRouter หรือ TypeSafe, Perplexity, Liquid AI d1, Cloudflare, เอนจินในเครื่อง หรือ URL กำหนดเอง) เพื่อจัดเรียงตามความสัมพันธ์ ปิดไว้จะไม่มีอะไรออกจากอุปกรณ์
- **อนุญาตให้คำขออัตโนมัติใช้การสมัครสมาชิก** **ปิดโดยค่าเริ่มต้น** ตัวเลือกนี้กำหนดว่าคำขอจากบรรทัดคำสั่งหรือจากเอเจนต์เขียนโค้ดที่เชื่อมต่อไว้ จะใช้การสมัครสมาชิก Claude หรือ Codex ของคุณได้หรือไม่ ดู [เชื่อมต่อเอเจนต์เขียนโค้ด](help://mcp)

## เกี่ยวกับ

- **เวอร์ชัน** ที่อยู่ GitHub ของโครงการ และข้อความหนึ่งบรรทัดที่ระบุชื่อโปรเจกต์โอเพนซอร์สที่แอปนี้พัฒนาต่อยอดมา
- **ช่องทางอัปเดต**: เสถียร หรือเบต้า การเปลี่ยนมีผลทันทีและจะตรวจหาอัปเดต แต่จะไม่ถอยกลับการติดตั้งแบบเบต้าไปเป็นเสถียร

## การผูกแอปเริ่มต้น

การตั้งค่าสามารถลงทะเบียนให้ GenOffice เป็นโปรแกรมที่เปิดไฟล์ .docx / .xlsx / .pptx / .pdf และไฟล์อื่น ๆ ได้ (การลงทะเบียนแอปเริ่มต้นระดับระบบปฏิบัติการ โดยต้องยืนยันเมื่อระบบถาม)

## การแจ้งซอฟต์แวร์ของบุคคลที่สามและการอัปเดต

- วิธีใช้ ▸ ประกาศเกี่ยวกับซอฟต์แวร์ของบุคคลที่สาม: รายการสัญญาอนุญาตโอเพนซอร์สทั้งหมดที่มาพร้อมแอป
- เมนู (☰) ▸ ตรวจหาการอัปเดต… (บน Mac ใช้ วิธีใช้ ▸ ตรวจหาการอัปเดต…): เรียกการตรวจสอบด้วยตนเอง หากมีเวอร์ชันใหม่จะแจ้งให้ติดตั้ง

## การเชื่อมต่อ MCP (สำหรับผู้ใช้ขั้นสูง / ไคลเอ็นต์ AI)

**การเชื่อมต่อ** คือแผงที่เชื่อม GenOffice เข้ากับเอเจนต์เขียนโค้ด และมีบทของตัวเองอยู่: การเชื่อมต่อเอเจนต์เขียนโค้ด สรุปสั้น ๆ คือ— เลือกเส้นทาง (บรรทัดคำสั่ง หรือ MCP) แล้วทำตามส่วนนั้น จากนั้นเริ่มแชทใหม่แล้วถาม

ภายใต้ **เซิร์ฟเวอร์ HTTP ในเครื่อง** แอปยังสามารถสั่งให้เซิร์ฟเวอร์ทำงานเองได้ — สวิตช์เปิดใช้งานและพอร์ต — และ **ขั้นสูง** จะเพิ่ม URL ของการตรวจสอบสถานะกับไฟล์ปูม แทนที่จะปล่อยให้ผู้ช่วยเป็นผู้ทำ โดยรับฟังเฉพาะในเครื่อง

## ตารางคำสั่งแบบเรียบด่วน

| ------------------- | ------------------------------ |
| `ieumoffice <file>` | เปิดไฟล์                       |

| `ieumoffice --help` | คำสั่งและตัวเลือกทั้งหมด       |
