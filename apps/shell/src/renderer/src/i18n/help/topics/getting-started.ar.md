# بدء سريع: الواجهة والأساسيات

GenOffice حزمة مكتبية تعمل على جهازك: نافذة واحدة وصف واحد من علامات التبويب يضم ثمانية محرّرات — Docs (معالجة النصوص)، وSheets (جداول البيانات)، وSlides (العروض التقديمية)، وPDF، وMarkdown والنص العادي، وHTML، وHWP/HWPX (مستندات Hangul)، والخرائط الذهنية (.xmind). يفتح كل محرّر الملفات بصيغته ويحفظها بها: .docx و.xlsx و.pptx و.pdf و.md و.html و.hwp/.hwpx و.xmind. لا يحتاج التحرير إلى اتصال بالشبكة، أما ميزات الذكاء الاصطناعي فتحتاج إليه. ويستورد محرر الخرائط الذهنية أيضًا ملفات FreeMind وFreeplane ‏(.mm) كخرائط جديدة تُحفظ بصيغة .xmind.

## نظرة عامة على الواجهة

تتألف النافذة من ثلاثة أجزاء:

- **شريط علامات التبويب (أعلى)**: كل ملف مفتوح هو علامة تبويب. علامة التبويب الرئيسية في أقصى اليسار موجودة دائمًا ولا يمكن إغلاقها؛ والعلامات الأخرى هي مستنداتك. انقر نقرًا مزدوجًا على أي علامة لإعادة تسمية ملفها في مكانه.
- **منطقة المحتوى**: المحرّر (أو الشاشة الرئيسية) الخاص بعلامة التبويب النشطة.
- **شريط القوائم**: في قائمة النظام على macOS، وفي أعلى النافذة على Windows/Linux. تتبدّل قوائم ملف/تحرير/عرض لتطابق المحرّر النشط.

## إنشاء مستند

أيّ من الطرق التالية:

- انقر بطاقة إنشاء سريع في قسم [بدء سريع](help://getting-started) في **الصفحة الرئيسية** (AI Docs، AI Sheets، AI Slides، ...).
- قائمة **ملف ▸ جديد**: Docs (⌘N/ctrl+N)، أو Sheets، أو Slides، أو Markdown، أو HTML، أو PDF.
- اسحب ملفًا إلى النافذة، أو انقر عليه نقرًا مزدوجًا في مدير الملفات (إذا كان GenOffice هو التطبيق الافتراضي).

يُفتح المستند الجديد بلا عنوان؛ ولا يُنشأ الملف على القرص إلا عند الحفظ الأول.

## فتح الملفات

- تفتح قائمة **ملف ▸ فتح…** (⌘O/ctrl+O) منتقي ملفات النظام: .docx / .doc / .odt / .xlsx / .xls / .csv / .tsv / .pptx / .ppt / .pdf / .md / .html.
- انقر أي عنصر في قائمة **المستخدمة مؤخرًا** في الصفحة الرئيسية.
- الأمر `ieumoffice <file>` من الطرفية يفتح الملفات أيضًا.

## مستندات ODT

تُفتح ملفات .odt (نص OpenDocument، وهو التنسيق الذي تحفظ به برامج مثل Hancom Office وLibreOffice) في علامة تبويب Docs، من كل مكان يُفتح منه ملف .docx. أما المستند الجديد فيبقى .docx.

- **يعمل كالمعتاد**: تحرير النص، وتنسيق الأحرف والفقرات، والجداول (إضافة الصفوف والأعمدة وحذفها، ودمج الخلايا وتقسيمها)، والصور، والرؤوس والتذييلات، والحواشي السفلية والختامية، وإعداد الصفحة والمقاطع، والتعداد النقطي والرقمي، وأنماط العناوين، والارتباطات، والبحث والاستبدال، والتدقيق الإملائي، والطباعة، والتصدير إلى PDF وHTML، والتحرير بالذكاء الاصطناعي.
- **معطَّل في ODT**: التعليقات، وتعقب التغييرات، والمقارنة، والعلامة المائية، والحبر، وجدول المحتويات، وإدراج المعادلات أو الأشكال أو مربعات النص أو المخططات، والأعمدة، والاقتباسات والمراجع، والتسميات التوضيحية والإسنادات الترافقية، ولون الصفحة، وكلمة المرور وتقييد التحرير، والتوصية بالقراءة فقط، وخطوط السمة وألوانها، والهوامش المتقابلة. تظهر أزرارها باهتة؛ احفظ المستند بتنسيق .docx لاستخدامها.
- **يبقى كما كان**: تظهر المعادلات والمخططات والرسومات الموجودة في الملف الأصلي صورًا مقفلة يمكن حذفها لا تعديلها، وتبقى خلايا الجداول المقفلة مقفلة. الأجزاء التي لا تلمسها تُحفظ دون تغيير. ملف ODT المحمي بكلمة مرور لا يُفتح؛ أزل كلمة المرور أولًا.
- يتيح **حفظ باسم** الاختيار بين .docx و.odt. قبل تغيير التنسيق تُعرض قائمة بما سيتغير أو يُفقد، ثم يُعاد فتح علامة التبويب على الملف الجديد. ويتيح Markdown وHTML أيضًا **تصدير كملف ODT…**.

## نموذج الحفظ

- **الحفظ اليدوي**: ⌘S/ctrl+S، أو ملف ▸ حفظ / حفظ باسم…. وفي الحفظ الأول يطلب التطبيق الموقع والاسم.
- **الحفظ التلقائي** يتبع مفتاح كل محرر (والقيمة الافتراضية للتطبيق). ملف PDF تقرأه فقط لن يُعاد كتابته بصمت، والمستند الجديد الذي ليس له ملف خاص لا يبدأ الحفظ التلقائي إلا بعد حفظه الأول.
- إغلاق علامة تبويب عليها تغييرات غير محفوظة يعرض عليك الحفظ / التجاهل / الإلغاء أولًا.
- كل كتابة تتم بشكل ذرّي (ملف مؤقت + إعادة تسمية)، فلا يمكن أن ينقطع التيار ويترك ملفًا نصف مكتوب.

## اختصارات شائعة

| الإجراء             | macOS | Windows / Linux |
| ------------------- | ----- | --------------- |
| مستند جديد          | ⌘N    | ctrl+N          |
| فتح                 | ⌘O    | ctrl+O          |
| حفظ                 | ⌘S    | ctrl+S          |
| إغلاق علامة التبويب | ⌘W    | ctrl+W          |
| فتح هذا الدليل      | F1    | F1              |
| طي الشريط           | ⌥⌘R   | Ctrl+F1         |

**طي الشريط** متاح في كل المحرّرات. يبقى صف علامات التبويب كما هو ويختفي شريط الأوامر الذي تحته؛ وتعمل علامة التبويب المحدّدة أيضًا كزرّ طي، لذا ما دام الشريط مطويًّا لا توجد علامة تبويب محدّدة، والضغط على أي علامة تبويب يُعيد الشريط إلى الظهور. والنقر المزدوج على علامة تبويب يفعل الشيء نفسه. أمّا الاتجاه الذي تركته فيه فيُحفظ لكل محرّر على حدة. يضيف Docs كثافة وسطى: **⌥⌘K** / Ctrl+Alt+K يقلّص الشريط إلى أيقونات فقط، ويُحفظ الاختيار كذلك.

اختصارات كل محرّر على حدة (نسخ التنسيق، بحث واستبدال، عمليات الجداول، ...) مذكورة في فصولها؛ ويضيف Docs نافذة «اختصارات لوحة المفاتيح» (**⌘/**) قابلة للبحث (انظر فصلها).

## اختصارات Option+Command

‏Option+Command هو الطبقة التي يحجزها Word للقفزات المنظّمة، وGenOffice يملأها بالطريقة نفسها. يأخذ Docs معظمها، ويأخذ Sheets اثنين خاصّة به من أجل مطابقة Excel، ويوجد اختصار واحد يعمل في كل المحرّرات.

**Docs**

| الاختصار (macOS) | ما يفعله          | Windows / Linux    |
| ---------------- | ----------------- | ------------------ |
| ⌥⌘1 / ⌥⌘2 / ⌥⌘3  | عنوان 1 / 2 / 3   | Ctrl+Alt+1 / 2 / 3 |
| ⌥⌘0              | عادي              | Ctrl+Alt+0         |
| ⌥⌘M              | فقرة              | Ctrl+Alt+M         |
| ⌥⌘A              | تعليق جديد        | Ctrl+Alt+A         |
| ⌥⌘F              | إدراج حاشية سفلية | Ctrl+Alt+F         |
| ⌥⌘E              | إدراج تعليق ختامي | Ctrl+Alt+D         |
| ⌥⌘G              | الانتقال إلى      | Ctrl+G             |

اختصاران من هذين يتغيّران على Windows، ولعلّة الفصل نفسها التي يفصل بها Word بينها. **macOS يملك ⌥⌘D** — فهو يعرض Dock ويُخفيه — لذا يكون إدراج التعليق الختامي ⌥⌘E على Mac وCtrl+Alt+D في كل مكان آخر. و**الانتقال إلى** يتخلّى عن Alt: ‏Ctrl+G، بينما يحمل اختصار Mac هذا المفتاح.

**Sheets** عندما يكون التركيز على الشبكة

| الاختصار (macOS) | ما يفعله    | Windows / Linux |
| ---------------- | ----------- | --------------- |
| ⌥⌘0              | حدود خارجية | Ctrl+Shift+7    |
| ⌥⌘−              | بلا حدود    | Ctrl+Shift+−    |

Windows ليس إعادة كتابة لزوج مفاتيح الـ Mac. يمنح Excel for Mac إلى Sheets **الاثنين** — ⌘⇧7 و⌥⌘0 مفتاحان لحدود خارجية واحدة — لذلك يبقي الأمر على Windows في مكانة Ctrl+Shift التي كانت له، ببساطة طبقة Option غائبة.

لاحظ أن **⌥⌘0 يعني «عادي» في Docs و«حدود خارجية» في Sheets**. كلاهما لا يظهر في المحرّر نفسه أبدًا، فلا يحدث تعارض في الاستخدام، لكن ⌥⌘0 محجوز ولا يمكن استخدامه كاختصار عام.

**كل محرّر**: **⌥⌘R / Ctrl+F1** يطوي الشريط، كما هو موضّح أعلاه.

وهذا يجعل ⌥⌘D متاحًا لتستخدمه GenOffice على macOS، إن احتاج إليه أمر في المستقبل.
