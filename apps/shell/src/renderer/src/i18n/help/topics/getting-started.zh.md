# 快速入门：界面与基本操作

GenOffice 是一个运行在本机的办公套件：一个窗口、一排标签页，装着文档（Docs）、表格（Sheets）、幻灯片（Slides）、PDF、Markdown 与纯文本、网页（HTML）、韩文文档（HWP/HWPX）和思维导图（.xmind）八个编辑器。每个编辑器打开并保存各自格式的文件：.docx、.xlsx、.pptx、.pdf、.md、.html、.hwp/.hwpx 和 .xmind。编辑文档不需要联网，AI 功能需要。思维导图编辑器还能把 FreeMind 和 Freeplane 文件（.mm）导入为新导图，保存为 .xmind。

## 界面总览

窗口分为三块：

- **顶部标签条**：每个打开的文件是一个标签页。最左边的「主页」标签永远存在、不可关闭；其余标签对应你打开的文档，双击标签可以直接重命名文件。
- **内容区**：当前标签对应的编辑器（或主页）。
- **菜单栏**：macOS 在系统菜单栏，Windows/Linux 在窗口顶部。文件、编辑、视图等菜单会随当前标签切换成对应编辑器的版本。

## 新建文档

三种方式任选：

- 在**主页**的[快速开始](help://getting-started)区点对应的卡片（AI 文档、AI 表格、AI 幻灯片等）。
- 菜单 **文件 ▸ 新建**：Docs（⌘N/ctrl+N）、表格、幻灯片、Markdown、网页、PDF 六种。
- 直接把文件拖进窗口，或双击系统里的文件（若 GenOffice 已设为默认应用）。

新建的文档先以「未命名」状态打开，第一次保存时才会在磁盘上创建文件。

## 打开文件

- 菜单 **文件 ▸ 打开**（⌘O/ctrl+O）弹出系统选择框，支持 .docx / .doc / .odt / .xlsx / .xls / .csv / .tsv / .pptx / .ppt / .pdf / .md / .html。
- 主页的「最近使用」列表直接点开。
- 命令行 `ieumoffice <文件>` 也可以打开（适配脚本）。

## ODT 文档

.odt 文件（OpenDocument 文本，Hancom Office、LibreOffice 等软件保存的格式）在 Docs 标签页中打开，凡是能打开 .docx 的地方都能打开它。新建文档仍是 .docx。

- **照常可用**：编辑文字，字符和段落格式，表格（增删行列、合并与拆分单元格），图片，页眉页脚，脚注尾注，页面设置与分节，项目符号与编号，标题样式，超链接，查找替换，拼写检查，打印，导出 PDF 和 HTML，以及 AI 编辑。
- **ODT 中关闭的功能**：批注，修订，文档比较，水印，墨迹书写，目录，插入公式、形状、文本框或图表，分栏，引文与书目，题注与交叉引用，页面颜色，密码与限制编辑，建议只读，主题字体与颜色，对称页边距。这些按钮会变灰；要使用它们，请另存为 .docx。
- **保持原样**：原文件中的公式、图表和绘图显示为锁定的图片，可以删除但不能修改；锁定的表格单元格仍然锁定。未改动的部分按原样保存。带密码的 ODT 无法打开，请先去掉密码。
- **另存为**可在 .docx 和 .odt 之间选择。切换格式前会列出会改变或丢失的内容，保存后标签页会重新打开新文件。Markdown 和 HTML 也可以**导出为 ODT…**。

## 保存模型

- **手动保存**：⌘S/ctrl+S，或 文件 ▸ 保存 / 另存为。第一次保存会让你选位置和文件名。
- **自动保存**遵循各编辑器的开关（以及应用全局默认值）。只读不改的 PDF 永远不会被悄悄改写；没有文件的新文档要等第一次保存之后才会自动保存。
- 关闭有未保存改动的标签时，会先询问「保存 / 放弃 / 取消」。
- 所有写入都是原子落盘（先写临时文件再改名），中途断电不会留下半个文件。

## 常用快捷键

| 操作       | macOS | Windows / Linux |
| ---------- | ----- | --------------- |
| 新建文档   | ⌘N    | ctrl+N          |
| 打开       | ⌘O    | ctrl+O          |
| 保存       | ⌘S    | ctrl+S          |
| 关闭标签   | ⌘W    | ctrl+W          |
| 打开本手册 | F1    | F1              |
| 折叠功能区 | ⌥⌘R   | Ctrl+F1         |

**折叠功能区**在每个编辑器里都可用：标签行照旧保留，下面的命令条收起；选中的标签同时充当折叠开关，所以功能区折叠期间不会有标签处于选中状态，按任意标签即可让命令条重新出现。双击标签效果相同。折叠与否按编辑器分别记住。 Docs 另有一档中间密度：**⌥⌘K** / Ctrl+Alt+K 把命令条压成仅图标，同样会被记住。

各编辑器内部（格式刷、查找替换、表格操作等）的快捷键见对应章节；Docs 还带一个可搜索的快捷键对话框（**⌘/**）（菜单 视图 或 帮助里的「键盘快捷键」）。

## Option+Command 这一组快捷键

Option+Command 是 Word 留给结构化跳转的层级，GenOffice 也按同样的方式填充。其中大部分归 Docs，Sheets 也有两个自己的快捷键，用来对齐 Excel；另外还有一个组合在所有编辑器里都能用。

**Docs**

| 快捷键（macOS） | 作用           | Windows / Linux    |
| --------------- | -------------- | ------------------ |
| ⌥⌘1 / ⌥⌘2 / ⌥⌘3 | 标题 1 / 2 / 3 | Ctrl+Alt+1 / 2 / 3 |
| ⌥⌘0             | 正文           | Ctrl+Alt+0         |
| ⌥⌘M             | 段落           | Ctrl+Alt+M         |
| ⌥⌘A             | 新建批注       | Ctrl+Alt+A         |
| ⌥⌘F             | 插入脚注       | Ctrl+Alt+F         |
| ⌥⌘E             | 插入尾注       | Ctrl+Alt+D         |
| ⌥⌘G             | 定位           | Ctrl+G             |

其中两个在 Windows 上会变，原因和 Word 拆分它们的一样。**macOS 占用了 ⌥⌘D**——它用来显示和隐藏 Dock——所以尾注在 Mac 上是 ⌥⌘E，在其他地方是 Ctrl+Alt+D。而**定位**则省掉了 Alt：Mac 上的组合键带着 Alt，Windows 上只要 Ctrl+G。

**Sheets**（网格获得焦点时）

| 快捷键（macOS） | 作用     | Windows / Linux |
| --------------- | -------- | --------------- |
| ⌥⌘0             | 外侧框线 | Ctrl+Shift+7    |
| ⌥⌘−             | 无框线   | Ctrl+Shift+−    |

Windows 并不是把 Mac 上那两个组合改写一遍。Excel for Mac 给 Sheets **两套都有**——⌘⇧7 和 ⌥⌘0 是同一种外侧框线的两个按键——所以在 Windows 上这个命令保留它本来就有的 Ctrl+Shift 位置，而 Option 这一层干脆就不存在。

注意 **⌥⌘0 在 Docs 里是「正文」，在 Sheets 里是「外侧框线」**。两者不会出现在同一个编辑器里，所以实际使用不会冲突；但 ⌥⌘0 已经被占用，不能再作为全局快捷键。

**所有编辑器**：**⌥⌘R / Ctrl+F1** 按上文所说的折叠功能区。

这样一来，macOS 上的 ⌥⌘D 就空着留给 GenOffice，将来若有命令想用，随时可以拿。
