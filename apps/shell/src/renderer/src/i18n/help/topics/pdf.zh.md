# PDF：阅读、注释与涂黑

PDF 编辑器有五个功能区标签：**开始 / 注释 / 编辑 / 页面 / 视图**。它既能读也能改：文字可以编辑、可以涂黑（redact）、可以签名、可以填表单。

## 阅读与导航

- 左侧栏：**缩略图**（点击跳页、显示当前可见范围）或**大纲**（书签目录，有则显示）。
- 缩放：右下角比例控件，ctrl+滚轮逐档缩放。
- 移动视图：开启**抓手工具**（开始、视图选项卡）后，拖动即可上下左右移动页面。开启期间拖动不会选中文字，单击链接仍会打开。按住鼠标中键（滚轮）拖动，不开工具也能移动。按 Esc 或选择其他工具即关闭。
- 页面旋转：页面菜单里逐页/全部旋转，旋转在保存时写回文件。
- 搜索：ctrl+F 全文查找，高亮所有命中。
- 加密 PDF：打开时弹出密码框（独立小窗），只在本会话使用。 这类文档也可以编辑和保存，保存后密码保持不变。在 **注释 → 保护** 中可以设置、更改或移除密码以及读者可执行的操作。

## 文字选择与标注（注释 ▸ 高亮家族）

试一下（对着任意一段文字）：

1. 在正文上**按住鼠标拖过一句话**——松开后文字上方浮出标注条：

![选中文字后浮出的标注条](img/pdf-highlight.png)

2. 点标注条上三种 **高亮** 颜色之一，或 **下划线**、**波浪线**、**删除线**。要更换高亮颜色，右键点该颜色再选新颜色。画完下划线、波浪线或删除线后，标注条会展开一排颜色：点另一种颜色即可更换，之后也会用这个颜色。点 **问 AI** 则把选中文字连同问题发给 AI 面板。
3. 想撤销某条标注：再对同一段文字拖选一次，点弹条上对应的已生效按钮即可取消（Word 式开关）；或选中后按 Delete。

其他要点：

- 在正文上拖选一段文字，文字上方会浮出标注条：**高亮 / 下划线 / 删除线 / 复制 / 问 AI**。
- 已保存进文件的标注同样可选中外删（⋯ 菜单或 Delete）。
- **注意**：绘图工具（见下）处于激活状态时文字层不可选——放置完一个图形后工具自动解除，回到选择模式即可继续选字。
- 标注颜色可在色板里选；**再次对同一段落点同一个标注 = 取消**（Word 式开关）。

## 绘图工具（注释 ▸ 绘图）

六个工具：**墨迹（手绘）、矩形、椭圆、箭头、便签**，以及注释页签里的**涂黑框**。

- 每个工具是开关按钮：点一下激活，**放置完一个图形自动解除**（想连续画就再点一次工具）；再点激活中的工具也是解除。
- 墨迹按笔宽绘制；矩形/椭圆/箭头拖拽画出；颜色用绘图色板。
- 画好的图形可以：选中后删除、拖动移动、（矩形/椭圆）拉伸调整大小。
- **涂黑（redact）完整流程**（以藏住一行文字为例）：

  1. 注释页签 ▸ 点 **涂黑区域**（工具变为激活态）。
  2. 在要藏住的内容上**拖出一个框**——框内文字被斜纹标记盖住，工具栏同时出现 **取消标记 / 应用涂黑** 两个按钮。

  3. 点 **应用涂黑**，确认后 GenOffice 另存一份工作副本并打开它——被涂区域的文字与图像从文件里**物理删除**（不是盖黑块），无法恢复；原文档保持不动。

  画错了就用 **取消标记**（清除当前所有标记）再重画。

## 便签与评论线程

- **便签工具**：点页面放置一枚图钉，在页边卡片里输入内容（作者名可设置），确认后保存为标准 PDF 文本注释。
- 点图钉展开线程：可**回复**（回复平铺成一列，不嵌套）、**编辑**自己的评论、**删除**整条或整个线程。
- 编辑中的评论在自动保存前会保留；保存把新文字写回文件里同一条注释（保留回复关系）。

## 编辑 PDF 内容（编辑页签）

- **编辑文字**：点文字进入编辑，逐块修改（引擎为 pdfium，复杂字体尽力匹配）。
- **插入文字**：在指定位置插入可搜索的文字（选择字体、大小、颜色）。
- **插入图片 / 图章**：放置图片或盖章。
- 表单：AcroForm 字段可直接填写；填写结果随保存写入。

## 签名

- **墨迹签名**：手绘签名，可关联到表单签名字段。
- **图片签名**：用一张图片作为签名放置。
- 签名保存后可重复使用。
- **证书签名**（注释页签）：用系统证书库或 .p12/.pfx 证书文件签名；可选择在页面上显示签章，也可以认证文档以限制后续修改。
- 签名总是写出一个 **新文件**（增量更新——之前的签名仍然有效），并在原位打开签名副本。先保存：签名覆盖的是磁盘上已保存的文件。
- 文档上方的横幅列出已有签名；**查看签名** 展示每个签名的有效性、覆盖范围和证书链。吊销状态（CRL/OCSP）不检查。

## 页面操作（页面页签）

- **旋转 / 删除 / 重排**：缩略图栏拖拽重排；删除有确认。
- **导入页面**：从别的 PDF 拉页面进来。**插入空白页**补一张空页。
- **替换页面** 把一整段页面换成从别处来的页面；**裁剪页面** 裁掉边距，可选对全部页面生效。
- **页面大小** 把所有页面缩放到同一种纸张尺寸；**倒序排列** 把文档从头到尾整个翻过来。
- **提取页面**：把选中页导出成新 PDF。
- **拆分**：两种形态——按范围拆成多个文件，或把每一页切成更小页面的网格。
- **合并**：两种形态——追加其他 PDF，或把多页并到同一张纸上。合并前会先统计所有文件的总大小，**超过 1 GiB 拒绝**并提示（防止一次性把内存吃光）。
- 页面级的修改在下次保存写回文件；工作副本另存不覆盖原件。

## 导出与打印

- **导出为 Word… / PPT… / Excel…** 可在「文件」菜单里选，也可从功能区的 **PDF 转换** 里选同样这三项——全部在本地完成，不会上传。.pptx 按每页一张幻灯片导出，.xlsx 按每页一个工作表导出。每一种都会询问保存位置。
- **打印**：按当前顺序与旋转走系统打印；可选页范围。

## 保存

- 普通 保存/自动保存 把注释与编辑写回原文件（原子写）。
- **涂黑走「应用」流程**生成副本，原文档不动，避免把敏感内容留在原文件里。

## 选择条快捷键

选中文字、标注条出现时，按一个键就能直接执行。

| 键    | 作用                       |
| ----- | -------------------------- |
| H     | 高亮（已高亮的地方则取消） |
| U     | 下划线                     |
| S     | 删除线                     |
| N     | 在选区末尾添加便笺         |
| E     | AI 解释（段落卡片）        |
| T     | AI 翻译（段落卡片）        |
| Enter | 打开 **问 AI** 输入框      |

- 开着韩文或其他输入法时，同一个键也做同样的事。正在输入框里打字，或按住 Ctrl、Alt 时，不当作快捷键。
- 在禁止编辑的文档（所有者密码禁止修改的文档）中，H、U、S、N 不起作用，并像标注条上的按钮一样显示原因。

## 段落卡片

按 **E** 或 **T**，或点 **问 AI** 框里的解释、翻译小标签，AI 的回答会以小卡片显示在选区旁边。卡片会保存下来，重新打开文档也还在，也可以复制。再次询问同一段文字时，不会发给 AI，而是打开已有的卡片。

- **留作批注**：在那个位置建一条便笺。第一行写着"AI 解释"或"AI 翻译"，作者是你的电脑账户名。保存 PDF 时才写进文件，在那之前卡片上显示"等待保存"。
- **在 AI 面板中继续提问** 把这段文字和回答交给 AI 面板（不会立即发送）；**加入笔记** 把它们放到这个 PDF 的笔记末尾。
- 只有点 **重新生成** 才会再次发给 AI。
- **删除** 只删除保存的卡片，已经留下的便笺不受影响。
- 有卡片的文字下方会画一条淡淡的虚线，点它会再次打开卡片。虚线只显示在屏幕上，不会保存或打印。可在 视图 ▸ **段落标记** 中开关。

## 批注一览

- 点 视图 ▸ **批注**，左侧边栏会把本文档的高亮、下划线、删除线、便笺、绘图，尚未保存的标注，以及段落卡片列在一个列表里。高亮等标注还会显示其下方的文字。
- 可按类型、颜色、页码范围、文字筛选，并按页码顺序或创建顺序排序。
- 点某一项会跳到那里并短暂闪烁。便笺会打开页边的讨论，卡片会打开卡片。
- 面板菜单中的 **复制为 Markdown**、**以 Markdown 文档打开**、**以 Word 文档打开** 使用当前筛选后的列表，不调用 AI。只有在 GenOffice 里打开的 PDF 才能新建文档。

## 译文对照

- 打开 视图 ▸ **译文对照** 后，每页右侧会出现译文栏并随原文一起滚动。仅仅打开不会向 AI 发送任何内容。已经用 **文档翻译** 译过的文档会立即显示译文，没有译文的段落以淡色原文显示。
- **翻译此页**（只译了一部分时为 **翻译剩余段落**）在使用订阅时按一下就发送这一页，按钮旁会显示要发给哪个 AI。若连接按用量收费，在一个标签页里第一次按时会先询问"将对此收费 · 翻译 / 取消"。
- 双击译文段落即可直接修改。改过的段落以无格式文字保存，并原样用于翻译后的 PDF、Markdown、EPUB。段落上的 **重新翻译** 只发送这一段；如果是改过的段落，会先询问。
- 鼠标移到译文段落上时，原文中对应的位置会出现边框。译文栏的宽度和字号可以调整。**翻译所有页面…** 会打开 **文档翻译** 窗口，其中的 **仅保存（不生成文件）** 格式只留下译文，不写文件。
- 新翻译的段落按句子一一对应。将鼠标移到译文的某一句上，原文页面上的对应句子会被标出；移到原文句子上，对应的译文句子会高亮。在页面上找不到句子位置的地方、以前翻译的段落和你修改过的段落，仍按段落对应。
- 栏上方的工具条可以在 **翻译** 和 **通俗解释** 之间切换。通俗解释用日常用语和短句改写原文，方便儿童、老年人或正在学这门语言的人阅读；事实、数字和名称保持不变。所选方式会被记住，切换本身不会发送任何内容。显示解释时，页面和段落按钮以及编辑都作用于解释。
- 在通俗解释下，**通俗解释所有页面…** 会打开 **文档翻译** 窗口，方式已选为 **通俗解释**。解释比原文长，放不进原来的位置，所以不能生成翻译 PDF，只能写成 Markdown 或 EPUB。勾选 **原文后附解释** 时，每段原文后面跟着它的解释；不勾选时文件里只有解释。语言一开始是界面语言，也可以和文档的语言相同。

## AI 重点标注

- 在 开始 ▸ **AI 重点标注** 中选择分类组（研究·报告、合同·条款、教材·说明书、自定义）和页码。确认预计调用次数和要发给哪个 AI 并按 **开始** 之前，不会发送任何内容。
- AI 选出的句子会以半透明色框预览在页面上。预览不会保存到文件，可在 视图 ▸ **重点标注预览** 中开关。
- 在 **批注** 面板中逐条 **接受** 或 **舍弃** 建议，也可以按分类全部接受。在页面文字中找不到的句子无法接受。
- 接受的建议会变成该分类颜色的高亮，分类名作为批注主题保存，其他 PDF 阅读器的批注列表里也能看到。保存 PDF 时才写进文件。
- 禁止编辑的文档中无法开始。AI 编造的、原文中没有的句子会被丢弃，结束时会告诉你收到多少条、丢弃多少条。

## 文档概览与段落引用

- 点 AI 面板顶部的 **文档概览** ▸ **生成概览**，会生成三句话摘要、摘要和关键术语（含义及首次出现的页码）。长文档会分段摘要，所以会先请你确认预计调用次数。
- 概览会保存下来，重新打开也还在；只有点 **重新生成** 才会再次发送。点术语会在文档中查找，每一栏都可以复制或 **加入笔记**。
- 对话为空时，AI 面板会给出三个推荐问题，点一下就发送一次。
- 点 AI 作为依据给出的页码链接（p.N），会跳到那一页并把引用的句子高亮两秒。找不到句子时只跳到那一页。

## 每个 PDF 一份笔记

- 第一次点视图选项卡或 **批注** 面板里的 **打开笔记** 时，会弹出保存对话框。默认位置是 PDF 所在的文件夹，默认文件名是"PDF 名称 笔记.md"。之后会直接在 Markdown 标签页中打开。
- 如果选择已有的文件，Windows 可能会询问是否替换，但文件不会被覆盖，而是原样作为笔记关联起来。
- **加入笔记**（卡片、批注面板的条目、文档概览）会在笔记标签页的文档末尾加入引用和页码链接，并保持未保存状态，由你在笔记标签页里保存。这个链接在浏览器等其他程序中也会打开到那一页。
- 从未保存过的 PDF 会显示"请先保存 PDF"。笔记只能用于在 GenOffice 里打开的 PDF。
