# スキル

スキルは AI に渡す作業手順書です。何度も繰り返す作業——会議メモをまとめる手順、報告書の文体、毎回確認するポイント——を一度書いておけば、AI パネルから呼び出せるほか、合うときには AI が自分で取り出して使います。スキルは `SKILL.md` ファイルの入ったフォルダーで、オープンな形式なので、GenOffice で作ったスキルは Claude Code や Codex でもそのまま使えます。

## スキルのオン・オフ

**設定 ▸ スキル** には、この PC にあるスキルが提供元ごとにまとめて表示されます。スキルはコーディングエージェントと同じように名前で表示されます。上の検索欄で、名前・説明から探せます。

| 提供元                      | 中身                                                   | 最初の状態 |
| --------------------------- | ------------------------------------------------------ | ---------- |
| **標準**                    | GenOffice に付属する 5 つのスキル                      | オン       |
| **マイスキル**              | 追加したスキルや作ったスキル（`~/.ieumoffice/skills`） | オン       |
| **Claude スキルフォルダー** | `~/.claude/skills` にあるスキル                        | オフ       |
| **Claude プラグイン**       | インストール済みの Claude プラグインのスキル           | オフ       |
| **Codex スキルフォルダー**  | `~/.agents/skills` にあるスキル                        | オフ       |

- スイッチでスキルをオン・オフします。この設定は、各エディターの AI パネル、ホームの AI に質問、エージェントウィンドウのすべてに同じように適用されます。
- オンのスキルでは **AI に任せる** か **呼び出したときだけ** を選びます。最初は AI に任せるです。呼び出したときだけにすると、自分で呼び出したときにしか使われません。
- 提供元が違えば、同じ名前のスキルが並ぶこともあります。各行の提供元の表示で見分けます。
- その他のメニューには **内容を見る**、**編集**（マイスキルのみ）、**エクスポート (zip)**（マイスキルのみ）、**フォルダーを開く** があります。
- **ごみ箱に移動** は、マイスキルのスキルをシステムのごみ箱に移します。ごみ箱から元に戻せます。
- 標準スキルは削除できない代わりに、**非表示にする** を選びます。一覧のいちばん下の **再表示** で、最初の状態のまま戻ります。
- 標準スキルやほかのプログラムのスキルを変えたいときは、**マイスキルにコピー** を選びます。コピーがマイスキルに作られ、元のスキルはオフになります。
- テンプレート付きのスキルをエクスポートすると、テンプレートの文書も zip に入ります。エクスポートする前に、文書に個人情報が入っていないか確認してください。

## スキルを追加する

1. **設定 ▸ スキル** で **追加** を押します。
2. **フォルダーから**、**zip ファイルから**、**GitHub リンクから** のどれかを選びます。GitHub の場合は、公開リポジトリのアドレスか `owner/repo` を入力して **検索** を押します。
3. プレビューで、見つかったスキルを確認します。ファイルの数とサイズ、スクリプトの有無、本文中の Web アドレス、ライセンスファイルが表示されます。
4. インストールするスキルだけにチェックを入れて、**インストール** を押します。インストールしたスキルはオンの状態で始まります。

プレビューの下には、いつも「信頼できる提供元のスキルだけをインストールしてください。スキルは AI に指示を与え、エージェントウィンドウではスクリプトを実行できます」と表示されます。出どころの分からないスキルは、インストールする前に中身を読んでください。

- マイスキルに同じ名前のスキルがすでにある場合は、その行で **置き換える** か **スキップ** を選びます。
- GitHub からダウンロードするとき、GenOffice が接続するのは `github.com`、`api.github.com`、`codeload.github.com` だけで、サインイン情報は送りません。アーカイブが大きすぎるか安全チェックを通らなかった場合は、何もインストールされません。
- **新規作成** を押すと空のエディターが開き、名前・説明・本文を自分で書けます。

## 更新を確認する

- GitHub からインストールしたスキルは、その他のメニューの **更新を確認** で新しい内容があるかを調べます。GitHub に接続するのは、これを押したときだけです。
- 変更がなければ「最新です」と表示されます。変更があれば、変更されたファイルとプレビューを確かめてから **更新** を押します。
- インストール後に自分でスキルを編集していた場合は、「自分で加えた編集は失われます」も表示されます。
- 更新しても、スキルのオン・オフと、AI に任せる / 呼び出したときだけ の選択はそのまま残ります。

## AI パネルでスキルを呼び出す

1. AI の入力欄の先頭か、スペースの直後で `/` または `$` を入力します。オンになっているスキルの一覧が出ます。
2. 続けて入力すると一覧が絞り込まれます。たとえば `/meet` で `meeting-minutes` が見つかります。説明に含まれる言葉でも探せるので、`/議事録` でも見つかります。
3. 矢印キーで選び、Enter か Tab を押します。スキルが入力欄の上にチップとして付きます。
4. してほしいことを書いて送信します。GenOffice がスキルの内容を依頼に添えます。

- Excel の AI パネルでは、`$` で一覧が開くのは入力欄のいちばん先頭だけです。`$A$1` のようなセル参照の入力を邪魔しないためです。
- チップは複数付けられ、× で外せます。Esc は一覧を閉じるだけで、実行中の AI は止めません。
- 一覧のいちばん下の **スキルを管理…** を押すと **設定 ▸ スキル** が開きます。
- チップは送信したメッセージにも、保存した会話にも残ります。会話を開き直してもう一度送信すると、スキルの今の内容があらためて読み込まれます。その間にスキルが削除されたりオフになったりしていると、チップに「なし」と表示されます。
- 一緒に送るスキルの文章が長すぎると、「スキルが大きすぎるため一緒に送信できません」と表示され、何も送信されません。

## AI が自分で使うスキル

- オンで AI に任せるにしてあるスキルは、名前と説明が一覧として AI に渡されます。依頼に合うスキルがあれば、AI がその内容を取り出して使います。
- AI がスキルを使うと、会話に「〈名前〉 スキルを使いました」と表示されます。
- AI は説明を見て、スキルを使うかどうかを決めます。どんなときに使うスキルなのかを説明に書いておくと、AI が的確に選べます。

## 頼んでスキルを作る

1. AI パネルで「今やったことをスキルとして保存して」「うちの書式で報告書を書くスキルを作って」のように頼みます。
2. AI が繰り返す価値のある手順やルールを拾い出し、**スキルを作成** のカードを表示します。名前や日付のように今回だけ使った値は、手順には入りません。
3. カードで名前・説明・本文を確かめて直します。名前はスキル一覧に表示され、`/` のあとに入力して呼び出すもので、英小文字・数字・ハイフン(-)で書きます。
4. **保存** を押します。新しいスキルはオンの状態でマイスキルに加わり、すぐに `/` の一覧に出ます。

- **保存** を押すまで、ファイルは何も書き込まれません。**キャンセル** を押すと、会話には「保存していないスキルの提案」としてだけ残ります。
- 「議事録のスキルをうちのやり方に変えて」のように、今あるスキルの変更も頼めます。このときカードのタイトルは **スキルを修正** になります。マイスキルのスキルは **置き換え** で上書きされます。標準スキルやほかのプログラムのスキルは、マイスキルにコピーとして保存され、元のスキルはオフになります。

## 文書をテンプレートとして付ける

エディターの AI パネルでスキルを作るとき、今の文書をテンプレートとして一緒に付けられます。カードの **この文書をテンプレートとして一緒に保存** にチェックを入れると、ボタンが 2 つになります。

- **空のテンプレートを作る**: 文書のコピーが新しいタブ「テンプレートのプレビュー - 〈title〉」で開き、そのタブの AI が名前・日付・個人情報などの記入済みの値を消します。タブを見直し、必要なら手で直してから **このタブをテンプレートとして保存** を押すと、その時点のタブがテンプレートになります。
- **元の文書のまま保存**: 今の文書をそのままテンプレートとして保存します。文書に AI から隠した部分があるとこのボタンは使えなくなり、隠した内容がそのままテンプレートに入ることはありません。
- テンプレートは、文書のコピーとしてスキルのフォルダーの中に保存されます。元の文書は変わりません。

## テンプレート付きのスキルを使う

- テンプレート付きのスキルは、一覧に **テンプレートあり** と表示されます。
- チップとして呼び出して送信すると、テンプレートのコピーが無題の新しい文書として開き、そのタブの AI が依頼の続きを進めます。元のパネルには「新しいタブでテンプレートを使って作業します」と **タブへ移動** が残ります。
- AI が自分でテンプレート付きのスキルを選んだ場合は、すぐにはタブを開きません。代わりに会話に **このテンプレートで新しい文書を開く** ボタンが表示されます。
- 新しい文書の保存先は、ふつう最初に保存するときに自分で決めます。ただし Markdown エディターと HTML エディターでは、これまでどおり既定のフォルダーに保存します。テンプレートのファイル自体は元のままです。

## スクリプト付きのスキル

- 通常の AI パネルとホームの AI に質問では、スキルのスクリプトは決して実行されません。AI に渡るのはスキルの文章だけです。
- スクリプト付きのスキルには **スクリプトあり · エージェントウィンドウで完全に動作** と表示され、チップとして付けると「このスキルのスクリプトは通常の AI ウィンドウでは実行されません」と表示されます。送信は止められません。
- スクリプトも使いたいときは、エージェントウィンドウでそのスキルを呼び出してください。[エージェントモード](help://agent-mode)をご覧ください。

## 標準スキル

| スキル            | できること                                                           |
| ----------------- | -------------------------------------------------------------------- |
| `meeting-minutes` | 会議のメモを、決定事項とやることが分かる議事録にまとめます           |
| `internal-comms`  | お知らせ、社内報、進捗報告、FAQ など組織内の文章を書きます           |
| `humanizer`       | 文章から AI が書いたような表現を探し、自然に直します                 |
| `copy-editing`    | 書き上げた英語の文章を見直し、より明確で簡潔にします                 |
| `find-skills`     | エージェントウィンドウで必要なスキルを探し、インストールを提案します |

`copy-editing` は英語のマーケティング文章向けに作られています。`find-skills` はエージェントウィンドウでしか使えません。

## エージェントウィンドウでは

- エージェントウィンドウも **設定 ▸ スキル** のオン・オフに従い、入力欄で `/` や `$` を使ってスキルを呼び出す方法も同じです。
- プロジェクトフォルダーの `.claude/skills` と `.agents/skills` にあるスキルは、オンにしなくてもそのセッションで使われます。
- スキルの一覧はセッションを始めた時点で決まります。セッションの途中でスキルをオン・オフすると、「変更したスキルは次のセッションから反映されます」と表示されます。
- エージェントがスキルを作るときも、ウィンドウに同じカードが出ます。テンプレートは、タブで開いている文書とプロジェクトフォルダー内のファイルから選びます。
- エージェントがインストールする価値のあるスキルを見つけると、インストールの提案が出ます。**プレビューを開く** で開き、自分で **インストール** を押さない限り、何もインストールされません。インストールしたスキルは次のセッションから使えます。
