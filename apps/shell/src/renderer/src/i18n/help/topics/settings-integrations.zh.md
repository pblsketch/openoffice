# 设置、语言、主题与 MCP 集成

## 打开设置

主屏左下角的那一行打开设置面板（还没有连接 AI 时显示为「连接 AI」）。面板共五个分区：账户、AI、通用、集成、关于。

**账户**显示你的 Claude 和 Codex 订阅当前的状态，**管理连接**会带你到 AI 分区。AI 有专门的两篇说明：[订阅连接](help://subscription)和 [AI 模型与设置](help://ai-models)。

## 语言

- 设置里可选 **21 种界面语言**：简体中文、English、日本語、한국어、Français、Deutsch、Español、ไทย、Bahasa Indonesia、Русский、العربية、Português、Italiano、Polski、Čeština、Nederlands、Bahasa Melayu、עברית、हिन्दी、繁體中文、Tiếng Việt。
- 切换立即生效并持久化；菜单栏（主进程菜单）随语言重建。

## 主题

浅色 / 深色 / 跟随系统三种。跟随系统时随 OS 外观自动切换，编辑器区域同步换肤，无闪白。

## 通用

- **AI 侧边栏位置**（左或右）、**AI 面板文字大小**和**AI 对话拼写检查**。
- **新文档中打开 AI 面板** —— 关闭，新文档开始时面板是收起的，点一下就到。
- **所有文档自动保存** 会让每个编辑器默认开启自动保存；单个窗口仍然可以关掉。
- **默认保存位置**配**更改**按钮，以及**设为 Office 文档默认程序**，把 .docx / .xlsx / .pptx 交给 GenOffice 处理。

GenOffice 不收集也不发送使用统计，所以这里没有相应的开关。

## AI ▸ 高级

默认是收起的，要你自己展开；大多数人用不到它。**AI 模型**页签里是对话用的 API 密钥和你自己运行的服务器。在**生图、媒体与搜索**页签里，每项能力自己挑提供它的服务商，服务商的密钥和基础地址只填一次，之后各行共用：

- **网络搜索**、**生图**、**图片解析**和**视频解析**，每项都有服务商、模型、密钥和基础地址。
- **本机文件搜索**跑在这台机器上。它下面的 **Jev 搜索重排** 默认关闭。打开后，本机搜索前 20 条命中的片段——每份文档最多 1,200 个字符，外加文件名和文件夹名——会发给你选择的决策端点（OpenRouter 或 TypeSafe 的 Jev、Perplexity、Liquid AI d1、Cloudflare、本地引擎或自定义 URL），按相关性重新排序。关闭时不会有任何东西离开本机。
- **允许自动调用使用订阅**这一项**默认关闭**。它决定来自命令行或已连接的编程代理的请求，能否使用你的 Claude 或 Codex 订阅；见[连接编程助手](help://mcp)。

## 关于

- **版本**、项目的 GitHub 地址，以及一行说明，写明本应用所基于的开源项目。
- **更新通道**：稳定版或 Beta 版。改完立即生效并检查更新；它不会把 Beta 版安装退回稳定版。

## 默认应用绑定

设置里可以把 .docx / .xlsx / .pptx / .pdf 等格式关联为「由 GenOffice 打开」（写入系统级别的默认应用注册，按平台提示确认）。

## 第三方声明与更新

- 帮助菜单 ▸ 第三方软件声明：随包附带的完整开源组件许可清单。
- 菜单（☰） ▸ 检查更新（Mac 上为 帮助菜单 ▸ 检查更新）：手动触发一次更新检查；有新版本时提示安装。

## MCP 集成（面向高级用户 / AI 客户端）

**集成**是把 GenOffice 接到编程代理上的面板，它也有专门一章：连接编程代理。简单说就是——选一条路子（命令行或 MCP），照那一节做，然后开一个新对话直接问。

在**本地 HTTP 服务**下，应用也可以自己来跑这个服务——一个启用开关、一个端口——而**高级**会再加上健康检查的网址和日志文件——而不是交给助手去做。它只监听 localhost。

## 命令行速查

| 命令                | 作用                |
| ------------------- | ------------------- |
| `ieumoffice <file>` | 打开文件            |
| `ieumoffice mcp`    | 启动本机 MCP 服务器 |
| `ieumoffice --help` | 全部命令与参数      |
