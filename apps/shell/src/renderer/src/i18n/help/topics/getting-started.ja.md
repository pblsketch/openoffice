# クイックスタート：画面と基本操作

GenOffice は自分のマシン上で動くオフィススイートです。ウィンドウ 1 つ、タブの列 1 行に 8 種類のエディター — Docs（文書処理）、Sheets（表計算）、Slides（プレゼンテーション）、PDF、Markdown とテキスト、HTML、HWP/HWPX（ハングル文書）、マインドマップ（.xmind）— が入っています。各エディターはそれぞれの形式のファイルを開いて保存します（.docx、.xlsx、.pptx、.pdf、.md、.html、.hwp/.hwpx、.xmind）。編集にネットワークは不要ですが、AI 機能には必要です。マインドマップエディターは FreeMind・Freeplane のファイル（.mm）も新しいマップとして読み込み、.xmind で保存します。

## 画面の全体像

ウィンドウは 3 つの部分に分かれています。

- **タブバー（上）**：開いているファイルがそれぞれ 1 タブになります。一番左のホームタブは常に存在し、閉じられません。残りのタブが、開いている文書です。タブをダブルクリックすると、ファイル名をその場で変更できます。
- **コンテンツエリア**：アクティブなタブに対応するエディター（またはホーム）。
- **メニュー**：macOS ではシステムメニュー、Windows/Linux ではウィンドウ上部にあります。ファイル／編集／表示の各メニューは、現在のタブのエディターに合わせて切り替わります。

## 文書を作る

以下のいずれかで作成できます。

- **ホーム**の[クイックスタート](help://getting-started)欄にあるクイック作成カード（AI Docs、AI Sheets、AI Slides など）をクリックする。
- メニュー **ファイル ▸ 新規作成**：Docs（⌘N/ctrl+N）、Sheets、Slides、Markdown、HTML、PDF。
- ファイルをウィンドウにドラッグする。あるいは、ファイルマネージャーでダブルクリックする（GenOffice が既定のアプリになっている場合）。

作成した文書は「無題」の状態で開かれ、ディスク上のファイルは最初に保存したときに初めて作られます。

## ファイルを開く

- メニュー **ファイル ▸ 開く**（⌘O/ctrl+O）でシステム標準の選択ダイアログが開きます。.docx / .doc / .odt / .xlsx / .xls / .csv / .tsv / .pptx / .ppt / .pdf / .md / .html に対応しています。
- ホームの**最近使用**リストから任意の項目をクリックする。
- ターミナルで `ieumoffice <file>` と入力しても開けます。

## ODT 文書

.odt ファイル（OpenDocument テキスト。Hancom Office や LibreOffice などが保存する形式）は Docs タブで開きます。.docx を開ける場所ならどこからでも開けます。新規文書は引き続き .docx です。

- **いつも通り使えるもの**：文字の編集、文字書式と段落書式、表（行・列の追加と削除、セルの結合と分割）、画像、ヘッダーとフッター、脚注と文末脚注、ページ設定とセクション、箇条書きと段落番号、見出しスタイル、ハイパーリンク、検索と置換、スペルチェック、印刷、PDF・HTML への書き出し、AI による編集。
- **ODT ではオフになるもの**：コメント、変更履歴、比較、透かし、インク、目次、数式・図形・テキストボックス・グラフの挿入、段組み、引用文献と文献目録、図表番号と相互参照、ページの色、パスワードと編集の制限、読み取り専用の推奨、テーマのフォントと色、見開きページの余白。これらのボタンは押せません。使うには .docx として保存してください。
- **元のまま残すもの**：元の文書の数式・グラフ・図形はロックされた画像として表示され、削除はできますが編集はできません。ロックされた表のセルもロックされたままです。手を加えていない部分は変わらずに保存されます。パスワード付きの ODT は開けないので、先にパスワードを外してください。
- **名前を付けて保存**では .docx と .odt を選べます。形式を切り替える前に、変わる点や失われる点を一覧で示し、保存後にタブを新しいファイルで開き直します。Markdown と HTML でも **ODT として書き出す…** が使えます。

## 保存の仕組み

- **手動保存**：⌘S/ctrl+S、または ファイル ▸ 保存／名前を付けて保存…。最初の保存では、保存先とファイル名を尋ねられます。
- **自動保存**は各エディターの切り替え（およびアプリ全体の既定値）に従います。読むだけの PDF が黙って書き換えられることはなく、ファイルのない新規文書は最初の保存を済ませてから自動保存されます。
- 未保存の変更があるタブを閉じようとすると、先に保存／破棄／確認のいずれにするか尋ねられます。
- 書き込みはすべてアトミック（一度一時ファイルに書いてからリネーム）なので、電源が落ちても半端なファイルが残ることはありません。

## よく使うショートカット

| 操作                 | macOS | Windows / Linux |
| -------------------- | ----- | --------------- |
| 新規文書             | ⌘N    | ctrl+N          |
| 開く                 | ⌘O    | ctrl+O          |
| 保存                 | ⌘S    | ctrl+S          |
| タブを閉じる         | ⌘W    | ctrl+W          |
| このマニュアルを開く | F1    | F1              |
| リボンを折りたたむ   | ⌥⌘R   | Ctrl+F1         |

**リボンの折りたたみ**はすべてのエディターで使えます。タブの行はそのまま残され、その下のコマンドバンドだけが隠れます。選択中のタブが折りたたみの操作も兼ねるので、リボンが折りたたまれている間はタブが選択されておらず、どのタブを押してもバンドが戻ります。タブをダブルクリックしても同じです。どちらの状態に残したかはエディターごとに記憶されます。 Docs には中間の密度もあります：**⌥⌘K** / Ctrl+Alt+K でコマンド帯をアイコンのみに圧縮でき、同じように記憶されます。

各エディター内部のショートカット（書式のコピー、検索と置換、表の操作など）はそれぞれの章で説明しています。Docs には検索できるキーボードショートカットのダイアログも付いています（**⌘/**）（Docs の章を参照）。

## Option+Command のショートカット

Option+Command は Word が構造化されたジャンプのために空けている層で、GenOffice も同じように埋めています。その大半は Docs が使い、Excel との互換のために Sheets が独自のものを 2 つ確保しています。どのエディターでも使えるものが 1 つあります。

**Docs**

| ショートカット (macOS) | 内容             | Windows / Linux    |
| ---------------------- | ---------------- | ------------------ |
| ⌥⌘1 / ⌥⌘2 / ⌥⌘3        | 見出し 1 / 2 / 3 | Ctrl+Alt+1 / 2 / 3 |
| ⌥⌘0                    | 標準             | Ctrl+Alt+0         |
| ⌥⌘M                    | 段落             | Ctrl+Alt+M         |
| ⌥⌘A                    | 新しいコメント   | Ctrl+Alt+A         |
| ⌥⌘F                    | 脚注の挿入       | Ctrl+Alt+F         |
| ⌥⌘E                    | 文末脚注の挿入   | Ctrl+Alt+D         |
| ⌥⌘G                    | ジャンプ         | Ctrl+G             |

このうち 2 つは Windows で変わります。Word が分けているのと同じ理由です。**⌥⌘D は macOS の持ち物**で、Dock の表示と非表示に使われるため、文末脚注は Mac では ⌥⌘E、それ以外の場所では Ctrl+Alt+D になります。また **ジャンプ** は Alt を落とします。Mac 側のショートカットが Alt を持っている代わりに、Windows では Ctrl+G だけでよいわけです。

**Sheets**（グリッドにフォーカスがあるとき）

| ショートカット (macOS) | 内容   | Windows / Linux |
| ---------------------- | ------ | --------------- |
| ⌥⌘0                    | 外枠   | Ctrl+Shift+7    |
| ⌥⌘−                    | 枠なし | Ctrl+Shift+−    |

Windows は Mac 側の 2 つを書き直したものではありません。Excel for Mac は Sheets に**両方**を与えます — ⌘⇧7 と ⌥⌘0 は同じ外枠への 2 つのキーです — そのため Windows ではこのコマンドはもともと持っていた Ctrl+Shift の位置をそのまま保ち、Option の層は単純に存在しません。

**⌥⌘0 は Docs では標準、Sheets では外枠を意味します**という点は注意してください。両者が同じエディターに現れることはないので実際に衝突することはありませんが、⌥⌘0 は使用済みで、グローバルショートカットとしては使えません。

**すべてのエディター**: **⌥⌘R / Ctrl+F1** はリボンを折りたたみます（上の説明どおり）。

これにより macOS では ⌥⌘D が空いたまま残り、将来のコマンドが必要になったときに GenOffice がそのまま使えます。
