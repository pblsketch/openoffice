# 그림 편집기

그림 편집기는 Excalidraw 그림을 자기 탭에서 열고, 고친 것을 같은 파일에 저장합니다.

- **여는 파일**: Obsidian Excalidraw 플러그인으로 그린 그림 노트(`.excalidraw.md`, 또는 앞머리에 `excalidraw-plugin`이 있는 `.md`)와 Excalidraw 웹 앱의 `.excalidraw` 파일.
- **새 그림**: 홈의 **Excalidraw 그림** 카드나 **파일 ▸ 새로 만들기**. 새 그림은 Obsidian 그림 노트(`.excalidraw.md`)이고, 이름은 처음 저장할 때 정합니다.
- **그리기**: 도형, 화살표, 선, 자유 곡선, 글자를 그림판의 도구 모음과 단축키로 그립니다. ctrl+Z로 되돌립니다.
- **저장**: ctrl+S. 파일은 연 형식 그대로 저장됩니다. 자동 저장은 30초마다, 그리고 창이 포커스를 잃을 때 쓰지만, 아직 파일 이름이 없는 그림은 건너뜁니다. 열어 보기만 한 그림은 원래 바이트 그대로 저장됩니다.

## Obsidian 그림 노트

- 저장할 때 다시 쓰는 곳은 노트의 글 목록과 그림 자료뿐입니다. 앞머리, 노트에 직접 쓴 글, 링크는 그대로 남으므로 Obsidian에서도 똑같이 열립니다.
- 노트가 가리키는 그림(Embedded Files 아래의 `[[그림.png]]`)은 노트의 보관함 안에 있으면 보입니다. 보관함은 노트 위로 올라가며 처음 만나는 `.obsidian` 폴더가 있는 곳이고, 없으면 노트의 폴더입니다. 20MB를 넘거나, 숨은 폴더에 있거나, 보관함 밖에 있는 그림은 보이지 않습니다.
- 아직 노트에 새 그림을 넣을 수는 없습니다. 그림 도구가 꺼져 있고 그림판에 파일을 끌어 놓는 것도 막혀 있습니다. 노트 안에만 들어간 그림은 Obsidian에서 보이지 않을 수 있기 때문입니다.

## 아직 안 되는 것

- AI 창이 없습니다. AI는 그림을 읽거나 고치지 못합니다.
- PNG나 SVG로 내보내기가 없습니다.
- 편집기는 네트워크에 닿지 않습니다. 글꼴은 앱에 들어 있고, 공유 라이브러리, 실시간 공동 작업, 웹 임베드는 꺼져 있습니다. 그림 안의 링크는 웹 주소나 메일 주소일 때만 브라우저로 엽니다.

## 파일 탐색기에서 그림 열기

설치 프로그램은 `.excalidraw` 파일의 **연결 프로그램** 목록에 이 앱을 넣지만, 기본 프로그램으로 정하지는 않습니다. 그림 노트는 `.md` 파일이므로 앱에서 Markdown 파일이 열리는 곳이면 어디서든 열리고, Markdown 편집기 대신 그림 편집기로 갑니다.
