# แก้ไขร่วมกันในเครือข่าย

ผู้ที่อยู่ในเครือข่ายเดียวกัน (LAN) สามารถเปิดเอกสารเดียวกัน แก้ไขพร้อมกัน และเห็นเคอร์เซอร์กับชื่อของกันและกันได้ โดยไม่ต้องมีเซิร์ฟเวอร์หรือบัญชี คอมพิวเตอร์ที่แชร์เอกสารจะเป็นผู้ดูแลเซสชัน และมีเพียงคอมพิวเตอร์เครื่องนั้นที่บันทึกไฟล์

## แชร์เอกสาร

1. เปิดเอกสาร แล้วคลิก **ทำงานร่วมกัน** ในแถวเครื่องมือของตัวแก้ไข
2. ป้อน **ชื่อของฉัน** และเลือก **สีของฉัน** ผู้อื่นจะเห็นข้อมูลเหล่านี้ข้างเคอร์เซอร์ของคุณ
3. คลิก **เริ่มแชร์** แล้ว **รหัส PIN** 6 หลักและ **ที่อยู่ของคอมพิวเตอร์เครื่องนี้** จะปรากฏขึ้น
4. บอก PIN ให้ผู้ที่จะเข้าร่วม และบอกที่อยู่ด้วยหากพวกเขาหาเอกสารไม่พบ

หากเอกสารมีการเปลี่ยนแปลงที่ยังไม่ได้บันทึก ให้บันทึกก่อน เอกสารที่ป้องกันด้วยรหัสผ่านจะแชร์ไม่ได้ **รหัส PIN ใหม่** จะเปลี่ยน PIN ของเอกสารเป็นรหัสใหม่ ส่วนผู้ที่เข้าร่วมอยู่แล้วจะยังอยู่ต่อ

หากต้องการหยุด ให้เปิด **ทำงานร่วมกัน** อีกครั้งแล้วคลิก **หยุดแชร์** ทุกคนที่เข้าร่วมจะยังมีสำเนาที่ยังไม่ได้บันทึกอยู่ในคอมพิวเตอร์ของตน

## เข้าร่วม

1. ในตัวแก้ไขใดก็ได้ คลิก **ทำงานร่วมกัน** แล้วสลับไปที่ **เข้าร่วม**
2. เลือกเอกสารใน **เอกสารที่พบ** หรือพิมพ์ที่อยู่ของคอมพิวเตอร์ที่แชร์ในช่อง **ที่อยู่**
3. ป้อน PIN แล้วคลิก **เข้าร่วม** เอกสารที่แชร์จะเปิดในแท็บใหม่

ระหว่างที่เข้าร่วมอยู่ ผู้แชร์จะเป็นผู้บันทึกไฟล์ การสั่งบันทึกของคุณจะไม่มีผลและจะแจ้งให้ทราบ และแท็บจะไม่ถามให้บันทึกเมื่อคุณปิด **ออก** จะพาคุณออกจากเซสชัน เมื่อเซสชันสิ้นสุด แท็บจะยังเปิดอยู่ในฐานะสำเนาที่ยังไม่ได้บันทึก ซึ่งคุณบันทึกไว้ที่ใดก็ได้

## แก้ไขด้วยกัน

- เคอร์เซอร์หรือส่วนที่เลือกของแต่ละคนจะแสดงเป็นสีของคนนั้น พร้อมชื่อ
- การเลิกทำจะย้อนกลับเฉพาะการแก้ไขของคุณเอง
- ฟีเจอร์บางอย่างใช้ไม่ได้ระหว่างเซสชัน เช่น ฟีเจอร์ที่เปลี่ยนส่วนอื่นของเอกสารนอกเหนือจากเนื้อหา ตัวแก้ไขจะแจ้งให้ทราบเมื่อปฏิเสธฟีเจอร์นั้น
- ในตัวแก้ไขฮันกึล มีเพียงผู้แชร์ที่แก้ไขได้ ผู้ที่เข้าร่วมจะดูการเปลี่ยนแปลงแบบเรียลไทม์
- ไฟล์ข้อความธรรมดาและไฟล์ JSON จะเปิดในมุมมองซอร์สของตัวแก้ไข Markdown และยังแชร์ไม่ได้

## ความปลอดภัย

- PIN จะไม่ถูกส่งผ่านเครือข่ายเลย ระบบตรวจสอบ PIN ด้วยการแลกเปลี่ยนคีย์ และทุกอย่างหลังจากนั้นจะถูกเข้ารหัส ผู้อื่นในเครือข่ายจึงอ่านเอกสาร การแก้ไข หรือ PIN ไม่ได้
- หากใส่ PIN ผิด 5 ครั้งจากคอมพิวเตอร์เครื่องเดียว เครื่องนั้นต้องรอ 10 นาที หากใส่ PIN ผิดรวมทั้งหมด 20 ครั้ง เอกสารที่แชร์ทุกฉบับจะได้รับ PIN ใหม่ และผู้แชร์จะได้รับแจ้ง
- เอกสารหนึ่งฉบับมีผู้เข้าร่วมได้สูงสุด 16 คน
- ระหว่างที่คุณแชร์ ชื่อของคุณและชื่อเอกสารจะถูกประกาศในเครือข่ายเพื่อให้ผู้อื่นค้นพบได้
- เมื่อแชร์ครั้งแรก ไฟร์วอลล์ Windows อาจขออนุญาต ให้อนุญาตสำหรับเครือข่ายส่วนตัว หากคุณบล็อก คอมพิวเตอร์เครื่องอื่นจะเชื่อมต่อไม่ได้
