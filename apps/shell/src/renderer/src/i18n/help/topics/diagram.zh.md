# 图表：绘制和编辑 draw.io 文件

图表编辑器会在标签页中打开 draw.io 文件。你可以绘制流程图、架构图等各种图表，按打开时的格式保存，导出为图片或 PDF，还可以让 AI 读取、修改和绘制图表。编辑器完全在你的电脑上运行。

## 打开图表

- 编辑器可以打开 `.drawio`、`.dio`、`.drawio.svg` 和 `.drawio.png` 文件：可以通过打开对话框、拖到窗口上、最近的文件或文件夹树打开，`.drawio` 和 `.dio` 还可以从 Google Drive 列表打开。在 Windows 中，安装 GenOffice 后，它会成为打开 `.drawio` 和 `.dio` 文件的程序。
- `.drawio.svg` 或 `.drawio.png` 文件只有在图片里存有图表时才能打开。普通的 SVG 或 PNG 图片不会作为图表打开。损坏的文件也无法打开，并会显示原因。
- Visio 文件（`.vsdx`）会作为一个新的无标题图表导入。第一次保存时，会建议在 Visio 文件所在的文件夹中保存一个 `.drawio` 文件，Visio 文件本身不会改变。如果其中有些图片无法转换，编辑器会告诉你有几张。在 Windows 中，`.vsdx` 文件只会出现在“打开方式”里。
- 新的空白图表可以从主屏上的**图表**磁贴或文件菜单中的“新建”开始。
- 如果这个图表已经打开，就会切换到它的标签页。

## 编辑

- 编辑界面就是 draw.io 原本的界面：顶部是菜单，左侧是形状，右侧是格式面板，底部是页面标签。
- 保存（Ctrl+S）、另存为（Ctrl+Shift+S）和打印（Ctrl+P）由 GenOffice 处理。切换标签页和其他全应用快捷键照常可用。其余快捷键都属于编辑器本身，包括撤销（Ctrl+Z）。
- 编辑器菜单中的**帮助**（F1）会打开本页。
- 编辑器使用 GenOffice 的界面语言。更改语言后，编辑器会重新启动：未保存的修改会保留，但撤销记录会丢失。
- 编辑器跟随 GenOffice 的主题。在深色主题下，图表也会以深色显示，但保存的文件、PNG、PDF 和打印结果与浅色主题下完全相同。

## 保存

- 保存、另存为、状态栏中的**自动保存**以及关闭前的询问，都和其他编辑器一样。
- 图表会按打开时的格式保存。另存为可以选择 `.drawio`、`.dio`、`.drawio.svg` 和 `.drawio.png`。新图表第一次保存为 `.drawio`。
- 如果没有任何改动，文件不会重新写入。文件中以压缩形式存储的页面，保存后仍然保持压缩。
- `.drawio.png` 文件的图片显示第一页，整个图表都存储在这张图片里。
- 图表有未保存的修改时，应用的数据文件夹中会保留一份恢复副本，即使程序意外退出，工作也不会丢失。

## 导出和打印

- 在文件菜单中选择 PNG、SVG 或 PDF 导出（编辑器自身菜单中的导出项也会打开同一个窗口）。然后选择**所有页面**（默认）或**仅当前页面**。
- 选择所有页面时，PNG 和 SVG 每页生成一个文件，文件名为 `<名称>-p<页码>`。PDF 每页一张，使用图表中设置的页面大小。
- 打印（Ctrl+P）同样每页打印一张。无论使用什么主题，导出和打印都使用浅色。

## AI 面板

- 可以让 AI 绘制流程图、时序图或组织结构图，解释图表，整理某一页的布局，或在你选中的形状后面添加下一步。
- AI 以文本形式读取图表：页面列表，每个形状和连接线的 id、文字、形状、位置和连接关系，以及你选中了哪些形状。它不会把图表当作图像来看。
- AI 做的修改会立即显示。每次修改算一步撤销（Ctrl+Z），面板中的“撤销 AI 的修改”列表可以撤回 AI 的一整轮修改。只要修改中有任何部分被拒绝，图表就保持原样。
- 新建流程图、时序图之类的图表时，AI 会编写 Mermaid，再由 GenOffice 在你的电脑上把它转换成形状。布局可能与 draw.io 网站生成的略有不同。
- 在其他编辑器的 AI 面板中也可以附加图表、用 `@` 选择它们，在主屏的文件搜索中也能找到它们。[终端命令](help://cli)同样可以读取、编辑和创建图表（`ieumoffice diagram read`、`ieumoffice diagram apply`、`ieumoffice create --type drawio`）。

## 联网情况

- 图表标签页不会向互联网发送任何内容。编辑器运行的是随 GenOffice 一起安装的文件，它的云存储、共享、插件和自带的 AI 都已关闭。
- 图表要从互联网获取的图片和字体不会加载，打开文件时会有提示说明这一点。形状上的网页或电子邮件链接，只有在你点击时才会用默认浏览器打开。
- 草稿本、你添加的形状库和最近使用的颜色都保存在这台电脑上的应用数据文件夹中。AI 面板会像其他编辑器一样，把图表的文本发送给你选择的 AI。

## 暂不支持

- 插入或编辑 PlantUML。文件中的 PlantUML 形状显示为其中保存的图片。
- 使用 ELK 的自动布局，以及绕开形状的连接线。这类连接线会画成普通连接线。
- 旧的 Visio 格式（`.vsd`、`.vss`），以及保存回 `.vsdx`。
- 云存储、共享、发布、插件以及编辑器自带的 AI 功能。
- 对 AI 隐藏图表的某些部分。
