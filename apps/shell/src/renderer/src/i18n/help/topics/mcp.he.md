# חיבור סוכן תכנון

‏GenOffice מדברת ב- Model Context Protocol, ולכן סוכן תכנון יכול לקרוא, לכתוב ולרנדר את המסמכים שלכם דרך אותם מנועים שהאפליקציה משתמשת בהם. הסוכן אינו מנחש פורמט קובץ: הוא מקבל את סכמות הפעולות המוטיפות מאותם הגדרות שמולן המבצע מאמת.

## רישום מתוך האפליקציה

‏**הגדרות ▸ שילובים** הוא המקום שבו עושים את זה. לחלונית שני צדדים, ואפשר להשתמש באחד מהם או בשניהם.

**ה-skill.** שורה אחת לכל סוכן תכנון שנמצא במחשב הזה — Claude Code, Codex, Cursor, Gemini CLI, Copilot CLI, OpenCode, Windsurf — ובכל שורה יש **התקנה**, **עדכון** ו**הסרה**, ובנוסף **התקנה לתיקייה אחרת…**, **הורדת skill (zip)** ו**העתקת נתיב**. אם העוזר שלכם אינו רשום ברשימה, הפנו את GenOffice לתיקייה שממנה הוא קורא את `SKILL.md`, או שמרו את קובץ ה-zip ותנו לעוזר להתקין אותו. אפשר להשאיר את ה-skill ואת MCP זה ליד זה: העוזר בוחר אחד מהם, ושניהם עושים בדיוק את אותו דבר.

**MCP.** מוצעים כאן שני דרכים: **מופעל על ידי העוזר (מומלץ)**, שבה אתם מוסיפים את תצורת הלקוח המוצגת ללקוח שלכם והעוזר מפעיל את השרת בעצמו; ו**שרת HTTP מקומי**, שהאפליקציה מריצה עבורכם. בשני המקרים העוזר בסופו של דבר מדבר עם GenOffice, ואתם אף פעם לא מקלידים פקודה.

## רישום מתוך שורת הפקודה

‏אותו דבר מתוך מסוף — זו הדרך המתקדמת, וזו לה גונבים כאשר הסוכן יושב במקום שהחלונית אינה יכולה למצוא:

```sh
ieumoffice mcp install all
```

‏היא מוצאת את סוכני התכנון שבמחשב הזה — Claude Code, Codex, Cursor, Gemini CLI, Copilot CLI, OpenCode, Windsurf — וכותבת את רשומת שרת ה-stdio בהגדרות של כל אחד מהם, ומשאירה את שאר הקובץ כפי שמצאה אותו. שם הרשומה הוא `ieumoffice`. כשעושים זאת ידנית עבור Claude Code, אותו רישום הוא `claude mcp add --transport stdio ieumoffice -- ieumoffice mcp`.

```sh
ieumoffice mcp list             # where each agent stands
ieumoffice mcp install cursor    # just one
ieumoffice mcp uninstall cursor  # take it back out
```

‏סוכן שהתקנתם במקום לא שגרתי זקוק ל-`--dir <path>`; ו-`--force` כותב מחדש רשומה שכבר קיימת.

‏`ieumoffice mcp --help` מציג במסך אחד את כל מה שהשרת מקבל: הצורות להתקנה, להסרה ולהצגה, הגשה דרך HTTP, ושני הדגלים של הסכמות.

## הרצה ללא עוזר

עבור לקוח במחשב אחר, הגישו אותו ב-HTTP במקום זאת:

```sh
ieumoffice mcp --http 8765 --token <secret>
```

‏`--host <addr>` משנה את הכתובת שבה הוא מאזין. העבירו ללקוח את אותו אסימון.

גם קבצים עוברים ב-HTTP: `PUT /files/<name>` מעלה קובץ אחד, כל כלי מקבל כתובת `http(s)` במקום נתיב, והפלטים חוזרים ככתובות הורדה — וכשהם קטנים מספיק, כמשאבים מוטמעים. פעולות, מפרטים ו-Markdown עוברים בתוך הבקשה בכל מקרה.

## מה הסוכן מקבל

כל פקודה היא כלי. המעניינות שבהן:

- **`docs`, `sheet`, `slides`** — קוראות ועורכות קובץ דרך נתיב הכתיבה של האפליקציה עצמה, **פעולה** (op) אחת בכל פעם. מצגת חדשה הולכת `deck_start`, `deck_page`, `deck_build`.
- **`render`** — PNG אחד לכל עמוד, בפריסה של המרונדר של האפליקציה, כך שהסוכן יכול להסתכל על שקופית במקום לנחש.
- **`pdf`** — שכבת הטקסט של PDF, עמוד אחר עמוד, בלי תהליך של האפליקציה.
- **`info`** — מטא-נתונים ותקציר מבנה, שבדרך כלל הוא הקריאה הראשונה הזולה ביותר על קובץ לא מוכר.
- **`search`, `image`, `media`** — חיפוש ברשת וחיפוש תמונות, יצירת תמונות וניתוח מדיה דרך מה שהוגדר באפליקציה, ולכן הסוכן לא צריך מפתחות משלו. הסעיף הבא מסביר במה מותר להם להשתמש.
- **`merge`** — מילוי תבנית `{{key}}`.

## חיפוש, תמונות ומדיה: במה מותר לסוכן להשתמש

בקשה שמגיעה מהפקודה `ieumoffice` או מלקוח MCP לא הוקלדה על ידכם באפליקציה, ולכן GenOffice נוהגת בה בזהירות.

- **חיפוש** פועל תמיד, והוא חינמי כברירת מחדל. במפתח של ספק חיפוש משתמשים רק אם בחרתם בו.
- **יצירת תמונה** דורשת מפתח של ספק תמונות. בגרסה הזו מינוי אינו יוצר תמונות.
- **תיאור תמונה** משתמש בספק עם מפתח כשמוגדר כזה. במינוי Claude או Codex שלכם **לא נעשה שימוש אלא אם אישרתם זאת**.
- **וידאו ושמע** דורשים ספק עם מפתח שתומך בווידאו.

כדי לאפשר שימוש במינוי, פתחו את הגדרות ▸ AI ▸ **מתקדם** והפעילו את **לאפשר לבקשות אוטומטיות להשתמש במינוי**. קודם מוצגת אזהרה — "אין מגבלה שעתית, ולכן תוכנה יכולה לשלוח כמה בקשות שתרצה, והן עשויות לכלול את כל הטקסט של מסמך ותמונות של עמודיו. אף אחת משתי החברות אינה ממליצה לאפשר לתוכנה להשתמש במינוי באופן אוטומטי, והחשבון שלכם עלול להיות מוגבל." — והמתג נדלק רק אחרי **להפעיל בכל זאת**.

גם כשהמתג דולק:

- הבקשות מטופלות אחת אחת. האחרות ממתינות לתורן.
- אין מכסה שעתית. התור מתחלף בין בקשות בודדות ולא בין משימות שלמות, כך שגם תרגום PDF ארוך מתחלף עם קוראים אחרים במקום לעכב אותם. מתג שהופעל לפי האזהרה הקודמת כובה: קראו את האזהרה החדשה והפעילו אותו שוב.
- כניסה בתשלום לפי שימוש שאישרתם עם **להשתמש בכל זאת** אינה נחשבת כאן למינוי. היא מטופלת כמו מפתח: אם בחרתם בה בתור ה-AI שבשימוש, תיאורי תמונות עוברים דרכה בלי קשר למצב המתג, וכל אחד מהם מחויב.

כשהמתג כבוי ולא הוגדר שום מפתח, הכלי עונה שהתכונה אינה זמינה ומציין את ההגדרה הזו. סוכן יכול לבדוק מראש בעזרת הכלי `capabilities`; ראו [שורת פקודות וסוכנים](help://cli).

## סכמות, ותקציב קטן יותר

‏`apply` ו-`create` מכריזות על הפרמטרים `ops`, `cells` ו-`data` שלהן עם הסכמה המוטיפה של כל פעולה, שנוצרה מ-`ieumoffice guide <domain> --json`. זה מדויק אך לא קטן. לקוח עם חלון הקשר צר יכול לבקש מערכים פשוטים במקום זאת:

```sh
ieumoffice mcp --compact-schemas
GENOFFICE_MCP_COMPACT_SCHEMAS=1 ieumoffice mcp
```

## למה צריך skill

סוכן שאינו מכיר את מילון הפעולות ינחש. ה-skill נושא איתו את המפנייה ואת מדריכי העיצוב — אותו חומר ש-`ieumoffice guide` מדפיס — כך שהעוזר כותב פעולות שאת המפרט שלהן קרא באמת. התקינו אותו מהחלונית למעלה, או בעזרת `ieumoffice skill` ממסוף.

## מה הוא מצליח להשיג באפליקציה

השרת אינו מוגבל לקבצים שעל הדיסק. כל עוד GenOffice רצה, הסוכן יכול לעבוד גם דרך החלון:

- **`open_in_genoffice`** פותח קובץ בכרטיסייה ומעביר אליה את המיקוד.
- **`open_documents`** מפרט כל מסמך פתוח אצלכם — מזהה, סוג, נתיב, ואם יש בו שינויים שלא נשמרו — ואז קורא את התוכן העדכני של אחד מהם, שומר אותו במקומו, או סוגר אותו, תוך שמירה תחילה אלא אם ביקשתם ממנו להיפטר מהשינויים.
- **כלי התוכן** לוקחים את המזהה (או הנתיב) הזה כארגומנט `document`, כך שעריכה נופלת בכרטיסייה שכבר פתוחה אצלכם, והחלון עובר להציג אותה.

שני דברים נשארים מחוץ להשגה: אין חלונית AI, וחלונית העדכון שבאפליקציה אינה חלה.

## החלונית של שרת ה-HTTP המקומי

תחת **שרת HTTP מקומי**, האפליקציה מריצה את השרת בעצמה במקום להשאיר אותו לעוזר: מתג הפעלה, שדה **יציאה**, מחוון **פעיל / לא פעיל** ו**יצירה ברקע** (כתיבת מסמכים ישירות לנתיב בלי לפתוח את ממשק המשתמש) ו**דוגמת תצורת לקוח** להעתקה. פתיחת **מתקדם** מוסיפה את שתי כתובות החיבור — Streamable HTTP והכתובת הישנה של SSE —, כתובת **בדיקת תקינות** ומתג **רישום ביומן** שמתעד את פעילות השרת והכלים בקובץ מקומי, וממנו אפשר **לפתוח**, **לרענן** או **לנקות**. הוא מאזין רק ב-localhost.
