# PDF：閱讀、註解與塗黑

PDF 編輯器有五個功能區分頁：**常用／註解／編輯／頁面／檢視**。它既能讀也能寫：文字可以編輯、內容可以塗黑（redact）、可以簽名，表單也可以填寫。

## 閱讀與導覽

- 左側邊欄：**縮圖**（點一下跳頁，並高亮顯示可見範圍）或**大綱**（書籤目錄，若有）。
- 縮放：右下角的比例控制項；ctrl+滾輪逐級縮放。
- 移動檢視：開啟**手形工具**（常用、檢視索引標籤）後，拖曳即可上下左右移動頁面。開啟期間拖曳不會選取文字，按一下連結仍會開啟。按住滑鼠中鍵（滾輪）拖曳，不開工具也能移動。按 Esc 或選擇其他工具即關閉。
- 旋轉：在頁面選單中逐頁或全部旋轉；旋轉會在儲存時寫回。
- 搜尋：ctrl+F 全文搜尋，所有符合的位置都會高亮。
- 加密的 PDF：開啟時會跳出密碼提示（獨立的小視窗）；密碼只在本次工作階段中使用。 這類文件也可以編輯和儲存，儲存後密碼維持不變。在 **註解 → 保護** 中可以設定、變更或移除密碼以及讀者可做的操作。

## 文字選取與標註（註解）

試試看（對著任一段文字）：

1. **用滑鼠拖過一句話**——放開後，文字上方會浮出一條標註工具列：

![選取文字後浮出的標註工具列](img/pdf-highlight.png)

2. 選擇三種 **螢光標示** 顏色之一，或 **底線**、**波浪線**、**刪除線**。要更換螢光標示的顏色，在該顏色上按右鍵再選新顏色。畫好底線、波浪線或刪除線後，標註列會展開一排顏色：點另一種顏色即可更換，之後也會用這個顏色。按 **問 AI** 則會把選取內容連同你的問題送到 AI 面板。
3. 想取消某個標註：再次拖選同一段文字，然後按工具列上已生效的按鈕（Word 式的開關），或選取後按 Delete。

補充說明：

- 在文字上拖曳會彈出工具列：**螢光標示／底線／刪除線／複製／問 AI**。
- 顏色從調色盤選擇；**對已標註的範圍套用同一種標註等同於取消**（Word 式的開關）。
- 已儲存進檔案的標註同樣可以選取並刪除（⋯ 選單或 Delete）。
- **請注意**：繪圖工具啟用時，文字層無法選取——每放下一個圖形，工具就會自動解除，讓你回到選取模式繼續下一個動作。

## 繪圖工具（註解）

六個工具：**手繪、矩形、橢圓、箭頭、便利貼**，以及註解分頁上的**塗黑方塊**。

- 每個工具都是開關：按一下啟用，**放下一個圖形後就會自動解除**（想連續畫就再按一次工具）；按一下已啟用的工具同樣是解除。
- 手繪會依筆寬畫出；矩形／橢圓／箭頭以拖曳方式畫出；顏色取自繪圖調色盤。
- 畫好的圖形可以選取、刪除、拖曳移動，以及（矩形／橢圓）調整大小。
- **塗黑（redact）的完整流程**（以藏住一行文字為例）：

  1. 註解分頁 ▸ 按一下 **塗黑區域**（工具進入啟用狀態）。
  2. **在要藏起來的內容上拖曳出一個方塊**——框住的內容會覆蓋上斜線標記，工具列同時出現 **清除標記／套用塗黑** 兩個按鈕。

  3. 按 **套用塗黑** 並確認——結果是一份工作副本，其中被塗黑的文字與圖片是**實體移除**（不是蓋上一塊黑布），而且無法復原；原始文件完全不動。

  畫錯了？按清除標記按鈕即可抹掉目前的標記，然後重畫。

## 便利貼與留言串

- **便利貼工具**：在頁面上放一枚圖釘，並在頁邊的卡片中輸入文字（作者名稱可設定）；確認後會儲存為標準的 PDF 文字註解。
- 點一下圖釘可展開留言串：**回覆**（回覆平鋪成一列，不巢狀）、**編輯**自己的留言、**刪除**單一則留言或整個留言串。
- 編輯中的內容會一直保留到儲存把新文字寫回檔案中同一則註解為止，回覆關係不會斷掉。

## 編輯 PDF 內容（編輯）

- **編輯文字**：點一下文字即可逐區塊編輯（pdfium 引擎；字型以盡力比對的方式處理）。
- **插入文字**：以自選的字型／字級／顏色放入可搜尋的文字。
- **插入圖片／圖章**。
- 表單：AcroForm 欄位可直接填寫；填入的值會在儲存時寫入。

## 簽名

- **手寫簽名**：畫出簽名；可綁定到表單的簽名字段。
- **圖片簽名**：以圖片作為簽名放置。
- 儲存過的簽名可以重複使用。
- **憑證簽署**（注釋分頁）：用系統憑證庫或 .p12/.pfx 憑證檔簽署；可選擇在頁面上顯示簽章，也可以認證文件以限制後續修改。
- 簽署總是寫出一個 **新檔案**（增量更新——之前的簽章仍然有效），並在原位開啟簽署副本。先儲存：簽章涵蓋的是磁碟上已儲存的檔案。
- 文件上方的橫幅列出既有簽章；**檢視簽章** 展示每個簽章的有效性、涵蓋範圍和憑證鏈。撤銷狀態（CRL/OCSP）不檢查。

## 頁面操作（頁面）

- **旋轉／刪除／重新排序**：拖曳縮圖即可重排；刪除時會先確認。
- **匯入頁面**：從其他 PDF 匯入頁面。**插入空白頁**會加上一張空白頁。
- **取代頁面** 把整段頁面換成其他來源的頁面；**裁剪頁面** 裁掉邊緣，並可選擇套用到所有頁面。
- **頁面大小** 會把所有頁面縮放成同一種紙張尺寸；**倒序排列** 則是把整份文件從頭到尾翻轉。
- **擷取頁面**：把選取的頁面匯出成新的 PDF。
- **拆分**：有兩種形式——依範圍拆成多個檔案，或把每一頁切成更小頁面的格線。
- **合併**：有兩種形式——附加其他 PDF，或把多頁併到同一張紙上。大小會在讀取任何內容**之前**先加總，**總計超過 1 GiB 會直接拒絕**並顯示易懂的錯誤（以確保記憶體用量有上限）。
- 頁面層級的變更會在下次儲存時寫回；另存新檔不會動到原檔。

## 匯出與列印

- **匯出為 Word… / PPT… / Excel…** 可在「檔案」選單中選擇，也可從功能區的 **PDF 轉換** 中選擇同樣三項——全部在本機完成，不會上傳。.pptx 每頁匯出一張投影片，.xlsx 每頁匯出一個工作表。每種都會詢問儲存位置。
- **列印**：透過系統對話方塊，依目前的頁序與旋轉列印；可指定頁面範圍。

## 儲存

- 一般儲存／自動儲存會把註解與編輯寫回檔案（原子寫入）。
- **塗黑一律走「套用塗黑」流程**產生一份副本，原始文件完全不動，敏感內容就不會留在原檔裡。

## 選取列快速鍵

選取文字、註解列出現時，按一個鍵就能直接執行。

| 鍵    | 作用                           |
| ----- | ------------------------------ |
| H     | 螢光標示（已標示的地方則取消） |
| U     | 底線                           |
| S     | 刪除線                         |
| N     | 在選取範圍結尾加上便箋         |
| E     | AI 解釋（段落卡片）            |
| T     | AI 翻譯（段落卡片）            |
| Enter | 開啟 **問 AI** 輸入框          |

- 開著韓文或其他輸入法時，同一個鍵也做同樣的事。正在輸入框中打字，或按住 Ctrl、Alt 時，不當作快速鍵。
- 在禁止編輯的文件（擁有者密碼禁止修改的文件）中，H、U、S、N 不會動作，並像註解列上的按鈕一樣顯示原因。

## 段落卡片

按 **E** 或 **T**，或按 **問 AI** 框中的解釋、翻譯小標籤，AI 的回答會以小卡片顯示在選取處旁邊。卡片會保存下來，重新開啟文件也還在，也可以複製。再次詢問同一段文字時，不會送給 AI，而是開啟既有的卡片。

- **留作註解**：在那個位置建立一則便箋。第一行寫著「AI 解釋」或「AI 翻譯」，作者是你的電腦帳戶名稱。儲存 PDF 時才寫進檔案，在那之前卡片上顯示「等待儲存」。
- **在 AI 面板中繼續提問** 把這段文字和回答交給 AI 面板（不會立即送出）；**加入筆記** 把它們放到這個 PDF 的筆記結尾。
- 只有按 **重新產生** 才會再次送給 AI。
- **刪除** 只刪除保存的卡片，已經留下的便箋不受影響。
- 有卡片的文字下方會畫一條淡淡的虛線，按它會再次開啟卡片。虛線只顯示在螢幕上，不會儲存或列印。可在 檢視 ▸ **段落標記** 中開關。

## 註解一覽

- 按 檢視 ▸ **註解**，左側邊欄會把本文件的螢光標示、底線、刪除線、便箋、繪圖，尚未儲存的標記，以及段落卡片列在同一個清單中。螢光標示等標記也會顯示其下方的文字。
- 可依類型、顏色、頁碼範圍、文字篩選，並依頁碼順序或建立順序排序。
- 按某一項會跳到那裡並短暫閃爍。便箋會開啟頁邊的討論，卡片會開啟卡片。
- 面板選單中的 **複製為 Markdown**、**以 Markdown 文件開啟**、**以 Word 文件開啟** 使用目前篩選後的清單，不會呼叫 AI。只有在 GenOffice 中開啟的 PDF 才能建立新文件。

## 譯文對照

- 開啟 檢視 ▸ **譯文對照** 後，每頁右側會出現譯文欄並隨原文一起捲動。只是開啟不會向 AI 傳送任何內容。已經用 **文件翻譯** 譯過的文件會立即顯示譯文，沒有譯文的段落以淡色原文顯示。
- **翻譯此頁**（只譯了一部分時為 **翻譯剩餘段落**）在使用訂閱時按一下就送出這一頁，按鈕旁會顯示要送給哪個 AI。若連線依用量計費，在一個分頁中第一次按時會先詢問「將對此收費 · 翻譯 / 取消」。
- 按兩下譯文段落即可直接修改。改過的段落以無格式文字保存，並原樣用於翻譯後的 PDF、Markdown、EPUB。段落上的 **重新翻譯** 只送出這一段；如果是改過的段落，會先詢問。
- 滑鼠移到譯文段落上時，原文中對應的位置會出現外框。譯文欄的寬度和字級可以調整。**翻譯所有頁面…** 會開啟 **文件翻譯** 視窗，其中的 **僅保存（不產生檔案）** 格式只留下譯文，不寫入檔案。
- 新翻譯的段落會逐句對應。將滑鼠移到譯文的某一句上，原文頁面上的對應句子會被標出；移到原文句子上，對應的譯文句子會亮起。在頁面上找不到句子位置的地方、以前翻譯的段落和你修改過的段落，仍按段落對應。
- 欄位上方的工具列可以在 **翻譯** 和 **淺顯解釋** 之間切換。淺顯解釋用日常用語和短句改寫原文，方便兒童、長者或正在學這個語言的人閱讀；事實、數字和名稱維持不變。所選方式會被記住，切換本身不會傳送任何內容。顯示解釋時，頁面與段落按鈕以及編輯都會作用在解釋上。
- 在淺顯解釋下，**淺顯解釋所有頁面…** 會開啟 **文件翻譯** 視窗，方式已選為 **淺顯解釋**。解釋比原文長，放不進原來的位置，所以不能產生翻譯 PDF，只能寫成 Markdown 或 EPUB。勾選 **原文後附解釋** 時，每段原文後面接著它的解釋；不勾選時檔案裡只有解釋。語言一開始是介面語言，也可以和文件的語言相同。

## AI 重點標示

- 在 常用 ▸ **AI 重點標示** 中選擇分類組（研究·報告、合約·條款、教材·說明書、自訂）和頁碼。確認預估呼叫次數和要送給哪個 AI 並按 **開始** 之前，不會傳送任何內容。
- AI 選出的句子會以半透明色框預覽在頁面上。預覽不會儲存到檔案，可在 檢視 ▸ **重點標示預覽** 中開關。
- 在 **註解** 面板中逐則 **接受** 或 **捨棄** 建議，也可以依分類全部接受。在頁面文字中找不到的句子無法接受。
- 接受的建議會變成該分類顏色的螢光標示，分類名稱作為註解主旨儲存，其他 PDF 檢視器的註解清單中也看得到。儲存 PDF 時才寫進檔案。
- 禁止編輯的文件中無法開始。AI 編造的、原文中沒有的句子會被捨棄，結束時會告訴你收到幾則、捨棄幾則。

## 文件概覽與段落引用

- 按 AI 面板頂端的 **文件概覽** ▸ **產生概覽**，會產生三句話摘要、摘要和關鍵術語（含意及第一次出現的頁碼）。長文件會分段摘要，所以會先請你確認預估呼叫次數。
- 概覽會保存下來，重新開啟也還在；只有按 **重新產生** 才會再次送出。按術語會在文件中搜尋，每一欄都可以複製或 **加入筆記**。
- 對話為空時，AI 面板會提供三個推薦問題，按一下就送出一次。
- 按 AI 作為依據給出的頁碼連結（p.N），會跳到那一頁並把引用的句子標示兩秒。找不到句子時只跳到那一頁。

## 每個 PDF 一份筆記

- 第一次按檢視索引標籤或 **註解** 面板中的 **開啟筆記** 時，會跳出儲存對話方塊。預設位置是 PDF 所在的資料夾，預設檔名是「PDF 名稱 筆記.md」。之後會直接在 Markdown 分頁中開啟。
- 如果選擇已有的檔案，Windows 可能會詢問是否取代，但檔案不會被覆寫，而是原樣連結為筆記。
- **加入筆記**（卡片、註解面板的項目、文件概覽）會在筆記分頁的文件結尾加入引文和頁碼連結，並保持未儲存狀態，由你在筆記分頁中儲存。這個連結在瀏覽器等其他程式中也會開到那一頁。
- 從未儲存過的 PDF 會顯示「請先儲存 PDF」。筆記只能用於在 GenOffice 中開啟的 PDF。
