# 局域网协作编辑

同一网络（局域网，LAN）中的人可以一起打开同一个文档、同时编辑，并看到彼此的光标和名字。不需要服务器或账号：共享文档的电脑负责这次协作，文件也只在那台电脑上保存。

## 共享文档

1. 打开文档，在编辑器的工具栏中点击 **协作**。
2. 填写 **我的名字** 并选择 **我的颜色**。其他人会在你的光标旁边看到它们。
3. 点击 **开始共享**。屏幕上会显示 6 位数字的 **PIN** 和 **这台电脑的地址**。
4. 把 PIN 告诉要加入的人；如果他们找不到文档，也把地址告诉他们。

如果文档有未保存的更改，请先保存。设置了密码的文档无法共享。**新 PIN** 会给文档换一个新的 PIN，已加入的人不受影响。

要停止共享，请再次打开 **协作** 并点击 **停止共享**。所有加入过的人的电脑上都会留下一份未保存的副本。

## 加入

1. 在任意编辑器中点击 **协作**，然后切换到 **加入**。
2. 在 **找到的文档** 中选择文档，或在 **地址** 中输入共享电脑的地址。
3. 输入 PIN 并点击 **加入**。共享的文档会在新标签页中打开。

参与期间由共享者保存文件。你点击保存不会真正保存，并会提示原因；关闭标签页时也不会询问是否保存。点击 **退出** 即可离开协作。协作结束后，标签页仍保持打开，成为一份未保存的副本，你可以把它保存到任何位置。

## 一起编辑

- 每个人的光标或选区都以其颜色显示，并标有其名字。
- 撤销只会撤回你自己的编辑。
- 协作期间部分功能不可用，例如会更改文档正文以外部分的功能。编辑器拒绝执行时会告诉你。
- 在韩文编辑器中只有共享者可以编辑，加入的人实时查看更改。
- 纯文本和 JSON 文件在 Markdown 编辑器的源码视图中打开，目前还无法共享。

## 安全

- PIN 从不通过网络发送。它通过密钥交换来验证，之后传输的所有内容都会加密。网络中的其他人无法读取文档、编辑内容或 PIN。
- 同一台电脑输错 PIN 5 次后，这台电脑需要等待 10 分钟。错误次数累计达到 20 次后，所有正在共享的文档都会换成新的 PIN，并通知共享者。
- 一个文档最多可有 16 人加入。
- 共享期间，你的名字和文档标题会在网络中广播，方便其他人找到它。
- 首次共享时，Windows 防火墙可能会请求权限。请在专用网络上允许。如果阻止，其他电脑将无法连接。
