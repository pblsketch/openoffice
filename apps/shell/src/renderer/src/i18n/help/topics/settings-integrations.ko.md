# 설정, 언어, 테마와 MCP 연동

## 설정 열기

홈의 왼쪽 아래 줄에서 설정 패널을 엽니다(AI가 연결되기 전에는 "AI 연결"로 표시됩니다). 이 패널에는 다섯 개 절이 있습니다: 계정, AI, 일반, 연동, 정보.

**계정**은 Claude와 Codex 구독이 지금 어떤 상태인지 보여 주고, **연결 관리**를 누르면 AI 절로 넘어갑니다. AI에는 별도 장이 있습니다. [구독 연결](help://subscription)과 [AI 모델과 설정](help://ai-models)을 보세요.

## 언어

- 설정에서는 **21개의 UI 언어**를 제공합니다: 영어, 중국어 간체, 일본어, 한국어, 프랑스어, 독일어, 스페인어, 태국어, 인도네시아어, 러시아어, 아랍어, 포르투갈어, 이탈리아어, 폴란드어, 체코어, 네덜란드어, 말레이어, 히브리어, 힌디어, 중국어 번체, 베트남어.
- 전환은 즉시 적용되어 유지되며, 네이티브 메뉴 바도 그 언어로 다시 만들어집니다.

## 테마

라이트/다크/시스템 따르기 세 가지입니다. 시스템 따르기를 고르면 OS 화면 설정에 따라 바뀌고, 편집기 영역도 함께 바뀝니다(깜빡임 없음).

## 일반

- **AI 사이드바 위치**(왼쪽 또는 오른쪽), **AI 패널 글자 크기**, **AI 채팅 맞춤법 검사**.
- **새 문서에서 AI 패널 열기** — 꺼져 있으면 새 문서가 패널을 접힌 상태로 시작하고, 한 번만 클릭하면 열립니다.
- **모든 문서 자동 저장** 는 모든 편집기에서 자동 저장을 기본으로 켭니다. 특정 창에 대해서는 여전히 끌 수 있습니다.
- **저장 위치** 와 **변경** 버튼, 그리고 **Office 문서 기본 앱** 으로 .docx / .xlsx / .pptx 을 GenOffice 가 처리하도록 지정합니다.

GenOffice는 사용 통계를 수집하지도 보내지도 않습니다. 그래서 이를 끄고 켜는 스위치도 없습니다.

## AI ▸ 고급

펼치기 전에는 접혀 있고, 대부분은 열 일이 없습니다. **AI 모델** 탭에는 대화에 쓸 API 키와 직접 운영하는 서버 설정이 있습니다. **AI 미디어 및 검색** 탭에서는 각 기능이 자신을 제공하는 공급자를 고르고, 공급자의 키와 기본 URL 은 한 번만 입력해 함께 씁니다:

- **웹 검색**, **이미지 생성**, **이미지 분석**, **동영상 분석** 은 각각 제공자, 모델, 키, 기본 URL 을 가집니다.
- **로컬 파일 검색**은 이 컴퓨터에서 돌아갑니다. 그 아래의 **Jev 검색 재순위**는 기본적으로 꺼져 있습니다. 켜면 로컬 검색 상위 20개의 발췌 — 문서당 최대 1,200자와 파일·폴더 이름 — 가 선택한 판단 엔드포인트(OpenRouter 또는 TypeSafe의 Jev, Perplexity, Liquid AI d1, Cloudflare, 로컬 엔진, 사용자 지정 URL)로 전송되어 관련성 순으로 재배열됩니다. 꺼두면 아무것도 기기를 떠나지 않습니다.
- **자동 호출에 구독 사용**은 **기본적으로 꺼져 있습니다**. 명령줄이나 연결해 둔 코딩 에이전트에서 들어온 요청이 Claude 또는 Codex 구독을 써도 되는지를 정합니다. [코딩 에이전트 연결](help://mcp)을 보세요.

## 정보

- **버전**, 프로젝트의 GitHub 주소, 그리고 이 앱의 바탕이 된 오픈 소스 프로젝트를 밝히는 한 줄.
- **업데이트 채널**: 안정 버전 또는 베타 버전. 바꾸면 즉시 반영되어 업데이트를 확인하며, 베타 설치를 안정 버전으로 되돌리지는 않습니다.

## 기본 앱 연결

설정에서 .docx / .xlsx / .pptx / .pdf 등의 파일을 GenOffice로 열도록 등록할 수 있습니다(플랫폼 수준의 기본 앱 등록. 물으면 확인합니다).

## 서드파티 고지 및 업데이트

- 도움말 ▸ 타사 소프트웨어 고지: 앱에 함께 들어 있는 전체 OSS 라이선스 목록.
- 메뉴(☰) ▸ 업데이트 확인(Mac은 도움말 ▸ 업데이트 확인): 수동으로 한 번 검사합니다. 새 버전이 있으면 설치를 권합니다.

## MCP 연동(고급 사용자/AI 클라이언트용)

GenOffice를 코딩 에이전트에 연결하는 곳이 **연동** 패널입니다. 이 주제만 다룬 별도 문서 「코딩 에이전트 연결」이 있습니다. 요약하면 — 방법(명령줄 또는 MCP)을 고르고 그 절을 따라간 뒤, 새 대화를 열어 물어보세요.

**로컬 HTTP 서버**에서는 어시스턴트에게 맡기는 대신 앱이 서버를 직접 실행하게 할 수도 있습니다(켜기 스위치, 포트). 그리고 **고급**이 상태 확인 URL과 로그 파일을 더합니다. localhost에서만 수신합니다.

## 명령줄 요약

| 명령                | 하는 일            |
| ------------------- | ------------------ |
| `ieumoffice <file>` | 파일 열기          |
| `ieumoffice mcp`    | 로컬 MCP 서버 시작 |
| `ieumoffice --help` | 모든 명령과 옵션   |
