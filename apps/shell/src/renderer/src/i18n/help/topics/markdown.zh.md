# Markdown 编辑器

Markdown 编辑器打开 .md / .markdown——以及 .txt / .json（直接进源码视图）——双栏体验：源码 + 渲染预览。

- **打开**：主页或 文件 ▸ 打开；也支持从命令行。
- **编辑**：纯文本编辑，GFM 扩展（表格、任务列表、删除线、自动链接）在预览中渲染。
- **预览**：实时渲染；相对路径的图片等资源随文档解析显示。
- **保存**：字节级忠实——BOM、CRLF、结尾是否有换行都原样保留；未改动时保存不重写文件。
- **查找替换**：ctrl+F 在源码中查找，全部替换后写回。
- **AI**：AI 预设按钮可让助手改写、续写、翻译当前文档。 选中内容可以对 AI 隐藏（见「AI 助手面板」一章）。

## 工具条

编辑区上方一排按钮（悬停可见说明）：

- **文件与历史**：保存、另存为、撤销、重做、查找；右侧的**自动保存**开关定时把改动写盘。
- **AI 按钮**：展开 AI 面板；旁边是改写、续写、翻译等预设按钮。
- **段落样式**（下拉）：正文与各级标题之间切换。
- **行内格式**：**加粗**、_斜体_、~~删除线~~、`行内代码`、链接。
- **列表**：无序列表、有序列表、任务列表。
- **插入**：表格、图片、分隔线。
- **属性**：在文首插入或跳转到 YAML front matter（文档属性块）。
- **大纲**：按标题层级快速跳转。
- **拼写检查**：开关当前文档的拼写检查。
- **图床设置**：粘贴/拖入的图片先上传到你自己的存储——S3 兼容（R2/OSS/COS/MinIO）、SM.MS 或 GitHub——本地 assets 副本保留作兜底。

上手三例：

- **标题**：光标放到该行 ▸ 段落样式下拉 ▸ 选「标题 1」。
- **表格**：点 **插入表格** ▸ 拖选行列数 ▸ 编辑单元格；预览侧立即渲染。
- **任务列表**：选中若干行 ▸ 点 **任务列表** ▸ 每行变成 `- [ ]`，预览里是可勾选样式的列表。

## 笔记之间的链接

笔记里的链接用 **Ctrl+点击**（Mac 上是 **⌘+点击**）打开。普通点击仍然是编辑文字。

- **标题**：`[文字](#标题)` 和 `[[#标题]]` 跳到本笔记里的那个标题。
- **其他文件**：`[文字](other.md)` 或 `[文字](../folder/report.pdf)` 以笔记所在文件夹为起点，在单独的标签页里打开该文件。指向另一篇 Markdown 笔记中的标题时，那篇笔记会停在该标题处。
- **双链**：`[[笔记]]`、`[[笔记#标题]]` 和 `[[笔记|显示文字]]` 会在笔记所属的库中任意位置查找。库是从笔记往上找到的第一个含有 `.obsidian` 的文件夹，找不到时就是笔记自己的文件夹。同名文件有多个时，打开离笔记更近的那个。
- **自动补全**：输入 `[[` 后从列表中选择库里的笔记，写入的是 `[[名称]]`。
- **图片**：`![[图片.png]]` 在文字下方显示图片，`![[图片.png|300]]` 设定宽度。只显示库内、不超过 20 MB 的图片。
- **不会改变的**：双链在文件里始终是纯文本，保存不会改写它们。网页链接在浏览器中打开。网络路径（`\\server\share`）、源码视图里的链接以及 AI 都不会打开任何东西。

## 导出

均在“文件”菜单中，全部是本地操作，并且都会询问结果要保存到哪里：

- **导出为 Word…** 和 **导出为 PDF…** 会写出真正的 .docx 或 .pdf 文件。
- **导出为 ODT…** 通过与导出 Word 相同的转换写出 .odt（OpenDocument 文本）；如果转换中有内容改变或丢失，会先列出并请你确认。
- **导出为图片…** 会把每一页各写成一个 PNG，放进您选择的目录。
- **转换为 Docs 文档并打开** 会转换为 .docx，并在本应用内置的 Docs 标签页中打开——它不是交给云端的任何服务，转换后的副本存放在一个缓存文件夹中，约一周后会被清理。

## 源码视图

工具排上有一个 **源码** 开关（随应用一起本地化）。打开后，编辑器会被原始的 Markdown 取代：就是保存时写入的那份文本，不美化，也不会在你背后做规范化。

- **编辑是字节级忠实的。** 在源码视图里保存，产出的字节与在编辑器里保存完全相同——BOM、CRLF 以及结尾是否有换行都原样保留。
- **还是同一份文档。** 随便来回切换；源码就是编辑器自己的文本，不是需要另行合并的副本。
- **格式工具条在这期间不可用**，因为那些按钮大多插入的是编辑器构造，只在渲染侧才有意义。关掉视图后它会回来。
- **.txt 与 .json** 直接以源码视图在这里打开：没有东西要渲染，源码*就是*文档本身。
