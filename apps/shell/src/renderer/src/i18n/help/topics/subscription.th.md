# การเชื่อมต่อการสมัครสมาชิก

AI ของ GenOffice ทำงานด้วยการสมัครสมาชิกที่คุณมีอยู่แล้ว จะเป็นการสมัครสมาชิก Claude (Anthropic) หรือแพ็กเกจ ChatGPT (OpenAI) ก็ได้ ChatGPT เชื่อมต่อใน GenOffice ได้โดยตรง หากคุณใช้โปรแกรม Codex ของ OpenAI ในคอมพิวเตอร์เครื่องนี้อยู่แล้ว จะเชื่อมต่อผ่าน Codex แทนก็ได้ ไม่ต้องใช้คีย์ API และ GenOffice ก็ไม่มีบัญชีของตัวเองให้สมัคร

## หลักการทำงาน

- AI ไม่ได้ฝังอยู่ใน GenOffice Claude ทำงานผ่านโปรแกรม **Claude Code** ที่ติดตั้งอยู่ในคอมพิวเตอร์เครื่องนี้ GenOffice จะขอคำตอบจากโปรแกรมนั้น และโปรแกรมนั้นเข้าสู่ระบบด้วยบัญชีของคุณเอง ทุกคำขอจึงนับรวมในการใช้งานแพ็กเกจของคุณเอง
- ChatGPT เชื่อมต่อโดย GenOffice เองโดยไม่ต้องใช้โปรแกรมใด ให้เข้าสู่ระบบในหน้าเข้าสู่ระบบ ChatGPT ของ OpenAI ที่เปิดขึ้นในเบราว์เซอร์ แล้วอนุญาตให้แอปนี้ใช้แพ็กเกจ ChatGPT ของคุณ คำขอจะส่งจากคอมพิวเตอร์เครื่องนี้ไปยัง OpenAI โดยตรง และการใช้งานจะนับจากแพ็กเกจ ChatGPT นั้น
- **Codex** เป็นโปรแกรมของ OpenAI เมื่อเชื่อมต่อ ChatGPT ผ่าน Codex แล้ว GenOffice จะขอคำตอบจากโปรแกรม Codex ในแบบเดียวกับ Claude Code
- GenOffice ไม่มีหน้าเข้าสู่ระบบของตัวเองภายในแอป คุณเข้าสู่ระบบในโปรแกรมของบริษัทนั้นเอง หรือในหน้าเว็บของบริษัทนั้นที่เปิดขึ้นในเบราว์เซอร์ GenOffice ไม่อ่านหรือเก็บข้อมูลการเข้าสู่ระบบของ Claude Code หรือ Codex ข้อมูลการเข้าสู่ระบบเพียงอย่างเดียวที่ GenOffice เก็บไว้คือข้อมูลที่ OpenAI มอบให้แอปนี้เมื่อคุณเชื่อมต่อ ChatGPT โดยตรง และข้อมูลนี้อยู่ในคอมพิวเตอร์เครื่องนี้เท่านั้น (เข้ารหัสไว้บน Windows) GenOffice ไม่เคยเห็นรหัสผ่าน ChatGPT ของคุณ

## ก่อนเริ่มต้น

คุณต้องมีอย่างใดอย่างหนึ่งต่อไปนี้ จะมีทั้งสองอย่างก็ได้

- การสมัครสมาชิก Claude (แพ็กเกจ Pro หรือ Max บัญชี Claude แบบฟรีเชื่อมต่อไม่ได้) และโปรแกรม Claude Code ที่ติดตั้งและเข้าสู่ระบบแล้วในคอมพิวเตอร์เครื่องนี้
- แพ็กเกจ ChatGPT หากเชื่อมต่อโดยตรงก็ไม่มีโปรแกรมที่ต้องติดตั้ง แพ็กเกจฟรีใช้งานได้เพียงเล็กน้อย หากคุณใช้โปรแกรม Codex ในคอมพิวเตอร์เครื่องนี้อยู่แล้ว จะเชื่อมต่อผ่าน Codex แทนก็ได้

ถ้ายังไม่ได้ติดตั้ง Claude Code หรือ Codex หรือยังไม่ได้เข้าสู่ระบบ ปุ่มในหัวข้อถัดไปจะช่วยจัดการให้

## การเชื่อมต่อ

1. เปิด **การตั้งค่า** จากแถวที่มุมล่างซ้ายของหน้าแรก แล้วเลือก **AI** ใต้ **การเชื่อมต่อการสมัครสมาชิก** จะมีการ์ดของ Claude, ChatGPT และ Codex ตามลำดับ ถ้าคุณมีแพ็กเกจ ChatGPT ให้เชื่อมต่อที่การ์ด ChatGPT ส่วนการ์ด Codex มีไว้สำหรับผู้ที่ใช้โปรแกรม Codex ในคอมพิวเตอร์เครื่องนี้
2. อ่านสถานะที่การ์ดแสดง แล้วกดปุ่มบนการ์ด ตารางด้านล่างอธิบายความหมายของแต่ละสถานะ
3. กลับมาที่หน้าต่าง GenOffice การ์ดจะตรวจสอบใหม่เอง ส่วน **ตรวจสอบอีกครั้ง** จะตรวจสอบทันที

ในขั้นตอนที่สองของหน้าจอต้อนรับเมื่อเปิดแอปครั้งแรก และในแผง AI เมื่อยังไม่มี AI ที่เชื่อมต่ออยู่ จะมีคำถาม "ตอนนี้คุณใช้ AI ตัวไหนอยู่" ขึ้นมาก่อน เลือกการสมัครสมาชิก Claude แบบชำระเงิน ChatGPT หรือยังไม่มีทั้งสองอย่าง แล้วจะเห็นเฉพาะขั้นตอนของทางนั้นและการ์ดของทางนั้นเพียงใบเดียว สำหรับ Claude ขั้นตอนคือ ติดตั้งโปรแกรม → เข้าสู่ระบบ → เชื่อมต่อเสร็จสิ้น สำหรับ ChatGPT คือ เข้าสู่ระบบ → เชื่อมต่อเสร็จสิ้น ในทางของ ChatGPT ปุ่ม **ใช้โปรแกรม Codex ในคอมพิวเตอร์เครื่องนี้อยู่แล้วใช่ไหม เชื่อมต่อผ่าน Codex** จะสลับไปยังทางของ Codex (ติดตั้งโปรแกรม → เข้าสู่ระบบ → เชื่อมต่อเสร็จสิ้น) และ **เชื่อมต่อในแอปโดยตรง ไม่ต้องใช้ Codex** ในทางนั้นจะพาคุณกลับไปยังการเชื่อมต่อโดยตรง หาก Codex เชื่อมต่ออยู่แล้ว จะแสดงทางของ Codex ตั้งแต่แรก กด **เลือกวิธีอื่น** เพื่อเลือกใหม่ได้ และจะข้ามทั้งหมดไปก่อนแล้วค่อยเชื่อมต่อภายหลังก็ได้ ถ้ายังเชื่อมต่อไม่ได้ ให้กด **คัดลอกข้อมูลเพื่อขอความช่วยเหลือ** แล้วส่งสิ่งที่คัดลอกให้คนที่ช่วยคุณ ข้อมูลนี้ไม่มีบัญชีและเส้นทางไฟล์

การ์ด ChatGPT ไม่ได้ทำงานผ่านโปรแกรมใด จึงไม่แสดง **ยังไม่ได้ติดตั้ง** หรือ **เข้าสู่ระบบแล้ว แต่ไม่ใช่ด้วยการสมัครสมาชิก** เมื่อการ์ดแสดง **ยังไม่ได้เข้าสู่ระบบ** ให้กด **ดำเนินการต่อด้วย ChatGPT** หน้าเข้าสู่ระบบ ChatGPT ของ OpenAI จะเปิดขึ้นในเบราว์เซอร์ เมื่อเข้าสู่ระบบและอนุญาตให้แอปนี้ใช้แพ็กเกจ ChatGPT ของคุณแล้ว การ์ดจะเปลี่ยนเป็น **เชื่อมต่อแล้ว** เอง หากคุณไม่ได้อนุญาต หรือทำไม่เสร็จภายใน 10 นาที การ์ดจะแจ้งว่าการเข้าสู่ระบบยังไม่เสร็จสิ้น กดปุ่มอีกครั้งเพื่อเริ่มใหม่ตั้งแต่ต้น ไม่มีหน้าต่างเข้าสู่ระบบและไม่มีรหัสที่ต้องวาง ระหว่างที่กำลังเข้าสู่ระบบ กด **ยกเลิกการเข้าสู่ระบบ** เพื่อหยุดได้

แอปจะตรวจสอบการเชื่อมต่อเมื่อเริ่มทำงาน เมื่อคุณเปิดการตั้งค่า และเมื่อคุณกลับมาที่หน้าต่างหลังจากเริ่มการติดตั้งหรือการเข้าสู่ระบบ

หากการ์ดของ Claude หรือ Codex แจ้งว่าการลงชื่อเข้าใช้ยังไม่เสร็จสิ้น ให้เลือก **เปิดหน้าต่างเข้าสู่ระบบ** รหัสที่เบราว์เซอร์แสดงต้องวางในหน้าต่างนั้น รหัสที่แสดงก่อนหน้านี้ใช้ไม่ได้แล้ว

หากหน้าเบราว์เซอร์หรือหน้าต่างลงชื่อเข้าใช้แสดง `3p_delegated_access_policy_denied` อาจเป็นเพราะนโยบายที่ใช้กับบัญชี Claude นั้นบล็อกการลงชื่อเข้าใช้ครั้งนี้ หากลองใหม่แล้วยังเป็นเหมือนเดิม โปรดสอบถามผู้ที่ดูแลบัญชี หรือลองดูว่าบัญชีอื่นใช้ได้หรือไม่

## ไม่มีการสมัครสมาชิก: AI ฟรี

ไม่มีการสมัครสมาชิก Claude หรือ ChatGPT ใช่ไหม ใน การตั้งค่า ▸ AI ส่วน **ใช้ฟรี** จะเชื่อมต่อ AI ฟรีให้แทน ถ้าเลือก **ยังไม่มีทั้งสองอย่าง** ในขั้นตอนที่สองของหน้าจอต้อนรับ จะเห็นการ์ดชุดเดียวกันนี้ และถ้าเลือกในแผง AI เมื่อยังไม่มีอะไรเชื่อมต่ออยู่ จะมี **เชื่อมต่อ AI ฟรี** ให้กด

- **OpenRouter**: กด **เชื่อมต่อในเบราว์เซอร์** เบราว์เซอร์จะเปิด OpenRouter ให้สมัครหรือเข้าสู่ระบบ แล้วอนุญาตการเข้าถึง เมื่อเบราว์เซอร์แจ้งว่าเชื่อมต่อแล้ว ให้ปิดแท็บนั้นแล้วกลับมา ไม่ต้องคัดลอกคีย์ใด ๆ และการ์ดจะแสดงว่าวันนี้เหลือคำขอฟรีอีกกี่ครั้ง
- **Google Gemini**: กด **รับคีย์** สร้างคีย์ใน Google AI Studio วางลงในการ์ด แล้วกด **เชื่อมต่อ** สำหรับผู้ที่มีอายุ 18 ปีขึ้นไปเท่านั้น คีย์ที่สร้างในโปรเจกต์ Google ที่เปิดการเรียกเก็บเงินไว้อาจถูกคิดค่าบริการ
- เมื่อเชื่อมต่อแล้ว AI นั้นจะกลายเป็น **AI ที่ใช้** หากเชื่อมต่อไว้ทั้งสองตัว ปุ่ม **ใช้ AI นี้** บนการ์ดจะสลับระหว่างกัน ส่วน **ยกเลิกการเชื่อมต่อ** จะลบคีย์ออกจาก GenOffice
- โมเดลฟรีมีความสามารถน้อยกว่าโมเดลของการสมัครสมาชิก และแต่ละวันส่งคำขอได้จำนวนจำกัด การแก้ไขเอกสารหนึ่งครั้งอาจใช้คำขอหลายครั้ง เมื่อใช้โควตาของวันนี้หมดแล้ว แผง AI จะแจ้งให้ทราบ พร้อมบอกว่าจะใช้ได้อีกเมื่อไร
- ระหว่างที่ใช้ฟรี สิ่งที่คุณส่งไปอาจถูกนำไปใช้ปรับปรุง AI ของบริษัทนั้น โปรดระมัดระวังเอกสารที่มีข้อมูลส่วนบุคคล

## การเข้าสู่ระบบแบบจ่ายตามการใช้งาน

การ์ดที่แสดง **เข้าสู่ระบบแล้ว แต่ไม่ใช่ด้วยการสมัครสมาชิก** จะมีคำเตือนกำกับไว้ว่า "นี่ไม่ใช่การสมัครสมาชิก: คุณจะถูกคิดค่าบริการตามที่ใช้จริง"

- GenOffice จะไม่ใช้การเข้าสู่ระบบนั้นจนกว่าคุณจะกด **ใช้ต่อไป** หลังจากนั้นทุกคำขอจะถูกเรียกเก็บจากบัญชีนั้น
- ถึงอย่างนั้นก็จะไม่ถูกเลือกโดยอัตโนมัติ คุณต้องเลือกเองใน **AI ที่ใช้** ซึ่งจะมีป้าย **มีค่าใช้จ่าย** กำกับอยู่
- การอนุญาตของคุณจะถูกจำไว้เฉพาะสำหรับโปรแกรมนั้น และจะถูกล้างเมื่อโปรแกรมออกจากระบบหรือการเข้าสู่ระบบเปลี่ยนไป
- หากต้องการใช้การสมัครสมาชิกแทน ให้เข้าสู่ระบบโปรแกรมด้วยบัญชีที่สมัครสมาชิกไว้ แล้วกด **ตรวจสอบอีกครั้ง**

## เปลี่ยนบัญชีหรือออกจากระบบ

การ์ดที่เข้าสู่ระบบอยู่จะแสดงบัญชีที่ใช้อยู่ การ์ดของ Claude และ Codex จะแสดงชื่อแพ็กเกจด้วยหากโปรแกรมรายงานมา และจะมีปุ่มเพิ่มอีกสองปุ่ม

- **เข้าสู่ระบบด้วยบัญชีอื่น** จะเริ่มขั้นตอนเข้าสู่ระบบของโปรแกรมเองอีกครั้ง ให้ทำต่อจนเสร็จในหน้าต่างที่เปิดขึ้น ด้วยบัญชีอีกบัญชีหนึ่ง
- **ออกจากระบบ** จะเรียกใช้การออกจากระบบของโปรแกรมเอง จากนั้นการ์ดจะแสดงว่า **ยังไม่ได้เข้าสู่ระบบ**
- บนการ์ดของ Claude และ Codex ทั้งสองอย่างมีผลกับโปรแกรมนั้นทั้งเครื่องนี้ ไม่ใช่เฉพาะใน GenOffice หากคุณใช้ Claude Code หรือ Codex ในเทอร์มินัลด้วย ที่นั่นก็จะถูกออกจากระบบหรือเปลี่ยนไปใช้อีกบัญชีหนึ่งเช่นกัน GenOffice จึงขอให้คุณยืนยันก่อน
- การ์ดของ Claude และ Codex ยังมี **ไม่ใช้ในแอปนี้** ด้วย โปรแกรมและการลงชื่อเข้าใช้ยังคงเหมือนเดิม มีเพียง GenOffice ที่เลิกใช้โปรแกรมนั้น คือไม่ตรวจสอบสถานะ ไม่ส่งคำขอ และ **อัตโนมัติ** จะข้ามโปรแกรมนั้นไป การใช้งานในเทอร์มินัลไม่ได้รับผลกระทบ จากนั้นการ์ดจะแสดง **ปิดไว้ในแอปนี้** และ **ใช้อีกครั้ง** จะเปิดกลับมา ทั้งสองอย่างไม่ถามยืนยัน เพราะไม่มีอะไรนอก GenOffice เปลี่ยน
- การ์ด ChatGPT ต่างออกไป **ออกจากระบบ** จะขอให้คุณยืนยันด้วยข้อความ "การดำเนินการนี้จะยกเลิกการเชื่อมต่อ ChatGPT กับแอปนี้" เมื่อยืนยันแล้ว GenOffice จะขอให้ OpenAI ยุติการเชื่อมต่อของแอปนี้ และลบข้อมูลการเข้าสู่ระบบที่เก็บไว้ในคอมพิวเตอร์เครื่องนี้ ส่วน **เข้าสู่ระบบด้วยบัญชีอื่น** จะเปิดหน้าเข้าสู่ระบบในเบราว์เซอร์ทันทีโดยไม่ถาม ทั้งสองอย่างไม่มีผลกับโปรแกรมอื่นในคอมพิวเตอร์เครื่องนี้ รวมถึง Codex
- การ์ด ChatGPT ที่เชื่อมต่อแล้วจะแสดงว่า "AI ในแอปนี้ทำงานตามแพ็กเกจ ChatGPT ของคุณ" และมีลิงก์ **จัดการการใช้งาน** ซึ่งจะเปิดหน้าการใช้งานในการตั้งค่า ChatGPT ของคุณ ที่นั่นคุณดูได้ว่าแอปนี้ใช้ไปเท่าใด และตั้งขีดจำกัดเฉพาะสำหรับแอปนี้ได้
- บัญชีและปุ่มสองปุ่มนี้มีเฉพาะที่นี่ ใน การตั้งค่า ▸ AI เท่านั้น GenOffice เพียงแสดงบัญชีและไม่บันทึกไว้ที่ใดเลย

## AI ตัวไหนถูกใช้

**AI ที่ใช้** ใน การตั้งค่า ▸ AI เริ่มต้นที่ **อัตโนมัติ** โดยอัตโนมัติจะตัดสินใจตามลำดับนี้

1. Claude เมื่อการ์ดของ Claude แสดงว่า "เชื่อมต่อแล้ว"
2. ถ้าไม่ใช่ ก็เป็น ChatGPT เมื่อการ์ดของ ChatGPT แสดงว่า "เชื่อมต่อแล้ว"
3. ถ้าไม่ใช่ ก็เป็น Codex เมื่อการ์ดของ Codex แสดงว่า "เชื่อมต่อแล้ว"
4. ถ้าไม่ใช่ทั้งหมดนี้ แสดงว่ายังไม่มี AI ที่เชื่อมต่ออยู่ และแผง AI จะแสดงคู่มือการเชื่อมต่อแทนข้อความแสดงข้อผิดพลาด

อัตโนมัติจะไม่เลือกสิ่งที่มีค่าใช้จ่ายเพิ่ม ไม่ว่าจะเป็นคีย์ API หรือการเข้าสู่ระบบแบบจ่ายตามการใช้งาน สิ่งเหล่านี้จะถูกใช้เฉพาะช่วงที่คุณเลือกไว้เองเท่านั้น

คุณเลือก AI ตัวใดตัวหนึ่งเองก็ได้ ทั้งที่ตำแหน่งเดียวกันนี้ หรือในรายการโมเดลที่ด้านล่างของแผง AI ถ้า AI ที่คุณเลือกเกิดใช้งานไม่ได้ GenOffice จะไม่สลับไปใช้ตัวอื่นเงียบ ๆ แต่จะบอกว่าเกิดอะไรขึ้น และแสดงวิธีเชื่อมต่อใหม่

รายการโมเดลแสดงโมเดลที่โปรแกรมรายงานมาเอง (สำหรับ ChatGPT คือโมเดลที่ OpenAI แจ้งว่าแพ็กเกจของคุณใช้ได้ และจะใช้โมเดลแรกในรายการจนกว่าคุณจะเลือกเอง) แต่ละโมเดลแสดงชื่อพร้อมรหัสโมเดลที่ถูกต้องอยู่ข้าง ๆ และ **โมเดลเริ่มต้น** จะระบุว่าตอนนี้หมายถึงโมเดลใด ป้ายที่ด้านล่างของแผง AI และ **AI ที่ใช้** ก็แสดงชื่อโมเดลนั้นด้วย การอ่านรายการไม่ได้ถามอะไร AI จึงไม่นับรวมในแพ็กเกจของคุณ หากโปรแกรมเก่าเกินกว่าจะรายงานโมเดลได้ จะแสดงรายการสั้น ๆ ที่มีมาในแอปแทน

ทุกที่ที่เลือก Codex ได้ จะมีข้อความหนึ่งบรรทัดแสดงคู่กันว่า "การใช้การสมัครสมาชิก Codex ภายในแอปไม่ใช่วิธีที่ OpenAI แนะนำอย่างเป็นทางการ" โปรดคำนึงถึงข้อนี้ก่อนตัดสินใจ

## เมื่อคำขอถูกหยุด

คำขอจะหยุดเมื่อใช้โควตาของแพ็กเกจครบแล้ว เมื่อการเข้าสู่ระบบหมดอายุ หรือเมื่อไม่มีโปรแกรมอยู่แล้ว GenOffice จะไม่สลับไปใช้ AI ตัวอื่นเอง

- สาเหตุจะแสดงตรงจุดที่คำตอบหยุด ในกรณีที่ใช้โควตาครบ จะแสดงเวลาที่โควตารีเซ็ตด้วยเมื่อโปรแกรมรายงานมา
- ChatGPT ที่เชื่อมต่อโดยตรงจะหยุดเมื่อใช้โควตาของแพ็กเกจครบแล้ว หรือเมื่อครบขีดจำกัดที่คุณตั้งไว้สำหรับแอปนี้ในการตั้งค่า ChatGPT โดยจะไม่แสดงเวลารีเซ็ต หากคุณยกเลิกการเชื่อมต่อแอปนี้ในการตั้งค่า ChatGPT การ์ดจะเปลี่ยนเป็น **ยังไม่ได้เข้าสู่ระบบ** ให้เข้าสู่ระบบอีกครั้ง
- ถ้าการสมัครสมาชิกอีกรายการของคุณเชื่อมต่ออยู่ จะมีปุ่ม **ดำเนินการต่อด้วย …** ปรากฏขึ้น เช่น **ดำเนินการต่อด้วย ChatGPT** หรือ **ดำเนินการต่อด้วย Codex** เมื่อกดแล้ว รายการนั้นจะกลายเป็น AI ที่ใช้ — รายการโมเดลจะแสดงการเปลี่ยนแปลงนี้ — และคำขอจะถูกเรียกใช้อีกครั้ง
- ถ้าการเชื่อมต่ออื่นที่เหลืออยู่มีเพียงการเข้าสู่ระบบแบบจ่ายตามการใช้งานที่คุณอนุญาตไว้ ปุ่มเดียวกันนี้จะมีหมายเหตุเรื่องค่าใช้จ่ายกำกับมาด้วย
- จะไม่มีปุ่มที่พาคุณไปใช้คีย์ API เลย

## บรรทัดแสดงการใช้งาน

เมื่อคุณใช้โควตาไปแล้ว 80% ขึ้นไป แผง AI จะแสดงบรรทัดอย่างเช่น "ใช้ไปแล้ว 85% · รีเซ็ตเวลา 15:00" Claude รายงานโควตา 5 ชั่วโมงและโควตา 7 วัน ส่วน Codex ก็จะแสดงในแบบเดียวกันเมื่อรายงานข้อมูลนี้มา ถ้าต่ำกว่า 80% หรือโปรแกรมไม่ได้รายงานอะไรมา จะไม่มีบรรทัดนี้แสดง ChatGPT ที่เชื่อมต่อโดยตรงจะไม่มีบรรทัดนี้ ให้ดูว่าใช้ไปเท่าใดผ่าน **จัดการการใช้งาน** บนการ์ด ChatGPT

## อะไรถูกส่งไป และส่งไปที่ไหน

ครั้งแรกที่ใช้การสมัครสมาชิกได้ GenOffice จะแสดงประกาศหนึ่งครั้ง หากต้องการอ่านอีกครั้ง ให้ไปที่ การตั้งค่า ▸ AI ▸ **ประกาศเมื่อเชื่อมต่อครั้งแรก** แล้วกด **ดูอีกครั้ง** ประกาศนี้บอกสามเรื่อง

- เนื้อหาเอกสารและบทสนทนาจะถูกส่งไปยัง Anthropic หรือ OpenAI ภายใต้บัญชีของคุณเอง
- เนื้อหานั้นจะถูกนำไปใช้ฝึก AI หรือไม่ ขึ้นอยู่กับการตั้งค่าบัญชีของคุณเองกับบริษัทนั้น ไม่ได้ขึ้นอยู่กับ GenOffice
- GenOffice ปิดการบันทึกประวัติการสนทนาของ Codex แต่ Codex อาจยังเก็บบันทึกการวินิจฉัยของตัวเองไว้ในคอมพิวเตอร์เครื่องนี้

คำขอผ่าน ChatGPT ที่เชื่อมต่อโดยตรงไม่ได้ผ่านโปรแกรม Codex แต่ส่งจากคอมพิวเตอร์เครื่องนี้ไปยัง OpenAI โดยตรง

สิ่งที่คุณซ่อนไว้ด้วย **ซ่อนส่วนที่เลือกจาก AI** จะไม่ถูกส่งไป ไม่ว่าคุณจะใช้ AI ตัวไหน

## ข้อควรรู้

- **ความเร็ว** คำตอบที่ผ่าน Claude Code หรือ Codex จะเริ่มช้ากว่าคำตอบที่ผ่านคีย์ API อยู่ไม่กี่วินาที เพราะโปรแกรมต้องเริ่มทำงานก่อน ส่วน ChatGPT ที่เชื่อมต่อโดยตรงไม่ต้องเริ่มโปรแกรมใด
- **แพ็กเกจฟรีของ ChatGPT** จะแสดงเป็น "เชื่อมต่อแล้ว" แต่โควตามีน้อย คำขอจึงหยุดเร็วกว่า และจะไม่มีบรรทัดแสดงการใช้งานให้เห็น
- **การสร้างภาพ** ในเวอร์ชันนี้ การสมัครสมาชิกสร้างภาพไม่ได้ ไม่ว่าจะเป็นแพ็กเกจใด การสร้างภาพต้องใช้คีย์ของผู้ให้บริการสร้างภาพ ดู [โมเดล AI และการตั้งค่า](help://ai-models)
- **พร็อกซี** Claude Code และ Codex ไม่รับการตั้งค่าพร็อกซีจาก GenOffice แต่ใช้พร็อกซีที่ตั้งไว้สำหรับคอมพิวเตอร์เครื่องนี้ เช่น ตัวแปรสภาพแวดล้อม `HTTPS_PROXY` เหมือนกับตอนที่คุณเรียกใช้ในเทอร์มินัล ถ้าเชื่อมต่อในเทอร์มินัลไม่ได้ ก็เชื่อมต่อจากที่นี่ไม่ได้เช่นกัน
- **คำสั่งและโปรแกรมอื่น** คำขอที่มาจากคำสั่ง `ieumoffice` หรือจากเอเจนต์เขียนโค้ดที่เชื่อมต่อไว้ จะไม่ใช้การสมัครสมาชิกของคุณ เว้นแต่คุณจะอนุญาต และแม้จะอนุญาตแล้ว ก็จะใช้ Claude Code หรือ Codex ไม่ใช้ ChatGPT ที่เชื่อมต่อโดยตรง ดู [เชื่อมต่อเอเจนต์เขียนโค้ด](help://mcp)
- **โหมดเอเจนต์** [โหมดเอเจนต์](help://agent-mode) เรียกใช้ Claude Code หรือ Codex ในคอมพิวเตอร์เครื่องนี้ ChatGPT ที่เชื่อมต่อโดยตรงเรียกใช้เอเจนต์ไม่ได้
