# 描画エディター

描画エディターは Excalidraw の描画を専用のタブで開き、変更を同じファイルに保存します。

- **開けるファイル**：Obsidian の Excalidraw プラグインで描いた描画ノート（`.excalidraw.md`、または front matter に `excalidraw-plugin` がある `.md`）と、Excalidraw の Web アプリの `.excalidraw` ファイル。
- **新しい描画**：ホームの **Excalidraw 描画** カード、または **ファイル ▸ 新規作成**。新しい描画は Obsidian の描画ノート（`.excalidraw.md`）で、名前は最初に保存するときに付けます。
- **描く**：図形、矢印、線、フリーハンド、テキストを、キャンバスのツールバーとショートカットで描きます。ctrl+Z で元に戻します。
- **保存**：ctrl+S。ファイルは開いたときの形式で保存されます。自動保存は 30 秒ごとと、ウィンドウがフォーカスを失ったときに書き込みますが、まだファイル名のない描画は飛ばします。開いて見ただけの描画は、元のバイトのまま保存されます。

## Obsidian の描画ノート

- 保存で書き直すのは、ノートのテキスト一覧と描画データだけです。front matter、ノートに書いた文章、リンクはそのまま残るので、Obsidian でも同じように開けます。
- ノートが参照する画像（Embedded Files の下の `[[画像.png]]`）は、ノートの保管庫の中にあれば表示されます。保管庫とは、ノートから上にたどって最初に `.obsidian` フォルダーを含むフォルダーで、なければノート自身のフォルダーです。20 MB を超える画像、隠しフォルダーにある画像、保管庫の外にある画像は表示されません。
- ノートに新しい画像を加えることは、まだできません。画像ツールはオフになっていて、キャンバスへのファイルのドロップも止めてあります。ノートの中だけに入った画像は、Obsidian で表示されないことがあるためです。

## まだできないこと

- AI パネルはありません。AI は描画を読むことも変えることもできません。
- PNG や SVG への書き出しはありません。
- エディターはネットワークに接続しません。フォントは組み込みで、共有ライブラリ、リアルタイム共同編集、Web の埋め込みはオフです。描画の中のリンクは、Web アドレスかメールアドレスのときだけブラウザーで開きます。

## エクスプローラーから描画を開く

インストーラーは `.excalidraw` ファイルの **プログラムから開く** にこのアプリを加えますが、既定のプログラムにはしません。描画ノートは `.md` ファイルなので、アプリで Markdown ファイルを開ける場所ならどこからでも開け、Markdown エディターではなく描画エディターで開きます。
