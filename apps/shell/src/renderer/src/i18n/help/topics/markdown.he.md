# עורך ה-Markdown

עורך ה-Markdown פותח ‎.md / .markdown‎ — וגם ‎.txt / .json‎, ישר לתצוגת המקור — עם מקור ותצוגה מרונדרת.

- **פתיחה**: מהמסך הבית או מ-File ▸ פתיחה; גם משורת הפקודה.
- **עריכה**: עריכת טקסט רגיל; הרחבות GFM (טבלאות, רשימות משימות, קו חוצה, קישורים אוטומטיים) מרונדרות בתצוגה המקדימה.
- **תצוגה מקדימה**: בזמן אמת; נכסים יחסיים כמו תמונות נפתרים לצד המסמך.
- **שמירה**: נאמנה לבתים — BOM, CRLF ונוכחות של שורת שיור בסוף נשמרים; שמירה ללא שינוי אינה כותבת מחדש את הקובץ.
- **חיפוש והחלפה**: ctrl+F מחפש במקור; החלפת הכול כותבת חזרה.
- **AI**: כפתורי ברירת מחדל מאפשרים לעוזר לנסח מחדש, להרחיב או לתרגם את המסמך. אפשר להסתיר בחירה מה-AI (ראו את פרק חלונית ה-AI).

## סרגל הכלים

שורה אחת של כפתורים מעל העורך (רחפו לקבלת תיאורים):

- **קובץ והיסטוריה**: שמירה, שמירה בשם, ביטול, ביצוע מחדש, חיפוש; המתג **שמירה אוטומטית** מימין כותב שינויים לדיסק מדי פרק זמן.
- **כפתור AI**: פותח את חלונית ה-AI; לצידו כפתורי ברירת מחדל לניסוח מחדש / הרחבה / תרגום.
- **סגנון פסקה** (תפריט נפתח): מעבר בין טקסט רגיל לרמות כותרת.
- **עיצוב בתוך שורה**: **מודגש**, _נטוי_, ~~קו חוצה~~, `קוד מוטבע`, קישור.
- **רשימות**: תבליטים, ממוספרת, רשימת משימות.
- **הוספה**: טבלה, תמונה, קו מפריד.
- **מאפיינים**: הוספה או קפיצה אל בלוק ה-YAML front matter בראש הקובץ.
- **מתאר**: קפיצה לפי היררכיית הכותרות.
- **בדיקת איות**: הפעלה או כיבוי של בדיקת האיות למסמך הזה.
- **הגדרות מארח תמונות**: תמונות מודבקות ונגררות נשלחות קודם לאחסון שלכם — תואם S3 ‏(R2/OSS/COS/MinIO), SM.MS או GitHub — העותק המקומי ב-assets נשאר כגיבוי.

שלושה דוגמאות מהירות:

- **כותרת**: ממקמים את הסמן בשורה ▸ תפריט סגנון הפסקה ▸ "כותרת 1".
- **טבלה**: לחצו על **הוספת טבלה** ▸ גררו את מספר השורות והעמודות ▸ מקלידים בתאים; התצוגה המקדימה מרונדרת אותה מיד.
- **רשימת משימות**: בחרו כמה שורות ▸ לחצו על **רשימת משימות** ▸ כל שורה הופכת ל-`- [ ]`, ומרונדרת כתיבים ניתנים לסימון בתצוגה המקדימה.

## קישורים בין פתקים

קישורים בפתק נפתחים ב-**Ctrl+לחיצה** (**⌘+לחיצה** ב-Mac). לחיצה רגילה ממשיכה לערוך את הטקסט.

- **כותרות**: `[טקסט](#כותרת)` ו-`[[#כותרת]]` עוברים לכותרת הזאת באותו פתק.
- **קבצים אחרים**: `[טקסט](other.md)` או `[טקסט](../folder/report.pdf)` פותח את הקובץ בכרטיסייה משלו, ביחס לתיקיית הפתק. קישור לכותרת בפתק Markdown אחר פותח את הפתק ההוא בכותרת.
- **קישורי ויקי**: `[[פתק]]`, `[[פתק#כותרת]]` ו-`[[פתק|טקסט מוצג]]` מחופשים בכל מקום בכספת של הפתק — התיקייה הקרובה ביותר מעל הפתק שמכילה `.obsidian`, ואם אין כזו, תיקיית הפתק עצמה. כששני קבצים נושאים אותו שם, נבחר הקרוב יותר לפתק.
- **השלמה**: הקלידו `[[` ובחרו פתק מהכספת ברשימה; הוא נכתב כ-`[[שם]]`.
- **תמונות**: `![[תמונה.png]]` מציג את התמונה מתחת לטקסט, ו-`![[תמונה.png|300]]` קובע את הרוחב. מוצגות רק תמונות בתוך הכספת בגודל של עד 20 MB.
- **מה לא משתנה**: קישורי ויקי נשארים טקסט רגיל בקובץ, ולכן שמירה אף פעם לא כותבת אותם מחדש. קישורי אינטרנט נפתחים בדפדפן. נתיבי רשת (`\\server\share`), קישורים בתצוגת המקור וה-AI לא פותחים דבר.

## ייצוא

תפריט קובץ, הכול מקומי והכול שואל לאן לשים את התוצאה:

- **ייצוא כ-Word…** ו־**ייצוא כ-PDF…** כותבים קובץ .docx או .pdf אמיתי.
- **ייצוא כ-ODT…** כותב קובץ .odt (טקסט OpenDocument) באותה המרה שמשמשת לייצוא ל-Word; אם משהו משתנה או אובד בדרך, תוצג הרשימה ותתבקשו לאשר קודם.
- **ייצוא כתמונות…** כותב קובץ PNG אחד לכל עמוד לתיקייה שבוחרים.
- **המרה ופתיחה ב-Docs** ממיר ל־.docx ופותח אותו בלשונית Docs המובנית כאן ביישום — זה אינו העברה לשום דבר בענן, והעותק שהומר שוכן בתיקיית מטמון שנמחקת בעוד כשבוע לערך.

## תצוגת מקור

בסרגל הכלים יש מתג **מקור** (מתורגם יחד עם האפליקציה). הפעילו אותו, והעורך מוחלף ב-Markdown הגולמי: בדיוק הטקסט ששמירה כותבת, בלי יופי ובלי נרמול מתחת לידייכם.

- **העריכה נאמנה לבתים.** שמירה מתצוגת המקור מפיקה את אותם בתים ששמירה מהעורך מפיקה — BOM, ‏CRLF ונוכחות שורת שיור בסוף נשמרים כולם.
- **זהו אותו מסמך.** אפשר לעבור בין השניים בחופשיות; המקור הוא הטקסט של העורך עצמו, לא עותק שצריך למזג.
- **סרגל העיצוב אינו זמין** כל עוד התצוגה פתוחה, מפני שרוב אותם כפתורים מכניסים מבנים של עורך שיש להם משמעות רק בצד המרונדר. הוא חוזר כשאתם סוגרים את התצוגה.
- **‎.txt ו-.json**‎ נפתחים כאן ישירות בתצוגת מקור: אין מה לרנדר, אז המקור _הוא_ המסמך.
