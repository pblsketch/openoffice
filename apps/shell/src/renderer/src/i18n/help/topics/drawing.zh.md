# 绘图编辑器

绘图编辑器在单独的标签页中打开 Excalidraw 绘图，并把改动保存回同一个文件。

- **能打开的文件**：用 Obsidian 的 Excalidraw 插件画的绘图笔记（`.excalidraw.md`，或 front matter 中带有 `excalidraw-plugin` 的 `.md`），以及 Excalidraw 网页应用的 `.excalidraw` 文件。
- **新建绘图**：主页上的 **Excalidraw 绘图** 卡片，或 **文件 ▸ 新建**。新绘图是一篇 Obsidian 绘图笔记（`.excalidraw.md`），名称在第一次保存时确定。
- **绘图**：用画布自带的工具栏和快捷键画形状、箭头、线条、自由线条和文字。ctrl+Z 撤销。
- **保存**：ctrl+S。文件按打开时的格式保存。自动保存每 30 秒以及窗口失去焦点时写入一次，但会跳过还没有文件名的绘图。只是打开看过的绘图，保存时逐字节保持原样。

## Obsidian 绘图笔记

- 保存时只重写笔记的文字列表和绘图数据。front matter、你在笔记里写的文字和链接都保持原样，所以这篇笔记在 Obsidian 中打开的样子不变。
- 笔记引用的图片（Embedded Files 下的 `[[图片.png]]`）位于笔记所属的库中时才会显示。库是从笔记往上找到的第一个含有 `.obsidian` 文件夹的文件夹，找不到时就是笔记自己的文件夹。超过 20 MB、位于隐藏文件夹中或在库之外的图片不会显示。
- 暂时还不能往笔记里添加新图片。图片工具已关闭，往画布上拖放文件也被阻止，因为只保存在笔记内部的图片在 Obsidian 中可能显示不出来。

## 暂不支持的功能

- 没有 AI 面板。AI 无法读取或修改绘图。
- 不能导出为 PNG 或 SVG。
- 编辑器不连接网络。字体已内置，共享素材库、实时协作和网页嵌入都已关闭。绘图中的链接只有是网址或邮件地址时才会在浏览器中打开。

## 从文件资源管理器打开绘图

安装程序会把本应用加入 `.excalidraw` 文件的 **打开方式** 列表，但不会把它设为默认程序。绘图笔记是 `.md` 文件，所以凡是应用里能打开 Markdown 文件的地方都能打开它，并且会进入绘图编辑器，而不是 Markdown 编辑器。
