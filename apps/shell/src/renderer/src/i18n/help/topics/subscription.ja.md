# サブスクリプションの接続

GenOffice の AI は、すでにお持ちのサブスクリプションで動きます。Claude のサブスクリプション（Anthropic）か、ChatGPT のプラン（OpenAI）のどちらかがあれば使えます。ChatGPT は GenOffice で直接接続します。この PC で OpenAI の Codex プログラムをすでに使っている場合は、代わりに Codex 経由で接続することもできます。API キーは必要なく、GenOffice に新しく登録するアカウントもありません。

## しくみ

- AI は GenOffice に組み込まれているわけではありません。Claude は、この PC にインストールされた **Claude Code** プログラムを通します。GenOffice はそのプログラムに回答を依頼し、そのプログラムはご自身のアカウントでログインしているので、リクエストはすべてご自身のプランの使用量として数えられます。
- ChatGPT は、プログラムを使わずに GenOffice 自身が接続します。ブラウザーで開く OpenAI の ChatGPT ログインページでログインし、このアプリが ChatGPT のプランを使うことを許可します。リクエストはこの PC から OpenAI に直接送られ、使用量はその ChatGPT のプランから差し引かれます。
- **Codex** は OpenAI のプログラムです。ChatGPT を Codex 経由で接続した場合は、Claude Code と同じように、GenOffice が Codex プログラムに回答を依頼します。
- GenOffice はアプリ内に独自のログイン画面を持ちません。ログインは、その会社のプログラムか、ブラウザーで開くその会社の Web ページで行います。GenOffice が Claude Code や Codex のログイン情報を読み取ったり保存したりすることはありません。GenOffice が保管するログインは、ChatGPT を直接接続したときに OpenAI がこのアプリに発行するもの 1 つだけで、この PC にだけ保存されます（Windows では暗号化して保存します）。GenOffice が ChatGPT のパスワードを目にすることはありません。

## 始める前に

次のどちらかが必要です。両方あってもかまいません。

- Claude のサブスクリプション（Pro または Max プラン。無料の Claude アカウントでは接続できません）と、この PC にインストールしてログインを済ませた Claude Code プログラム。
- ChatGPT のプラン。直接接続する場合は、インストールするプログラムはありません。無料プランで使える量はわずかです。この PC で Codex プログラムをすでに使っている場合は、代わりに Codex 経由で接続することもできます。

Claude Code や Codex をまだインストールしていない場合や、まだログインしていない場合は、次の節のボタンで済ませられます。

## 接続する

1. ホームの左下の行から **設定** を開き、**AI** を選びます。**サブスクリプションの接続** の下に、Claude、ChatGPT、Codex のカードがこの順に並んでいます。ChatGPT のプランを使う場合は、ChatGPT のカードで接続します。Codex のカードは、この PC で Codex プログラムを使っている人のためのものです。
2. カードに書かれている状態を確認して、カードのボタンを押します。それぞれの状態の意味は下の表のとおりです。
3. GenOffice のウィンドウに戻ります。カードは自動で確認し直します。**再確認** を押すと、すぐに確認します。

初回起動時のようこそ画面の 2 番目のステップと、AI が接続されていないときの AI パネルでは、まず「いま使っている AI はありますか？」と尋ねます。Claude の有料サブスクリプション、ChatGPT、まだない、のどれかを選ぶと、その道筋の手順とカード 1 枚だけが表示されます。Claude の手順はプログラムのインストール → ログイン → 接続完了、ChatGPT の手順はログイン → 接続完了です。ChatGPT の道筋で **この PC で Codex プログラムをすでに使っていますか？Codex で接続** を押すと Codex の道筋（プログラムのインストール → ログイン → 接続完了）に切り替わり、その道筋で **Codex を使わず、アプリで直接接続** を押すと直接接続に戻ります。Codex がすでに接続されている場合は、最初から Codex の道筋が表示されます。**別の方法を選ぶ** で選び直せます。すべてスキップして、あとで接続してもかまいません。それでも接続できない場合は、**サポート用の情報をコピー** を押し、コピーされた内容を手伝ってくれる人に送ります。アカウントとファイルのパスは含まれません。

ChatGPT のカードはプログラムを通さないので、**未インストール** や **ログイン済みですが、サブスクリプションではありません** と表示されることはありません。**未ログイン** と表示されたら、**ChatGPT で続行** を押します。ブラウザーで OpenAI の ChatGPT ログインページが開きます。ログインして、このアプリが ChatGPT のプランを使うことを許可すると、カードは自動で **接続済み** に変わります。許可しなかった場合や 10 分以内に終わらなかった場合は、ログインが完了しなかったことがカードに表示されます。ボタンをもう一度押すと、最初からやり直せます。ログインウィンドウもコードの貼り付けもありません。ログインの途中で **ログインをキャンセル** を押すと中止できます。

接続は、アプリの起動時、設定を開いたとき、インストールやログインを始めたあとでウィンドウに戻ったときに確認されます。

Claude や Codex のカードにログインが完了しなかったという案内が出たら、**ログインウィンドウを開く** を選びます。ブラウザにコードが表示された場合は、そのコードをウィンドウに貼り付ける必要があります。前に表示されたコードは使えません。

ブラウザーの画面やサインイン ウィンドウに `3p_delegated_access_policy_denied` と表示された場合は、Claude アカウントにかかっているポリシーがこのサインインを止めた可能性があります。もう一度試しても同じなら、アカウントを管理している人に問い合わせるか、別のアカウントでできるか確かめてください。

## サブスクリプションなしで: 無料の AI

Claude や ChatGPT のサブスクリプションがない場合は、設定 ▸ AI の **無料で使う** で、代わりに無料の AI を接続できます。初回起動時のようこそ画面の 2 番目のステップで **まだありません** を選ぶと同じカードが表示され、AI が何も接続されていないときに AI パネルでこれを選ぶと **無料の AI を接続** が表示されます。

- **OpenRouter**：**ブラウザーで接続** を押します。ブラウザーで OpenRouter が開くので、登録またはログインして、アクセスを許可します。ブラウザーに接続済みと表示されたら、そのタブを閉じて戻ります。キーをコピーする必要はなく、今日残っている無料リクエストの数がカードに表示されます。
- **Google Gemini**：**キーを作成** を押して Google AI Studio でキーを作り、カードに貼り付けて **接続** を押します。18 歳以上の方だけが使えます。課金を有効にした Google プロジェクトで作ったキーには、料金が発生することがあります。
- 接続すると、その AI が **使用する AI** になります。両方を接続した場合は、カードの **この AI を使う** で切り替えます。**接続を解除** を押すと、GenOffice からキーが削除されます。
- 無料のモデルはサブスクリプションのモデルより性能が低く、1 日に送れるリクエストの数にも上限があります。文書を 1 回直すのに、リクエストを何回か使うことがあります。今日の上限に達すると、AI パネルがそのことと、また使えるようになる時刻を知らせます。
- 無料で使っている間は、送った内容がその会社の AI の改善に使われることがあります。個人情報を含む文書には注意してください。

## 従量課金のログイン

**ログイン済みですが、サブスクリプションではありません** と表示されたカードには、警告が添えられます。「サブスクリプションではなく、使った分だけ料金が発生します。」

- **それでも使用** を押すまで、GenOffice がそのログインを使うことはありません。押したあとは、リクエストのたびにそのアカウントへ課金されます。
- 押したあとも、自動で選ばれることはありません。**使用する AI** でご自身で選ぶ必要があり、そこには **有料** と表示されます。
- 許可は、そのプログラムについてだけ記憶されます。プログラムからログアウトするか、ログインが変わると、許可は消去されます。
- サブスクリプションで使いたい場合は、サブスクリプションのアカウントでプログラムにログインし直してから **再確認** を押します。

## アカウントの切り替えとログアウト

ログイン済みのカードには、ログイン中のアカウントが表示されます。Claude と Codex のカードには、プログラムが報告する場合はプラン名も表示されます。ボタンも 2 つ増えます。

- **別のアカウントでログイン** は、プログラム自身のログイン手順をもう一度始めます。開いたウィンドウで、別のアカウントを使ってログインを済ませます。
- **ログアウト** は、プログラム自身のログアウトを実行します。カードの表示は **未ログイン** に変わります。
- Claude と Codex のカードでは、どちらも GenOffice だけでなく、この PC のそのプログラム全体に適用されます。ターミナルで Claude Code や Codex を使っている場合は、そちらも一緒にログアウトされるか、アカウントが切り替わります。そのため GenOffice は実行の前に確認を求めます。
- Claude と Codex のカードには **このアプリでは使わない** もあります。プログラムとそのサインインはそのままにして、GenOffice だけがそのプログラムを使わなくなります。状態の確認もリクエストの送信もせず、**自動** でもそのプログラムは飛ばされます。ターミナルでの利用には影響しません。カードには **このアプリではオフ** と表示され、**再び使う** を押すと元に戻ります。GenOffice の外は何も変わらないため、どちらも確認を求めません。
- ChatGPT のカードは違います。**ログアウト** を押すと「このアプリと ChatGPT の接続を解除します」という確認が出ます。確認すると、GenOffice は OpenAI にこのアプリの接続を終わらせるよう依頼し、この PC に保管していたログイン情報を削除します。**別のアカウントでログイン** は、確認なしですぐにブラウザーでログインページを開きます。どちらも、Codex を含め、この PC のほかのプログラムには影響しません。
- 接続済みの ChatGPT のカードには「このアプリの AI は ChatGPT のプランの範囲で動きます」という案内と、**使用量を管理** リンクがあります。リンクを押すと ChatGPT の設定の使用量ページが開き、このアプリがどれだけ使ったかを確認したり、このアプリだけの上限を設定したりできます。
- アカウントとこの 2 つのボタンは、設定 ▸ AI のカードにだけ表示されます。GenOffice はアカウントを表示するだけで、どこにも保存しません。

## どの AI が使われるか

設定 ▸ AI の **使用する AI** は、最初は **自動** になっています。自動は次の順で決めます。

1. Claude のカードが「接続済み」なら、Claude。
2. そうでなく、ChatGPT のカードが「接続済み」なら、ChatGPT。
3. そうでなく、Codex のカードが「接続済み」なら、Codex。
4. どれでもなければ、AI は接続されていません。このとき AI パネルには、エラーではなく接続ガイドが表示されます。

自動が、追加の料金がかかるものを選ぶことはありません。API キーも、従量課金のログインも選びません。これらは、ご自身で選んでいる間だけ使われます。

AI をご自身で 1 つ選ぶこともできます。同じ場所で選ぶか、AI パネルの下部にあるモデル一覧で選びます。選んだ AI が使えなくなっても、GenOffice が黙って別の AI に切り替えることはありません。何が起きたかを知らせ、接続し直す方法を表示します。

モデルの一覧には、プログラム自身が報告するモデルが表示されます（ChatGPT の場合は、そのプランで使えると OpenAI が示すモデルで、ご自身で選ぶまではその最初のモデルが使われます）。各モデルには名前と正確なモデル ID が並び、**既定のモデル** には現在それが指しているモデルが書かれます。AI パネル下部の選択表示と **使用する AI** にも、そのモデル名が表示されます。一覧の読み取りは AI に何も尋ねないため、プランの使用量には数えられません。プログラムが古くてモデルを報告できない場合は、アプリに組み込まれた短い一覧が代わりに表示されます。

Codex を選べる場所には、必ず次の 1 行が添えられます。「アプリ内で Codex のサブスクリプションを使うことは、OpenAI が公式に推奨している方法ではありません。」このことを踏まえて決めてください。

## リクエストが止まったとき

プランの上限を使い切ったとき、ログインの期限が切れたとき、プログラムがなくなったときに、リクエストは止まります。GenOffice が自分で別の AI に切り替えることはありません。

- 返信が止まった場所に理由が表示されます。上限を使い切った場合は、プログラムが報告していれば、リセットされる時刻も表示されます。
- 直接接続した ChatGPT は、プランの上限か、ChatGPT の設定でこのアプリに設定した上限を使い切ると止まります。リセットされる時刻は表示されません。ChatGPT の設定でこのアプリの接続を解除した場合は、カードが **未ログイン** に変わるので、もう一度ログインします。
- もう一方のサブスクリプションが接続されていれば、**… で続行** ボタンが表示されます（たとえば **ChatGPT で続行** や **Codex で続行**）。押すと、そちらが使用する AI になり（モデル一覧にも変更が反映されます）、リクエストをもう一度実行します。
- ほかに残っている接続が、許可済みの従量課金のログインだけの場合は、同じボタンに料金についての注意書きが付きます。
- API キーに切り替えるボタンが表示されることはありません。

## 使用量の表示

上限の 80% 以上を使うと、AI パネルに「85% 使用 · 15:00 にリセット」のような行が表示されます。Claude は 5 時間の上限と 7 日間の上限を報告し、Codex も報告があれば同じように表示されます。80% 未満のとき、またはプログラムから何も報告がないときは、行は表示されません。直接接続した ChatGPT ではこの行は表示されません。使った量は、ChatGPT のカードの **使用量を管理** から確認します。

## 何がどこに送られるか

サブスクリプションを初めて使えるようになったとき、GenOffice は案内を 1 回表示します。もう一度読むには、設定 ▸ AI ▸ **初回接続時の案内** で **もう一度見る** を押します。案内には次の 3 つが書かれています。

- 文書の内容と会話は、ご自身のアカウントで Anthropic または OpenAI に送信されます。
- その内容が AI の学習に使われるかどうかは、GenOffice ではなく、その会社でのご自身のアカウント設定によって決まります。
- GenOffice は Codex の会話履歴の保存をオフにしますが、Codex が独自の診断ログをこの PC に残す場合があります。

直接接続した ChatGPT のリクエストは、Codex プログラムを通らず、この PC から OpenAI に直接送られます。

**選択範囲をAIに隠す** で隠した内容は、どの AI を使っていても送信されません。

## 知っておくとよいこと

- **速度。** Claude Code や Codex 経由の返信は、API キー経由の返信より数秒遅れて始まります。先にプログラムが起動する必要があるためです。直接接続した ChatGPT は、プログラムを起動しません。
- **ChatGPT の無料プラン。** 「接続済み」と表示されますが、上限が小さいため、リクエストが早く止まります。使用量の表示も出ません。
- **画像生成。** このバージョンでは、どのプランでもサブスクリプションで画像は生成できません。画像プロバイダーのキーが必要です。[AI モデルと設定](help://ai-models) を参照してください。
- **プロキシ。** Claude Code と Codex は、GenOffice からプロキシ設定を受け取りません。ターミナルで実行するときと同じように、`HTTPS_PROXY` 環境変数など、この PC に設定されたプロキシを使います。ターミナルで接続できない場合は、ここからも接続できません。
- **コマンドとほかのプログラム。** `ieumoffice` コマンドや、接続したコーディングエージェントから届いたリクエストは、許可しないかぎりサブスクリプションを使いません。許可した場合も使うのは Claude Code か Codex で、直接接続した ChatGPT は使いません。[コーディングエージェントの接続](help://mcp) を参照してください。
- **エージェントモード。** [エージェントモード](help://agent-mode) は、この PC の Claude Code または Codex を実行します。直接接続した ChatGPT ではエージェントを実行できません。
