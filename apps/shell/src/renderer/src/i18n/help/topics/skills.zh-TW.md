# 技能

技能是交給 AI 的工作說明。把一再重複的事寫下來一次——整理會議筆記的步驟、報告的語氣、每次都要檢查的重點——之後就能在 AI 面板中呼叫它，AI 也會在適合的時候自己拿來用。技能是一個放著 `SKILL.md` 檔案的資料夾，採用開放格式，所以在 GenOffice 中做好的技能，拿到 Claude Code 或 Codex 裡也能照樣使用。

## 開啟和關閉技能

**設定 ▸ 技能**會依來源分組，列出這台電腦上的技能。技能和在程式設計代理程式中一樣以名稱顯示。用上方的搜尋框，可以依名稱或說明尋找。

| 來源                  | 包含的內容                                   | 一開始 |
| --------------------- | -------------------------------------------- | ------ |
| **內建**              | GenOffice 隨附的 5 個技能                    | 開啟   |
| **我的技能**          | 你新增或製作的技能（`~/.ieumoffice/skills`） | 開啟   |
| **Claude 技能資料夾** | `~/.claude/skills` 中的技能                  | 關閉   |
| **Claude 外掛程式**   | 已安裝的 Claude 外掛程式中的技能             | 關閉   |
| **Codex 技能資料夾**  | `~/.agents/skills` 中的技能                  | 關閉   |

- 用開關開啟或關閉技能。同一個設定會同時套用到各編輯器的 AI 面板、首頁的 AI 問答和代理程式視窗。
- 已開啟的技能可以選擇**自動使用**或**僅在呼叫時**，一開始是自動使用。選僅在呼叫時，只有你親自呼叫時才會用到這個技能。
- 不同來源的技能可能同名。請靠每一列上的來源標籤區分。
- 更多選單裡有**查看內容**、**直接修改**（僅限我的技能）、**匯出（zip）**（僅限我的技能）和**開啟資料夾**。
- **移到資源回收筒**會把我的技能中的一個移到系統的資源回收筒，之後可以從那裡還原。
- 內建技能無法刪除，只能隱藏：選擇**隱藏**。在清單底部按一下**重新顯示**，它就會以一開始的狀態回來。
- 想修改內建技能或其他程式的技能，請選擇**複製到我的技能**。副本會出現在我的技能中，原技能隨之關閉。
- 匯出附有範本的技能時，範本文件也會一起放進 zip。匯出前請確認文件裡沒有個人資料。

## 新增技能

1. 在**設定 ▸ 技能**中按一下**新增**。
2. 選擇**從資料夾**、**從 zip 檔案**或**從 GitHub 連結**。選 GitHub 時，填入公開儲存庫的網址或 `owner/repo`，再按一下**尋找**。
3. 在預覽中檢查找到的技能。預覽會顯示檔案數量和大小、是否含指令碼、內文中的網址，以及授權檔案。
4. 只勾選要安裝的技能，然後按一下**安裝**。安裝好的技能一開始就是開啟狀態。

預覽下方一定會寫著：「只安裝來自可信來源的技能。技能會向 AI 下達指示，在代理程式視窗中還可以執行指令碼」。來源不明的技能，請先讀過一遍再安裝。

- 如果我的技能中已有同名技能，請在那一列選擇**取代**或**略過**。
- 從 GitHub 下載時，GenOffice 只會連線到 `github.com`、`api.github.com` 和 `codeload.github.com`，也不會傳送任何登入資料。壓縮檔太大或沒有通過安全檢查時，什麼都不會安裝。
- **建立技能**會開啟一個空白編輯器，由你自己填寫名稱、說明和內文。

## 檢查更新

- 對於從 GitHub 安裝的技能，更多選單中的**檢查更新**會尋找新內容。只有在你按下它時才會連線到 GitHub。
- 沒有變更時，會顯示「已是最新版本」。有變更時，先查看有變更的檔案和預覽，再按一下**更新**。
- 如果安裝後你自己修改過這個技能，還會顯示「你所做的修改將會遺失」。
- 更新後，技能的開啟/關閉狀態以及自動使用 / 僅在呼叫時的選擇都會保留。

## 在 AI 面板中呼叫技能

1. 在 AI 輸入框的開頭或空格之後輸入 `/` 或 `$`，就會出現已開啟技能的清單。
2. 繼續輸入可以縮小範圍。例如輸入 `/meet` 會找到 `meeting-minutes`。說明裡的詞也能用來尋找，輸入 `/會議` 也可以。
3. 用方向鍵選取一個，按 Enter 或 Tab。這個技能會變成輸入框上方的一個標籤。
4. 寫下你的要求並傳送。GenOffice 會把技能內容附在要求裡。

- 在 Excel 的 AI 面板中，`$` 只有在輸入框的最開頭才會開啟清單，這樣不會妨礙輸入 `$A$1` 這類儲存格位址。
- 可以加入多個標籤，按 × 可以移除其中一個。Esc 只會關閉清單，不會停止正在執行的 AI。
- 清單底部的**管理技能…** 會開啟**設定 ▸ 技能**。
- 標籤會留在已傳送的訊息和儲存的對話中。重新開啟對話再次傳送時，會重新讀取技能目前的內容。如果在這期間技能被移除或關閉，標籤上會顯示「無法使用」。
- 要一起傳送的技能文字太長時，會顯示「技能太大，無法一起傳送」，而且不會傳送任何內容。

## AI 自行使用的技能

- 已開啟且設為自動使用的技能，名稱和說明會以清單形式交給 AI。某個技能符合要求時，AI 會取出它的內容來使用。
- AI 使用技能時，對話中會顯示「已使用技能 〈名稱〉」。
- AI 會根據說明判斷要不要使用某個技能。在說明中寫清楚這個技能適合在什麼時候使用，能幫 AI 選得更準確。

## 用對話製作技能

1. 在 AI 面板中說一句話，例如「把剛才做的事存成技能」或「做一個照我們公司格式寫報告的技能」。
2. AI 會挑出值得重複的步驟和規則，顯示一張**建立技能**卡片。只用這一次的值，例如姓名和日期，不會寫進說明裡。
3. 在卡片上檢查並修改名稱、說明和內文。名稱會顯示在技能清單中，也是在 `/` 後面輸入的內容，只能使用英文小寫字母、數字和連字號(-)。
4. 按一下**儲存**。新技能會加入我的技能，處於開啟狀態，並立刻出現在 `/` 清單中。

- 在你按下**儲存**之前，不會寫入任何檔案。按一下**取消**的話，對話中只會留下「未儲存的技能建議」。
- 也可以請它修改現有的技能，例如「把整理會議紀錄的技能改成我們的做法」。這時卡片標題會是**修改技能**。我的技能中的技能會透過**取代**直接覆寫；內建技能或其他程式的技能則會以副本形式存進我的技能，原技能隨之關閉。

## 把文件加為範本

在編輯器的 AI 面板中製作技能時，可以把目前的文件當成範本一起帶上。勾選卡片上的**將此文件作為範本一起儲存**，按鈕就會變成兩個。

- **製作空白範本**：文件的副本會在新分頁「範本預覽 - 〈title〉」中開啟，該分頁裡的 AI 會清除已填入的值，例如姓名、日期和個人資料。檢查一遍這個分頁，再自己動手修改，然後按一下**將此分頁儲存為範本**；分頁在那一刻的樣子就會成為範本。
- **依原文件儲存**：把目前的文件原封不動地儲存為範本。如果文件中有你對 AI 隱藏的部分，這個按鈕會被停用，以免隱藏的內容原樣進入範本。
- 範本會以文件副本的形式保存在技能資料夾裡。原文件不會改變。

## 使用附有範本的技能

- 附有範本的技能在清單中會顯示**含範本**。
- 以標籤形式呼叫並傳送後，範本的副本會以新的未命名文件開啟，該分頁裡的 AI 會接著處理你的要求。原本的面板會留下「將在新分頁中使用範本工作」和**前往分頁**。
- AI 自行選用附有範本的技能時，不會馬上開啟分頁，而是在對話中顯示**用此範本開新文件**按鈕。
- 新文件要存放在哪裡，通常由你在第一次儲存時決定。不過 Markdown 和 HTML 編輯器會照舊存入預設資料夾。範本檔案本身保持不變。

## 含指令碼的技能

- 在一般 AI 面板和首頁的 AI 問答中，技能的指令碼絕不會執行。只有技能的文字會交給 AI。
- 含指令碼的技能會顯示**含指令碼 · 在代理程式視窗中完整運作**，把它加為標籤時會顯示「此技能的指令碼不會在一般 AI 視窗中執行」。但不會阻止傳送。
- 想連指令碼一起使用，請在代理程式視窗中呼叫這個技能。請參閱[代理程式模式](help://agent-mode)。

## 內建技能

| 技能              | 作用                                             |
| ----------------- | ------------------------------------------------ |
| `meeting-minutes` | 把會議筆記整理成列明決議事項和待辦事項的會議紀錄 |
| `internal-comms`  | 撰寫公告、電子報、進度報告、常見問題等內部文字   |
| `humanizer`       | 找出文字中像是 AI 寫的說法，把它改得自然         |
| `copy-editing`    | 檢查你寫好的英文文字，改得更清楚、更簡潔         |
| `find-skills`     | 在代理程式視窗中尋找你需要的技能，並建議安裝     |

`copy-editing` 是為英文行銷文字設計的。`find-skills` 只能在代理程式視窗中使用。

## 在代理程式視窗中

- 代理程式視窗沿用**設定 ▸ 技能**中的開啟/關閉設定，同樣可以在輸入框中用 `/` 或 `$` 呼叫技能。
- 專案資料夾中 `.claude/skills` 和 `.agents/skills` 裡的技能，不必開啟就會在該工作階段中使用。
- 技能清單在工作階段開始時就固定下來。如果在工作階段中途開啟或關閉技能，會顯示「變更的技能將從下一個工作階段起生效」。
- 代理程式製作技能時，視窗中也會出現同樣的卡片。範本可以從分頁中開啟的文件和專案資料夾裡的檔案中選擇。
- 代理程式找到值得安裝的技能時，會出現安裝建議。用**開啟預覽**開啟它，由你親自按一下**安裝**；否則什麼都不會安裝。安裝的技能從下一個工作階段起可以使用。
