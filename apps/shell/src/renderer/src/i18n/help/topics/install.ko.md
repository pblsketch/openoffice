# GenOffice 설치

모든 버전은 GitHub에 있는 프로젝트의 [Releases 페이지](https://github.com/pblsketch/openoffice/releases/latest)에 올라옵니다. 이 버전은 Windows용으로 배포됩니다.

## 내 컴퓨터에 맞는 파일 고르기

| 플랫폼      | 필요한 것                         | 파일                            |
| ----------- | --------------------------------- | ------------------------------- |
| **Windows** | Windows 10 이상, 64비트 Intel/AMD | `GenOffice-Setup-<version>.exe` |

이전 버전은 Releases 페이지에 그대로 남아 있습니다.

## Windows에서

1. Releases 페이지에서 `GenOffice-Setup-<version>.exe`를 내려받습니다.
2. 실행합니다. 설치 파일에 코드 서명이 없어서, Windows가 먼저 파란색 "Windows의 PC 보호" 창을 띄울 수 있습니다. **추가 정보**를 누른 다음 **실행**을 누릅니다. 창에 나오는 정확한 문구는 Windows 버전에 따라 다를 수 있습니다.
3. 설치 프로그램의 안내를 끝까지 따라갑니다.

GenOffice를 시작 메뉴에 넣고 `.docx`, `.xlsx`, `.pptx`, `.pdf` 등을 등록해서, 파일을 두 번 클릭하면 열립니다.

서명이 없는 설치 파일이므로, 위 Releases 페이지에서 내려받은 것만 실행하세요.

## 업데이트

- GenOffice는 같은 GitHub Releases 페이지에서 새 버전을 찾습니다. 새 버전이 올라오면 **설정 ▸ 정보**에 업데이트가 나타납니다. **…(으)로 업데이트**를 누르고 다운로드가 끝나기를 기다린 뒤 **재시작 후 설치**를 누릅니다.
- **메뉴(☰) ▸ 업데이트 확인**을 누르면 그때 바로 확인합니다. Mac에서는 **도움말 ▸ 업데이트 확인**입니다.
- 확인에 실패해도(네트워크가 없거나 아직 올라온 버전이 없는 경우) 아무 일도 일어나지 않고, 앱은 그대로 쓸 수 있습니다.
- **업데이트 채널**도 설정 ▸ 정보에 있으며, 안정 버전과 베타 버전 중에서 고릅니다. 바꾸면 즉시 반영되어 업데이트를 확인하며, 베타 설치를 안정 버전으로 되돌리지는 않습니다.
- 업데이트 파일에도 코드 서명은 없습니다. 대신 설치하기 전에, 내려받은 파일이 그 릴리스와 함께 공개된 확인 값과 일치하는지 앱이 검사합니다.

## 지금 실행 중인 빌드

**설정 ▸ 정보**는 앱이 지금 가진 버전, 따르는 업데이트 채널, 프로젝트가 있는 곳을 보여 주는 곳입니다. 이 앱의 바탕이 된 오픈 소스 프로젝트도 여기에 적혀 있습니다.

## 명령줄도 함께 옵니다

모든 설치본에는 `ieumoffice` 명령이 들어 있고, 창이 쓰는 바로 그 엔진을 구동합니다. 같은 파일에 대한 둘의 판단이 어긋날 일은 없습니다. `ieumoffice install-cli`로 `PATH`에 넣습니다. 무엇을 할 수 있는지는 [명령줄과 에이전트](help://cli)를 보세요.
