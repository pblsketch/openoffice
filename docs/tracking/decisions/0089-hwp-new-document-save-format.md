# 0089 한글 새 문서의 기본 저장 형식

## 맥락

한글 문서를 메신저로 보낼 때 HWPX만 받는 곳이 늘었다. 그런데 이음오피스에서 새 한글 문서를 처음 저장하면 "제목 없음.hwp"가 먼저 나와서, 사용자가 매번 "다른 이름으로 저장"의 형식 목록에서 HWPX를 골라야 했다(2026-10-29 사용자 의견, 전북 수학 교사). 한컴 한글에는 새 문서의 기본 저장 형식을 정하는 설정이 있다.

## 결정

- 설정 → 일반의 **저장 위치** 아래에 **새 한글 문서 저장 형식**을 둔다. 고르는 값은 HWP(.hwp)와 HWPX(.hwpx) 둘이고, 저장하지 않은 값은 HWP다.
- 이 값은 `userData/app-settings.json`의 `hwpDefaultFormat`에 둔다. 껍데기 앱이 쓰고, 한글 메인이 첫 저장 대화 상자를 열 때마다 읽는다.
- **파일이 없는 새 문서의 첫 저장에만** 적용한다. 대화 상자의 기본 이름과 파일 형식 목록의 첫 항목이 이 형식이 된다.
- 파일이 있는 문서는 그 파일의 형식 그대로 저장한다. 스킬 양식의 제목 없는 사본도 양식의 형식을 따른다. 복구 사본에서 파일 없이 되살린 문서는 원래 파일의 형식을 따른다.
- 새 문서를 처음 저장할 때 대화 상자에서 다른 형식을 고르면 그 선택이 이긴다. 설정은 어디까지나 처음의 제안이다.

## 버린 대안

- **새 문서의 기본값만 HWPX로 바꾼다**: HWP가 필요한 사용자에게는 반대의 불편이 생긴다. 사용자가 고르게 한다.
- **파일이 있는 문서도 저장할 때마다 설정한 형식으로 바꾼다**: 저장 결과의 형식이 사용자가 연 파일과 달라지고, `.hwp`에서 `.hwpx`로 바꿀 때 바탕쪽·메모처럼 엔진이 옮기지 못하는 것이 있다. "연 형식 그대로 저장" 규칙을 지킨다.
- **새 문서를 만들 때 HWPX 빈 문서에서 시작한다**: 편집기와 복구 사본이 쓰는 빈 문서의 형식까지 바꾸게 되어, 첫 저장 전의 복구 경로가 달라진다. 이번에는 저장 대화 상자의 제안만 바꾼다.

## 결과

- HWPX만 받는 메신저를 쓰는 사용자는 설정을 한 번 바꾸면 새 문서를 곧바로 `.hwpx`로 저장할 수 있다.
- 기존 문서를 HWPX로 보내려면 지금처럼 "다른 이름으로 저장"에서 HWPX를 고른다.
- 설정은 앱 전체에 하나이고, 이미 열린 탭에도 다음 저장부터 적용된다.
