# 0068 — 한글 모양 복사는 앱 모듈에서 한컴 동작으로 채운다

## 맥락

한글 탭에는 rhwp-studio의 `모양 복사`가 이미 있었다(Alt+C, 도구 줄 단추, 편집 메뉴). 그러나 한컴 한글 2024의 모양 복사와 달랐다.

- 무엇을 복사할지 고르는 대화상자가 없었다.
- 언어별 글꼴, 글자·문단 테두리/배경, 탭 위치를 잃었다.
- 표에서 글자 블록에 칸 모양을 적용하지 않았고, 본문에서 복사한 모양을 셀 블록에 적용하면 상태를 덮어썼다.
- 양식 칸의 `fieldName`을 칸 모양으로 복사해 필드를 지울 수 있었다.
- 한 번 적용이 실행 취소 2~3단계였고, 복사한 모양은 한 번 쓰면 사라졌다.

저장소 주인은 2026-10-25에 대화상자까지 하는 B안, 1단계는 같은 문서만, 양식 칸 보호를 먼저, 셀 기본값에 테두리까지 포함하는 것을 골랐다. 분석과 설계는 `docs/plans/hwp-format-copy.md`에 있다.

## 결정

**한글 모양 복사는 앱의 `apps/hwp/studio-plugin/format-copy.mjs`가 맡고, studio에는 실행부를 잇는 작은 패치만 건다.**

- 명령 id(`edit:format-copy`, `edit:format-paste`), 도구 줄 단추, 편집 메뉴, `Alt+C`는 그대로 둔다. 화면 이름은 한컴과 같은 `모양 복사`다.
- studio 패치는 셋이다.
  - `studio-format-copy-safety`: 옛 `FORMAT_COPY_CELL_KEYS`에서 `fieldName`·`editableInForm`을 뺀다. 지금 기능을 쓰는 사람의 양식 칸을 먼저 지킨다.
  - `studio-format-copy`: `edit.ts`의 두 실행부를 새 모듈로 바꾸고, `edit:format-copy`를 양식 모드에서 끈다.
  - `studio-format-copy-state`: `input-handler.ts`의 `hasCopiedFormat`이 새 모듈의 상태를 보게 한다.
- 대화상자는 한컴의 본문 선택지(글자/문단/둘 다/글자 스타일/문단 스타일)와 셀 선택지(속성/테두리/배경, 기본 셋 다 켬), 적용 대상(둘 다/셀만)을 둔다. 편집기 안 대화상자라 한국어·영어만 쓴다.
- 복사한 모양은 적용해도 지우지 않고 덮어쓸 때까지 이 편집기에서 기억한다. 1단계에서는 다른 문서로 가져가지 않는다.
- 한 번 적용은 한 실행 취소 단계다. 글자·문단·칸은 합성 명령으로, 문단 스타일은 스냅샷 하나로 묶는다.
- 칸 모양에는 양식 필드 이름·편집 가능 여부·칸 크기를 넣지 않는다. `fieldName`은 데이터이고 모양이 아니다.
- 온전히 적용할 수 없는 자리는 일부만 바꾸지 않고 이유를 알린다. 표 안의 표는 글자 모양·글자 스타일만, 머리말·각주·본문과 표에 걸친 선택은 1단계에서 거절한다.
- 글꼴 등록은 복사할 때가 아니라 적용할 때 변경 안에서만 한다. 복사는 문서를 바꾸지 않는다.

## 버린 대안

- **studio의 `performFormatCopy`를 통째로 다시 쓴다.** studio 소스에 한컴 대화상자와 표 분류를 넣어 패치가 커지고, rhwp를 올릴 때마다 큰 충돌을 푼다. 앱 모듈은 studio를 import하지 않아 단위 시험이 쉽다.
- **새 명령을 등록하고 도구 줄·메뉴의 `data-cmd`를 바꾼다.** 명령이 둘로 보이고, 명령 팔레트에 옛 명령이 남으며, DOM 이름에 기대야 한다. 기존 명령의 실행부만 바꾸는 편이 작다.
- **모든 적용을 스냅샷 하나로 한다.** 문서 전체를 복사해 큰 문서에서 느리다. 글자·문단·칸은 합성 명령으로, 스타일만 스냅샷으로 한다.
- **칸 모양에 양식 필드 이름을 포함한다.** 일반 칸의 모양을 이름 있는 칸에 복사하면 필드가 사라진다. 엔진으로 재현했고, 안전 패치와 새 모듈 양쪽에서 뺐다.
- **다른 문서로의 기억을 1단계에 넣는다.** 앱 실행 토큰과 공유 저장소가 필요해 범위가 커진다. 한 문서 안에서 여러 번 적용하는 흐름을 먼저 낸다.

## 결과

- 단위 시험 23개, 실제 엔진 시험 5개, 패치 시험, 빌드한 앱 화면 시험 2개가 통과했다(`npm run test -w @genoffice/hwp`, `e2e/hwp-format-copy*.spec.ts`).
- 빌드한 앱에서 `Alt+C` 대화상자, 복사 뒤 블록 적용, 셀 항목 셋(테두리 포함), 일반 칸의 모양을 양식 칸에 적용한 뒤 `이름1`·`이름2` 필드가 남는 것을 확인했다.
- 아직 아닌 것: 다른 문서로의 기억, 머리말·꼬리말·각주·미주, 표 안의 표의 문단·칸 모양, 한컴과 나란히 두고 하는 육안 비교, rhwp 상위 제안.
