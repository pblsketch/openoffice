# 0071 업데이트 설치가 끝나지 않았을 때

## 맥락

Windows에서 "다시 시작 및 설치"를 누르면 앱은 꺼지는데 새 버전이 깔리지 않는다는 신고가 들어왔다(2026-10-26). 앱은 electron-builder의 NSIS 설치 프로그램을 조용한 모드(`/S`)로 띄우고 바로 꺼진다. 조용한 설치 프로그램은 다음 두 경우에 아무 창도 없이 그냥 끝난다.

- "모든 사용자용"으로 설치한 PC. 처음 설치 때 이 앱의 설치 프로그램은 "나만 / 모든 사용자"를 고르게 한다(`oneClick: false`, `perMachine` 지정 없음). 모든 사용자용 설치는 업데이트에도 관리자 승인이 필요하다. 승인 창을 거절했거나, 창이 다른 창 뒤에 가렸거나, 표준 계정이라 관리자 암호가 없으면 설치 프로그램은 그대로 끝난다.
- 설치 폴더 안의 프로세스를 끝내지 못했을 때. 예를 들어 앱을 관리자 권한으로 실행해 두었으면, 설치 프로그램은 두 번 다시 시도한 뒤 "닫을 수 없음" 창의 기본값(취소)으로 끝난다.

앱은 설치 프로그램이 어떻게 끝났는지 들을 길이 없고, 업데이트 기록도 남기지 않아 신고만으로는 어느 경우인지 가릴 수 없었다. 또 설치 프로그램을 앱이 꺼지기 전에 띄웠기 때문에, 저장하지 않은 문서가 있어 "저장할까요?"를 묻는 동안 설치 프로그램이 1~2초 뒤 앱을 강제로 끝냈다.

## 결정

- **설치 프로그램은 앱이 끝나기로 확정된 뒤에 띄운다.** "다시 시작 및 설치"는 앱을 끄라고 요청할 뿐이고, 설치 프로그램은 `will-quit`(모든 창이 닫히고 어떤 저장 질문도 취소되지 않음)에서 시작한다. 저장 질문에서 취소하면 다시 시작 요청도 취소된다(`cancelUpdateRestart`). electron-updater가 스스로 끝날 때 설치하는 장치(`autoInstallOnAppQuit`)는 끄고, "나중에" 뒤의 끝날 때 설치도 같은 자리에서 한다.
- **설치 프로그램을 띄울 때마다 기록을 남긴다.** 데이터 폴더의 `update-install-attempt.json`에 어느 버전을, 어느 버전에서, 어떤 방식으로 띄웠는지 적는다. 다음 실행이 여전히 그 이전 버전이면 설치가 되지 않은 것이다.
- **실패하면 한 단계씩 물러난다.** 조용한 설치가 되지 않았으면 다음 실행의 업데이트 창이 그 사실을 알리고("install-failed"), 다시 내려받은 뒤 설치 프로그램을 창으로 띄운다. 창으로 띄운 설치 프로그램은 진행 상황과 관리자 승인 요청, "닫을 수 없음" 창을 사용자에게 보여 준다. 그것도 되지 않았으면 다운로드 페이지를 안내한다. 실패한 기록은 다음 설치 시도가 덮어쓸 때까지 남겨, "나중에"를 눌러도 단계가 처음으로 돌아가지 않는다. 실패한 뒤에는 끝날 때 조용히 다시 설치하지 않는다.
- **관리자 권한이 필요한 설치는 처음부터 창으로 띄운다.** 앱 폴더에 파일을 만들어 보고(Windows의 `access(W_OK)`는 읽기 전용 속성만 본다) 쓸 수 없으면, "다시 시작 및 설치"에서 설치 프로그램을 창으로 띄우고 업데이트 창에 관리자 승인을 묻는 창이 뜬다고 미리 적는다. 끝날 때 설치는 지금처럼 조용히 한다.
- **업데이트 기록을 남긴다.** 데이터 폴더의 `update-log.txt`에 앱과 electron-updater가 한 일을 한 줄씩 적는다. 256KB를 넘으면 오래된 절반을 버린다. 밖으로 보내지 않고, 신고할 때 사용자가 붙인다.

## 버린 대안

- **언제나 창으로 띄우기**: 대부분의 PC(나만 설치)에서는 조용한 설치가 잘 된다. 창으로 띄우면 설치 방식 선택 화면과 마침 화면을 매번 거쳐야 한다.
- **설치 방식을 "나만"으로 고정하기(`perMachine: false` + 선택 화면 없애기)**: 이미 모든 사용자용으로 설치한 사람의 업데이트는 그대로 막힌다.
- **electron-updater의 `elevate.exe`로 조용히 승인 받기**: 승인 창을 거절하면 다시 아무 말 없이 끝난다. 실패를 알아채는 기록은 어차피 필요하고, 창으로 띄우는 편이 무슨 일인지 보여 준다.
- **설치 프로그램이 끝나기를 앱이 기다렸다가 결과 보기**: 설치 프로그램은 앱이 꺼져야 진행된다. 앱이 살아 있는 동안에는 결과가 없다.

## 결과

- 조용한 설치가 실패해도 다음 실행에서 사용자가 알게 되고, 두 번째 시도는 눈에 보이는 창에서 한다.
- 저장 질문 중에 설치 프로그램이 앱을 끄는 일이 없어진다.
- 신고자에게 `%APPDATA%\IeumOffice\update-log.txt`를 받아 어느 단계에서 멈췄는지 볼 수 있다.
- 설치 프로그램 자체가 어디서 그만두었는지는 여전히 기록되지 않는다(NSIS의 조용한 모드는 로그를 남기지 않는다). 기록에는 "띄웠다"와 "다음 실행의 버전"만 있다.
- 실제 릴리스로 확인할 것: 모든 사용자용 설치에서 창으로 뜨는지, 승인 거절 뒤 다음 실행에 안내가 나오는지(`docs/tracking/findings.md`).
