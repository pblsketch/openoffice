# 0013 — 디자인 템플릿 글꼴을 설치 파일에 넣는다

## 맥락

슬라이드 디자인 템플릿 12개는 저마다 정해진 글꼴로 모양을 낸다. 글꼴이 PC에 없으면 다른 글꼴로 바뀌어 그려지고, 템플릿이 템플릿처럼 보이지 않는다. 템플릿이 쓰는 글꼴은 10개 패밀리(파일 13개)이고, 모두 SIL Open Font License 1.1이다. 템플릿이 실제로 쓰는 굵기만 넣는다. 합치면 약 42.9 MiB이고, 설치 파일은 압축되어 약 14 MB 커진다. 저장소 주인은 "수십 MB"까지 늘어나는 것을 받아들였다.

## 결정

템플릿 글꼴을 설치 파일에 넣는다. 폴더 하나(`packages/ui/template-fonts`)를 설치 파일에 한 번만 넣고(`resources/template-fonts`), 워드·엑셀·파워포인트 편집기가 모두 같은 폴더를 읽는다. 편집기마다 따로 넣지 않는다. 실행 중에 글꼴을 내려받지 않고, Windows에 설치하지도 않는다. 원래 배포처의 파일을 고치지 않고 그대로 넣고, 라이선스 글을 곁에 둔다.

## 택하지 않은 것

- **k-slide처럼 템플릿마다 글꼴을 따로 둔다.** 템플릿마다 다른 글꼴을 쓰면 합쳐서 약 100 MB가 되고, 확인하고 고지할 라이선스가 수십 개가 된다. 템플릿들이 같은 글꼴 묶음을 나눠 쓰게 했다.
- **PC에 깔린 글꼴만 쓴다.** 설치 파일은 커지지 않지만 템플릿의 모양이 PC마다 달라진다. 템플릿 글꼴은 Windows에 기본으로 들어 있지 않다.
- **처음 쓸 때 내려받는다.** 설치 파일은 작아지지만 내려받는 서버와 파일을 관리해야 하고, 오프라인에서는 템플릿이 깨진다. [0008](0008-remove-font-downloads.md)에서 없앤 내려받기를 다시 들이는 일이기도 하다.

## 결과

- 설치 파일이 약 14 MB, 설치된 폴더가 약 42.9 MiB 커진다. 글꼴 파일 합계의 상한은 `TEMPLATE_FONTS_MAX_BYTES`(45 MiB)이고 테스트가 지킨다.
- [0008](0008-remove-font-downloads.md)은 그대로다. 글꼴 내려받기는 여전히 없고, 사용자가 가진 글꼴 파일을 설치하는 기능도 바뀌지 않는다.
- 다른 PC나 다른 프로그램에서도 같은 모양으로 보려면 그 PC에 글꼴을 설치해야 한다. 템플릿 고르는 화면의 버튼으로 글꼴 폴더를 열고, 사용자가 파일을 직접 설치한다.
- 글꼴 이름, 라이선스, 배포처, 받은 버전은 `NOTICE`와 `packages/ui/template-fonts/README.md`에 적는다. 글꼴을 더하거나 바꾸면 두 곳을 함께 고친다.
- 2026-10-31 [0092](0092-docx-pdf-fidelity-fixes.md)가 일부를 바꿨다. Noto Serif KR 두 파일은 PDF에 Type3로 들어가지 않도록 윤곽을 TrueType으로 바꿔 넣는다(이름·글자 폭·줄 높이 치수는 그대로). 그래서 폴더 합계가 약 51.1 MiB가 되어 상한을 55 MiB로 올렸다.
