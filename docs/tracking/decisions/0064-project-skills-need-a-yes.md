# 0064 — 에이전트 모드에서 프로젝트 폴더의 스킬은 사람이 그 폴더에서 켠 동안만 쓴다

## 맥락

2026-10-22에 받은 외부 소스 점검이 짚었다. 에이전트 창은 고른 프로젝트 폴더의 `.claude/skills`, `.agents/skills`를 묻지 않고 세션에 넣었다(결정 0049). 남에게 받은 폴더를 고르면 그 안의 스킬이 사용자 모르게 에이전트의 지시가 된다. 스킬의 스크립트는 명령 실행이라 묻는 방식에서는 허락을 거치지만, "이 프로젝트는 믿고 맡기기"에서는 묻지 않고 돈다. Claude Code 자체도 같은 설계이긴 하다.

## 결정

- 시작 화면에서 폴더를 고르면, 그 폴더에 스킬이 있을 때 "이 폴더의 스킬" 칸이 이름과 설명을 보여 주고 "켜지 않기 / 켜기"를 고르게 한다. 처음은 켜지 않기다. 켜지 않은 채로도 시작할 수 있고, 그때 세션에는 그 폴더의 스킬이 들어가지 않는다.
- 켜면 그 폴더 스킬들의 지문을 `app-settings.json`의 `agentProjectSkills`에 폴더별로 적는다. 지문은 스킬마다 모든 파일의 자리와 내용의 해시다(`SKILL.md`만이 아니라 스크립트도 친다. 링크는 따라가지 않는다. 400개, 16MB를 넘으면 지문을 만들지 않고 꺼진 것으로 본다).
- 세션을 시작할 때 뒷단이 지문을 다시 만들어 적힌 것과 같을 때만 프로젝트 스킬을 묶음에 넣는다(`apps/shell/src/main/agent/project-skills.ts`). 창이 보낸 값으로 정하지 않는다.
- 켠 뒤로 파일이 하나라도 바뀌면 꺼진 것으로 돌아가고, 시작 화면이 "켠 뒤로 스킬이 바뀌었다"고 알리며 다시 고르게 한다.
- 프로젝트 지침(`CLAUDE.md`, `AGENTS.md`)은 이 결정 밖이다. 지시문에 붙는 글일 뿐 실행되는 것이 없고, 지금처럼 붙인다.

## 택하지 않은 것

- **처음 여는 폴더만 묻고 그 뒤로는 묻지 않는다.** 폴더를 받은 뒤에 스킬이 바뀌거나 더해지는 경우를 놓친다.
- **스킬을 고를 수 있게 하나씩 켜고 끈다.** 화면이 복잡해지고, 여러 스킬이 서로를 부르는 폴더에서 일부만 켜면 동작을 예상하기 어렵다. 한 폴더의 스킬은 함께 켜고 끈다.
- **시작할 때마다 묻는다.** 자기 폴더를 쓰는 사람이 매번 같은 질문을 받게 되어 읽지 않고 누르게 된다.

## 결과

- 남의 폴더를 골라도 그 안의 스킬은 사람이 목록을 보고 켜기 전에는 에이전트에 들어가지 않는다.
- 이미 프로젝트 스킬을 쓰던 사람은 업데이트 뒤 처음 그 폴더를 열 때 한 번 켜야 한다.
